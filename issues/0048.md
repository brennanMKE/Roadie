# 0048 — Audio does not play through HomePods or other AirPlay speakers

| | |
|---|---|
| **Status** | open |
| **Module** | AudioCore / App |
| **Platform** | macOS |
| **First seen** | 2026-10-13 |

## Description

Choosing a HomePod as the Mac's sound output has no effect on SkinAmp: playback keeps coming from the Mac mini's built-in speaker. SkinAmp should play through whatever output the user picks, including AirPlay 2 speakers, and should support playing to several speakers at once the way Music.app does (for example, two HomePods together).

## Steps to reproduce

1. Play a local file in SkinAmp.
2. Choose a HomePod as the sound output (Control Center › Sound or the menu bar).

## Expected behavior

- Playback moves to the HomePod, resuming at the same position.
- SkinAmp offers an AirPlay route picker so one or more AirPlay 2 speakers can be selected together, as in Music.app.

## Actual behavior

Audio keeps playing from the built-in speaker.

## Notes

Starting points, unverified:

- `AVAudioEngine`'s output node binds to an output device. `Player.handleConfigurationChange()` (`Packages/PlayerKit/Sources/AudioCore/Player.swift`) restarts the engine on `AVAudioEngineConfigurationChange`, but that may not fire for a default-output change, and the engine may stay on the device it started with. Check whether the output unit follows `kAudioHardwarePropertyDefaultOutputDevice`, or set the device explicitly when the default changes. Since #0042 the graph is connected once at the output rate; a new device with a different rate needs that revisited.
- Music.app's multi-speaker selection is AirPlay 2 multi-room, which Apple exposes for long-form audio through `AVRoutePickerView` / `AVRouteDetector` and an `AVPlayer` or `AVSampleBufferAudioRenderer` pipeline, not a raw `AVAudioEngine` output. Supporting it may mean changing the output stage (for example, rendering the engine offline and feeding an `AVSampleBufferAudioRenderer`) while keeping the EQ, gapless scheduling and analyzer tap.
- The user will add documentation on how Music.app's multi-HomePod playback works; attach it here (`issues/0048/`) and plan from it.

Hand-testing only: tests must stay silent, and the VM has no AirPlay path.
