# 0222 — Genre responses from Music Assistant are unrecorded, and nobody knows why the genre list is 14 short

| | |
|---|---|
| **Status** | open |
| **Module** | Tooling / MusicAssistantKit |
| **Platform** | macOS |
| **First seen** | 2026-10-27 |

## Description

M17 ([#0220](0220.md)) builds on `music/genres/*`, and no genre response is recorded: the fixtures have none, `ScriptedMusicAssistant` answers every genre command with the unknown-command error, and the shape of `media_counts` is a guess. The user's server also says `music/genres/count` = 113 while the first `library_items` page of 100 returned 99, so paging on the count, or stopping on a short page, may miss genres that have music. This issue adds a read-only `--record-genres` mode to `scripts/record-ma-fixtures.py`, runs it against the user's server, commits the fixtures, and writes down what the probe says. Design: [docs/design/genres.md](../docs/design/genres.md) §3.

## Plan

### Recorder (`scripts/record-ma-fixtures.py`)

1. **Allowlist.** Add to `ALLOWED` (reads only, all `library.read` in `commands.json`): `music/genres/count`, `music/genres/library_items`, `music/genres/media_counts`, `music/genres/get`, `music/genres/tracks`, `music/genres/albums`, `music/genres/overview`, `music/genres/genres_for_media_item`, `music/genres/global_exclusions`, `music/genres/scanner_status`. Nothing from the genre write commands (`add`, `merge`, `update`, `remove`, `*_alias`, `*_exclusion*`, `add_media_mapping`, `remove_media_mapping`, `scan_mappings`, `restore_defaults`) and nothing to `ALLOWED_WRITES`. Update the module docstring's run lines (`Genres: … --record-genres [--out DIR]   (read-only, #0222)`).
2. **`GENRE_FIXTURES`**, a frozenset of the names in design §3's table, plus `genres-probe` (the summary). Protect them from the default run's cleanup exactly like `QUEUE_FIXTURES` (`fn[:-5] not in WRITE_FIXTURES | QUEUE_FIXTURES | GENRE_FIXTURES`), and from `--check`'s shape rule: each is `{command, args, frames}` with an `ALLOWED` command (add a branch to `shape_problems`, as the queue fixtures have).
3. **`record_genres_calls(s)`**, pure over a session like `record_queue_calls` (so it's testable with a fake): the calls in design §3's table, in that order. It picks "the largest genre" from the `media_counts` result (most tracks; ties by name) and "a duplicate pair" as the first two ids whose names match case-insensitively in `genres-page-all` (skip `genre-tracks-filter-merged` when none). It collects ids from every listing for `media_counts`. Ids go to `library_items {genre}` as **ints** (`int(item_id)`), to `media_counts` as **strings**. Timeouts 30 s for the lists.
4. **`probe_summary(fixtures)`**, pure: a short text (and the same as a JSON object for the fixture `genres-probe.json`): item count per listing; `count` minus the size of the union of listings; the ids no plain page returned and which other listings (`media_type`, `content_type`, `hide_empty`, `global_exclusions`) contain them, with their names; genres with music per `content_type`; whether `genres-page-2` (offset 100) returned the rest. Also written to `docs/ma-protocol/genres-probe.txt` (scrubbed like the other docs).
5. **`record_genres(args)`**: the `record_queue` skeleton (read `.env` itself, `/info`, one session, `auth`, calls, `write_fixtures`, `gate`, delete on a gate failure). `--record-genres` in `main()`. `TRUNCATE` keeps whole lists for the genre listings and 5 items for `genre-tracks`, `genre-albums` and the `*-filter` fixtures (they are requested with `limit: 5` anyway).

### Fixtures and Swift

6. `MAFixture`: one case per new file, after the existing cases, under a `// #0222: --record-genres` comment (`baseline` stays the first 42). `MAFixtureTests`: whatever enumerates recorded cases picks them up; if a test lists expected commands, add the genre ones.
7. **Run it (host only).** The user has authorized agents to run the recorder against their server for this milestone. From the repo root on the host: `/usr/bin/python3 -I scripts/record-ma-fixtures.py --record-genres`, then `/usr/bin/python3 -I scripts/record-ma-fixtures.py --check`. The script reads `.env` itself: never `cat`, `source` or print `.env`, never put the token or URL in a command line, log, commit or issue. If the secret gate fails, the script deletes what it wrote; stop and say so in `## Notes`. Never run it in the VM (the guest has no `.env` and must not get one). The implementer asks the orchestrator to run it if its own session can't reach the server.
8. **Write down the answer** in `docs/ma-protocol-notes.md`: a new "Genres" section (the commands, `library_items`' filters, `media_counts`' exact shape, int vs string ids, the summary-vs-full keys) and the 99-of-113 explanation from `genres-probe.txt`, with the listing rule #0223 must use (design §3, "The rule until the probe says otherwise", confirmed or changed). Add a Quirks entry if the probe shows one (for example "(e) `library_items` without `media_type` omits non-default genres" or "(e) a page can come back short before the end"), with `MAFixtureTests.recordedQuirksHold` checking it against the genre fixtures.
9. If the probe contradicts design §3's rule, edit `docs/design/genres.md` §3 and #0223's `## Plan` to match, in this issue's commit.
