## Description

Every 0.0.4 bug the user hit was on Music Assistant: the row index (#0187), playlists that couldn't be played (#0189), LIST › Load with no way to a server playlist (#0190). Nothing drives the app against a Music Assistant server. This issue adds `MusicAssistantUITests` over the scripted server (#0197): connecting at launch, browsing, playing on This Mac and a speaker, the remote queue in the editor, the three regressions, playlists, favorites, discover, radio, the output picker, now-playing events and quit. Rows: [docs/design/test-automation.md](../docs/design/test-automation.md) §5.7 (Music Assistant parts), §5.10, and the Music Assistant rows of §5.5–§5.6.

## Plan

Launch: `app.launch(library: .musicAssistant, scenario: .queueLoaded, windows: [.main, .playlist])`: a verified server, the scripted library, a queue of 12 rows playing on the speaker `ap223aed81fe30` with row 2 current. Where a test needs This Mac, use `scenario: .thisMacIsASendspinPlayer` and select This Mac in the output picker. The probe's `maRequests` shows what the server received.

- `playAlbumShowsRemoteQueue`: select the speaker in `library.output`; double-click a recorded album → `maRequests` ends with `player_queues/play_media option=replace`; the playlist editor's rows are the album's tracks (remote rows), `pl.row.0` current, `main.marquee` shows the title, `main.state == playing`.
- `doubleClickRowSendsItsPosition` (**#0187**): with `queueLoaded`, double-click `pl.row.5` → `maRequests` ends with `player_queues/play_index index=5` and, after the pushed `queue_updated`, `pl.row.5` has `current=true`. Then select row 7, Return → `index=7`. Right-click row 1 › Play → `index=1`.

- `sortIsRefusedOnARemoteQueue`: `MISC › sort` → the pop-up items are disabled and `main.marquee` shows "Not for Music Assistant queues".
- `transportOnSpeaker`: `main.pause` → `players/cmd/pause`, `main.state == paused` after the event; `main.next` → `players/cmd/next`; volume slider → `volume_set`; balance → no request (refused quietly) and the marquee shows the balance text.
- `nowPlayingFollowsTheServer`: the scripted clock advances elapsed time; `main.time` advances without any request; the server pushes a `player_updated` with a new `current_media` (test hook: `-RoadieMAScript` can't be poked from the test, so the scenario includes a timed event 5 s after connect) → `main.marquee` changes.
- `doubleClickPlaylistPlays` (**#0189**): Library › Playlists, double-click "Party"-equivalent (the first recorded playlist) → `play_media` with the playlist URI, `option=replace`; the editor shows its tracks.
- `playlistRowMenu` (**#0189**): right-click the playlist → Play, Play Next, Add to Queue, Favorite, then New Playlist…, Rename…, Delete…, Export…, Import…; Play Next → `play_media option=next`; Add to Queue → `option=add`.
- `dragPlaylistAppendsToQueue` (**#0189**): drag the playlist row onto `pl.row.2` → `play_media option=add` (appended on a Music Assistant queue, #0173 decision 4) and the rows grow by the playlist's track count.
- `listLoadOffersLibraryPlaylist` (**#0190**): launch with `library: .musicAssistant`, `scenario: .libraryIdle`, a folder library configured too and the local queue playing (`-RoadieOpenFiles`): `LIST › load` pops "Library Playlist…" / "Playlist File…"; choose Library Playlist… → the picker sheet lists the recorded playlists; pick one, Load → the editor shows the Music Assistant queue with its tracks and This Mac's feed is Music Assistant (`probe.feed == musicAssistant`). Also `Playback › Load Playlist from Library…` is enabled and opens the picker.
- `saveQueueAsPlaylist`: with a remote queue, `LIST › save` → the Save Queue sheet; type a name, Save → `music/playlists/create_playlist` then `add_playlist_tracks` in `maRequests`; the Library's Playlists section shows the new name.
- `playlistCRUD`: New Playlist (toolbar) → the name sheet → `create_playlist`; Rename → `update`; add a track from an album via Add to Playlist ▸ → `add_playlist_tracks`; open the playlist, right-click a track › Remove from Playlist → confirm → `remove_playlist_tracks`; Delete… → confirm → the row goes. Export…/Import… use `-RoadieSaveTo`/`-RoadieOpenFiles` (M3U round trip through `PlaylistFile`).
- `dropOntoPlaylistAdds`: drag an album row onto a playlist row in the Playlists list → `add_playlist_tracks` with the album's tracks.
- `favorites`: right-click a track › Favorite → `music/favorites/add_item`; Favorites › Tracks lists it; `main` playing that track, ⌃⌘L (Favorite Current Track) → `remove_item` (toggle) or `add_item` per state.
- `discover`: the Discover section shows the recorded recommendation rows; Play All on a row → `play_media`; Show all rows toggles.
- `radio`: Radio lists the recorded stations; double-click → `play_media` with the radio URI; Add Radio URL… sheet → `music/radios/…` (check which command the app sends; the scripted server must know it: add to #0197's list if missing).
- `outputPicker`: `library.output` shows This Mac, Speakers (recorded names), Groups; toggle a second speaker → `players/cmd/set_members`; Only → leader alone; select This Mac → playback moves (`OutputMove`), the editor switches to the local queue.
- `thisMacPlaysMusicAssistant`: scenario `thisMacIsASendspinPlayer`, select This Mac, play an album → `play_media` targets the wrapper player; `probe.feed == musicAssistant`; the Sendspin stream is simulated by the stub (if `SendspinKit`'s stub can't feed audio, assert the feed and the rows only; note it).
- `quitSendsStop`: with the speaker playing, ⌘Q → `players/cmd/stop` is the last request (`QuitStop`), the app exits. (Read `maRequests` right before quitting won't show it; the scripted server writes `received.log` into `ROADIE_TEST_DATA` on every command; the test reads the file after `app.wait(for: .notRunning)`. Add that log to #0197's server if absent.)
- `badTokenShowsTheReason`: scenario `badToken` → Settings › Music Assistant shows the auth failure reason (`ma.reason`), the Library falls back or shows Retry.

**`testOutputPicker` hypothesis:** the run-3 screenshot shows the popover open, but every speaker row reads "user", not the `players-all.json` names.
