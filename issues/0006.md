## Description

Let the user open or drag in local audio files and folders; they go into the same queue as Plex tracks.

## Acceptance criteria

- Open panel and drag-and-drop on the player window accept audio files and folders.
- Metadata (title, artist, duration, bitrate, sample rate, channels) is read with AVFoundation.
- Unsupported files are skipped with a warning, never a crash.

### 1. AudioCore: `LocalTrackLoader`

New file `Packages/PlayerKit/Sources/AudioCore/LocalTrackLoader.swift` (`import AVFoundation`, `import UniformTypeIdentifiers`, `import os`). No AppKit, no UI. Everything is `nonisolated`/`Sendable` so it runs off the main actor under Swift 6 strict concurrency.

```swift
public struct SkippedFile: Sendable { public let url: URL; public let reason: String }
public struct LocalImport: Sendable { public var tracks: [Track]; public var skipped: [SkippedFile] }

public enum LocalTrackLoader {
    public static let audioTypes: [UTType]            // for NSOpenPanel.allowedContentTypes
    public static func isAudio(_ url: URL) -> Bool
    public static func collectAudioURLs(from urls: [URL]) -> [URL]   // sync, expands folders
    public static func load(_ urls: [URL]) async -> LocalImport      // never throws
    public static func loadTrack(at url: URL) async throws -> Track  // one file
}
```

**Which files count as audio.** `isAudio` reads `url.resourceValues(forKeys: [.contentTypeKey]).contentType` and returns true when it `conforms(to: .audio)`. Fall back to `UTType(filenameExtension:)` when the resource value is unavailable. `audioTypes` = `[.audio, .mp3, .mpeg4Audio, .wav, .aiff, UTType(filenameExtension: "flac")]` (compact nils). `.audio` is the parent of mp3, m4a, aac, wav, aiff, caf and flac on macOS 14, so the explicit entries are only there for clarity. Playlists (`.m3u`), images, `.txt`, `.nfo`, `.cue` do not conform to `.audio` and are ignored.

**Folder enumeration and order.** `collectAudioURLs` preserves the order of the input URLs as given (open-panel / drop order). For each input: if it is a regular file, keep it (regardless of type; the type check happens in `load`, so an explicitly chosen non-audio file is *reported* as skipped). If it is a directory, walk it recursively with a helper that, per directory, lists `contentsOfDirectory(at:includingPropertiesForKeys: [.isRegularFileKey, .isDirectoryKey, .contentTypeKey], options: [.skipsHiddenFiles, .skipsPackageDescendants])`, sorts the names with `localizedStandardCompare` (Finder order, so `2 Two` precedes `10 Ten`), emits the audio **files first**, then recurses into the **subdirectories** in sorted order. That gives disc-1 tracks in the album root before a `Disc 2/` subfolder. Non-audio files inside folders are dropped silently (no warning; a folder full of cover art would otherwise spam the log). Do not follow symlinked directories (`contentsOfDirectory` does not by default; leave it). Hidden and AppleDouble (`._foo.mp3`) files are excluded by `.skipsHiddenFiles`.

**Loading one track (`loadTrack`).**

1. `let file = try AVAudioFile(forReading: url)`. This is the decisive check: the AudioCore graph plays through `AVAudioFile`, so if it cannot open the file, the player cannot play it, and the file is skipped. Take `sampleRate = file.fileFormat.sampleRate`, `channels = Int(file.fileFormat.channelCount)`, and `fileDuration = Double(file.length) / file.fileFormat.sampleRate` (fallback duration). `AVAudioFile` is a local and is not `Sendable`; do not let it escape the function.
2. `let asset = AVURLAsset(url: url)`; `let (cmDuration, common) = try await asset.load(.duration, .commonMetadata)`. Wrap this in its own `do/catch`: if it throws, the file still becomes a track using the fallbacks below (an MP3 with odd tags should still play).
3. Title: `AVMetadataItem.metadataItems(from: common, filteredByIdentifier: .commonIdentifierTitle).first`, then `try await item.load(.stringValue)`; trim whitespace; if nil or empty, fall back to `url.deletingPathExtension().lastPathComponent`. Artist: same with `.commonIdentifierArtist`, nil when absent.
4. Duration: `CMTimeGetSeconds(cmDuration)` if `cmDuration.isNumeric && > 0`, else `fileDuration`.
5. Bitrate (kbps): `let tracks = try await asset.loadTracks(withMediaType: .audio)`; `let rate = try await tracks.first?.load(.estimatedDataRate)` (bits/s); if finite and > 0, `Int((rate / 1000).rounded())`. Otherwise estimate from file size: `fileSize * 8 / duration / 1000` using `.fileSizeKey`. For lossless files this yields e.g. 1411 for CD WAV, which is what Winamp shows.
6. Return `Track(id: UUID(), title:, artist:, duration:, bitrate:, sampleRate:, channels:, source: .file(url))`.

**`load(_:)` never throws.** It calls `collectAudioURLs`, then for each URL: if the URL is a regular file that is not audio → `skipped` with reason "not an audio file"; if it does not exist → "file not found"; else `do { try await loadTrack } catch { skipped.append(reason: error.localizedDescription) }`. Each skip logs `logger.warning("Skipping \(url.lastPathComponent, privacy: .public): \(reason, privacy: .public)")` with `private static let logger = Logger(subsystem: "com.brennanmke.SkinAmp", category: "LocalTrackLoader")`. Load files with a `withTaskGroup` capped at 4 concurrent `loadTrack` calls, keyed by index, and reassemble results in input order; sequential is acceptable as a first cut if the task group complicates things, but note it in `## Fix`. Log one `info` line at the end with counts.

### 2. App side

**`PlayerModel`** (`App/PlayerModel.swift`):

- `func importLocalFiles(_ urls: [URL], replace: Bool)`: spawns a `Task`, `let result = await LocalTrackLoader.load(urls)`, then on the main actor: `replace ? queue.replace(with: result.tracks) : queue.append(contentsOf: result.tracks)`. If `replace`, or if the player was stopped and the queue was empty before the append, start playing the first new track (Winamp behavior: Open plays immediately; drop onto an idle player also plays). Set `errorMessage` to "Skipped N file(s) — see Console" when `result.skipped` is non-empty and `result.tracks` is empty; otherwise just log.
- `@MainActor func openAudioFiles(replace: Bool)`: `NSOpenPanel()` with `canChooseFiles = true`, `canChooseDirectories = true`, `allowsMultipleSelection = true`, `allowedContentTypes = LocalTrackLoader.audioTypes`, `message` "Choose audio files or folders", `prompt` "Open" / "Add". `let response = await panel.begin()`; on `.OK`, `importLocalFiles(panel.urls, replace: replace)`. Because `ENABLE_APP_SANDBOX` is `NO`, the returned URLs are directly readable — no security-scoped bookmarks.
- `eject()` currently opens the skin importer. Winamp's eject button opens the file dialog, so change it to `openAudioFiles(replace: true)` and leave skin loading on its own menu command (`isImporting` stays for the skin `fileImporter`).

**Menu** (`App/SkinAmpApp.swift`, inside `CommandGroup(replacing: .newItem)`):

- `Open…` ⌘O → `model.openAudioFiles(replace: true)`
- `Add to Playlist…` ⌥⌘O → `model.openAudioFiles(replace: false)`
- `Open Skin…` ⇧⌘O → `model.isImporting = true` (was ⌘O; update the placeholder text in `PlayerView` that mentions "File › Open Skin…" if the shortcut is shown anywhere)

**Drop** (`App/PlayerView.swift`): extend the existing `.dropDestination(for: URL.self)` so it partitions the dropped URLs: the first `.wsz` loads the skin (current behavior); every other URL goes to `model.importLocalFiles(others, replace: false)`. Return `true` if either list was non-empty. Dropping files or folders from Finder yields file URLs for both files and directories, and the loader does the filtering. If a Finder folder drop does not arrive through `dropDestination(for: URL.self)` in testing, add a fallback `.onDrop(of: [.fileURL], isTargeted: nil)` that reads `NSItemProvider.loadItem(forTypeIdentifier: UTType.fileURL.identifier)` and decodes the `Data` as a URL.

**Append vs replace semantics (summary):** Open… and the eject button replace the queue and start playback; Add to Playlist… and drag-and-drop append, and only start playback if the player was idle with an empty queue. Dropping the same folder twice produces duplicate entries, as in Winamp.

uses `AVAudioFile(forWriting: url, settings: [AVFormatIDKey: kAudioFormatLinearPCM, AVSampleRateKey: sampleRate, AVNumberOfChannelsKey: channels, AVLinearPCMBitDepthKey: 16])`, fills an `AVAudioPCMBuffer(pcmFormat: file.processingFormat, frameCapacity: n)` with a low-amplitude sine (not all zeros), sets `frameLength = n`, and `file.write(from:)`. ### 6. Risks

- **#0002 shape.** `Track`'s field names, the queue API, and whether `PlayerModel` can start playback are all assumptions; adapt rather than fight them, and record divergences in `## Fix`.
- **Swift 6 concurrency.** `AVURLAsset`, `AVAudioFile` and `AVMetadataItem` are not `Sendable`; keep them local to `loadTrack` and return only `Track`. The task group must only pass `URL` in and `Track`/`SkippedFile` out.
- **Large folders.** Thousands of files take seconds to load; the loader is off-main so the UI stays responsive, but there is no progress UI in scope. The 4-way task group keeps it tolerable.
- **FLAC metadata.** `AVAudioFile` reads FLAC, but `AVURLAsset` may not expose Vorbis comments in `.commonMetadata`; such files still load with filename titles. Acceptable for M1.
- **Bitrate accuracy.** `estimatedDataRate` is an average for VBR MP3s; the file-size fallback is coarser still. Both are display-only.
- **Finder folder drops.** `dropDestination(for: URL.self)` should receive folder URLs; the `onDrop` fallback is the escape hatch if it does not.
- **Sandbox later.** The code relies on `ENABLE_APP_SANDBOX: NO`. If the app is sandboxed, open-panel and drop URLs need `startAccessingSecurityScopedResource` and bookmarks to survive relaunch.
- **Shortcut change.** Moving `Open Skin…` off ⌘O is a small behavior change; it is called out so the reviewer does not read it as accidental.

> 🟢 Resolved 2026-10-12 — `LocalTrackLoader` imports files and folders (recursive, Finder order, AVAudioFile as the playable check, AVFoundation metadata, skips logged never fatal), wired to Open / Add to Playlist / eject and window drops; reviewed against fc7a5ce.

Reviewer (Opus) findings:

- Independently re-ran: `swift test --package-path Packages/PlayerKit` twice, both `Test run with 67 tests in 17 suites passed`, `LocalTrackLoaderTests` passed and the real-time `mixedFormatsAdvanceWithoutGapRealtime` / `seekInResampledFileKeepsFileTime` ran and passed; SkinKit `5 tests in 1 suite passed`; `xcodegen generate` + `xcodebuild ... build` `** BUILD SUCCEEDED **` with no warnings or errors; the built app launched, stayed up, and quit via AppleScript with no crash report.
- Folder drops: the skipped `onDrop(of: [.fileURL])` fallback is not needed. Experiment in the scratchpad: writing a folder `NSURL` to an `NSPasteboard` (what Finder does) yields only `public.file-url`, and `NSItemProvider.loadTransferable(type: URL.self)` decodes it to the folder URL, both for `NSItemProvider(object:)` and for a provider built from the pasteboard item's data. `URL`'s Transferable imports `public.file-url` for directories exactly as for files, so `dropDestination(for: URL.self)` receives folder URLs.
- Symlink cycles cannot recurse: an experiment showed `contentsOfDirectory` entries that are symlinks to directories report `isDirectoryKey == false` (resource values do not follow the last component), and their content type is a symlink, not audio, so the walker drops them. Side effect: symlinked audio files inside folders are skipped silently, and a symlinked folder passed explicitly is reported "skipped" by AVAudioFile. Finder aliases inside folders are dropped silently; the open panel resolves aliases itself. Acceptable for M1.
- `load` runs on the global executor (no `NonisolatedNonsendingByDefault` in PlayerKit), so the synchronous folder walk stays off the main actor. Only `URL` goes into the 4-wide task group and only `Track` / `Error` comes out; `AVAudioFile` and `AVURLAsset` stay local. Results are reassembled by index (test `inputOrderIsPreserved`). Memory for very large folders is one `[URL]` plus results; no progress UI (in plan risks).
- Logging uses `lastPathComponent` as `.public`, not full paths, as the plan specified.
- App: Open and eject replace and play, Add to Playlist and drops append and play only when idle with an empty queue. The drop partitions the first `.wsz` as a skin and imports everything else (additional `.wsz` are ignored). Open Skin… moved to Shift-Cmd-O; the placeholder text names the menu item, not the shortcut, so it is still accurate. #0002's temporary `playFiles` path is removed.
- Gap, follow-up rather than a bounce: the "Skipped N file(s)" message only appears in the no-skin placeholder, so with a skin loaded an all-unsupported drop gives no visible feedback beyond the Console warning (which meets the acceptance criterion), and the message is not cleared by a later successful import. A status/marquee message belongs with the playlist UI.

To confirm by the user before closing:

1. Cmd-O on a folder with subfolders and a stray `.txt`: the queue fills in Finder order (root files before `Disc 2/`), playback starts; folders are selectable in the panel.
2. Opt-Cmd-O and the eject button: Add appends without interrupting playback; eject opens the panel and replaces.

4. Drag a `.wsz` onto the window: the skin still loads. Shift-Cmd-O opens the skin importer.

## Root cause

There was no way to get local audio into the queue except a temporary smoke path from #0002 (`PlayerModel.playFiles`, file-extension filter, no folders, no metadata, no open panel).

## Fix

- New `LocalTrackLoader` (`Packages/PlayerKit/Sources/AudioCore/LocalTrackLoader.swift`) as planned: `audioTypes`, `isAudio`, `collectAudioURLs`, `load`, `loadTrack`, plus `SkippedFile` / `LocalImport`. Folders are walked recursively in `localizedStandardCompare` order, audio files first then subfolders; hidden files and non-audio files inside folders are dropped silently; explicit non-audio files and missing files are reported as skipped. `AVAudioFile(forReading:)` is the playable check; metadata comes from `AVURLAsset` (failure there still yields a track from fallbacks). Loading runs in a task group capped at 4 and is reassembled in input order. Each skip logs an `os.Logger` warning (subsystem `com.brennanmke.SkinAmp`, category `LocalTrackLoader`).
- App: `PlayerModel.openAudioFiles(replace:)` (NSOpenPanel, files and folders, multiple), `importLocalFiles(_:replace:)`, `eject()` now opens the panel. Menu: Open... Cmd-O, Add to Playlist... Opt-Cmd-O, Open Skin... Shift-Cmd-O. The window drop partitions `.wsz` (first one loads as a skin) from everything else (appended). The temporary `playFiles` is removed.
- Deviations from the plan (adapted to the landed APIs): `Track.artist` is a non-optional `String`, so a missing artist is `""` not nil. The queue is owned by `Player`; replace is `player.clearQueue()` + `enqueue` + `play(at:)`, append is `enqueue`, and playback starts on append only if the player was stopped with an empty queue. The `onDrop(of: [.fileURL])` fallback was not added since a Finder folder drop could not be exercised here. The error message "Skipped N file(s) - see Console" is set only when nothing loaded; it shows in the no-skin placeholder only.
