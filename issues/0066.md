## Description

Local playback mode (doc section 5.2, mode 2): register SkinAmp as a **Sendspin** player so MA streams to the Mac, in sync with HomePods when grouped. MA cannot AirPlay to a Mac.

## Acceptance criteria

- A smoke test first: `sendspin-cli -n test` on the Mac shows up as a player in MA. Record the result.
- SkinAmp registers as a Sendspin player (paired with the server), receives the stream and plays it through the existing output path, with the EQ and analyzer working.
- Grouped with a HomePod in MA, playback stays in sync.

**Design in one paragraph** (sources and probe in [docs/sendspin-notes.md](../docs/sendspin-notes.md)): SkinAmp connects to `ws(s)://<MA API host:port>/sendspin`, authenticates with the MA token it already stores (`{"type":"auth","token","client_id"}` → `auth_ok`), and speaks the legacy unencrypted Sendspin wire that MA 2.10.6 (aiosendspin 9.1.1) and MA dev (aiosendspin 10.x) accept by default, exactly as MA's own desktop app does. It advertises one format (PCM, 16-bit, stereo, the output's rate) so the server resamples; audio chunks carry server-time stamps that a port of Sendspin's time-filter maps to host time; AudioCore schedules them on the existing player node, so the EQ, balance and visualizer apply as for files. MA wraps the client in a `universal_player` (named `SkinAmp (<computer name>)`), which SkinAmp finds by its `output_protocols` and targets when Music Assistant content is played on This Mac. No pairing, no port 8927, no C++. ("Paired with the server" in the criteria is met by the token-authenticated proxy: Sendspin's own pairing belongs to the encrypted wire, which MA does not require for this path. If MA ever drops its "allow legacy clients" setting, MA's desktop app breaks the same day; the follow-up then is a Noise `KKpsk2` client over the same proxy (MA 2.10.6 auto-approves an encrypted client that advertises unpaired access; a pairing token `SP:0…` pasted into MA's player settings is the paired route), with `SendspinWire` as the seam.)

**Done when** all five children are resolved, the milestone-style `scripts/verify.sh --full --head` passes, and the user has run the manual acceptance in #0109 (play on This Mac with EQ and visualizer, local file preempts, grouped with a HomePod in sync). Record the user's result here; only the user closes this issue.
