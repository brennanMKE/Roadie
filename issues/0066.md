## Description

Local playback mode (doc section 5.2, mode 2): register SkinAmp as a **Sendspin** player so MA streams to the Mac, in sync with HomePods when grouped. MA cannot AirPlay to a Mac.

## Acceptance criteria

- A smoke test first: `sendspin-cli -n test` on the Mac shows up as a player in MA. Record the result.
- SkinAmp registers as a Sendspin player (paired with the server), receives the stream and plays it through the existing output path, with the EQ and analyzer working.
- Grouped with a HomePod in MA, playback stays in sync.

## Notes

No Swift Sendspin SDK exists: wrap `sendspin-cpp` (Apache 2.0) through Swift C++ interop, or port the client from the spec plus `time-filter`. Sendspin is a technical preview, audio is 16-bit, and the protocol may change. A separate milestone-sized piece; do it after #0060–#0065 are solid. Tests must stay silent (see `docs/testing-in-vm.md`).
