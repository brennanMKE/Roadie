## Description

M14 work item W2 from [docs/design/release.md](../docs/design/release.md). Depends on: W1.

## Expected behavior

Bundle ids `co.sstools.roadie`, `.thumbnail`, `.preview`; UTIs `co.sstools.roadie.wsz` / `.media-id` (old `.wsz` UTI still accepted for a transition); Keychain service, Logger subsystems, queue labels and App Support paths on the new id; migration wired first in `PlayerModel.init`. `check-info-plist.sh`/`check-quicklook.sh` updated; new `check-identifiers.sh` allows `com.brennanmke` only in legacy constants.

## Root cause

The app still carried SkinAmp's identity: bundle ids under `com.brennanmke.SkinAmp`, the `com.brennanmke.skinamp.wsz` and
`.media-id` UTIs, the `com.brennanmke.SkinAmp.musicAssistant` Keychain service, and `com.brennanmke.SkinAmp` in Logger
subsystems, queue labels and App Support/Caches paths.

## Fix

- `project.yml`: `bundleIdPrefix: co.sstools`; bundle ids `co.sstools.roadie`, `co.sstools.roadie.thumbnail`,
  `co.sstools.roadie.preview`; the exported UTIs, document type and Quick Look content types are `co.sstools.roadie.wsz`
  and `co.sstools.roadie.media-id`. No transitional old UTI and no migration (scope change; #0152 won't fix).
- `App/Info.plist` and both Quick Look `Info.plist`s regenerated to match; `PlayerView.wsz` and
  `UTType.skinAmpMediaID` use the new UTIs.
- Keychain service `co.sstools.roadie.musicAssistant`; every Logger subsystem, queue label and App Support/Caches
  path or fallback is on `co.sstools.roadie`. Review caught two that were left: the `QueueSnapshot.defaultURL` fallback
  (`"SkinAmp"`) and `NowPlayingBridge`'s Logger subsystem (`"SkinAmp"`), fixed in 2434683.
- `check-info-plist.sh` and `check-quicklook.sh` pin the new UTIs and pluginkit ids; `TokenStoreTests` pins the new
  Keychain service.
- New `scripts/check-identifiers.sh` (VM step `identifiers`) fails on any `com.brennanmke` in App, Packages, QuickLook,
  scripts or project.yml except `LegacyDataCleanup.keychainService` (`com.brennanmke.SkinAmp.plex`).
- Product, target and file names stay SkinAmp until #0154; thread names, temp file names and UI strings are W4.
