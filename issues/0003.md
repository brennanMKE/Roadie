# 0003 — Tracks do not play back to back without a gap

| | |
|---|---|
| **Status** | open |
| **Module** | AudioCore |
| **Platform** | macOS |
| **First seen** | 2026-10-12 |

## Description

Schedule the next queued file on the player node before the current one ends so consecutive tracks play gaplessly.

## Acceptance criteria

- Current-track state advances when the scheduled buffer completes.
- Skipping or reordering the queue cancels the pre-scheduled file correctly.
