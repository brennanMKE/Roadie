## Description

To play Music Assistant audio on this Mac (#0066), SkinAmp has to be a Sendspin player: connect to the server, say hello, keep its clock in sync with the server's, report its state, and receive timed audio chunks and stream/volume commands. No Swift Sendspin client exists. This issue adds one as a new Foundation-only package target, `SendspinKit`, with no audio code: it hands decoded events and raw PCM chunks (with server timestamps) to whoever plays them (#0108).

The wire, the connection path and every message shape are in [docs/sendspin-notes.md](../docs/sendspin-notes.md), from the spec, aiosendspin 9.1.1 (what Music Assistant 2.10.6 runs) and a live probe (`scripts/probe-sendspin.py`, scrubbed frames in `docs/ma-protocol/sendspin-probe.json`).

## Resolution notes

> 🟢 Resolved 2026-10-19 — The new Foundation-only `SendspinKit` target speaks the legacy Sendspin wire through Music Assistant's authenticated `/sendspin` proxy (auth, hello, burst clock sync on a time-filter port, state, timed PCM chunks, stream and volume/mute commands, goodbye, reconnect with backoff), covered by 24 stub-transport tests.

## Root cause

SkinAmp had no Sendspin client, so Music Assistant could not stream audio to this Mac.

## Fix

Added the Foundation-only `SendspinKit` target as planned. It has the legacy-wire message models, the `SendspinWire` 9-byte audio parser, a port of `SendspinTimeFilter` (time-filter `main` 531e2707), burst clock sync, a `URLSessionWebSocketTask` transport, the configuration (token redacted), `SendspinIdentity`, and the `SendspinSession` actor with its `SendspinSessionDriving` seam. It also adds the `SendspinKitTests` test target, the `project.yml` scheme entry, and the fixture directory in `owned_files()` of `scripts/record-ma-fixtures.py`.

Divergences from the plan:
- **Initial convergence:** each burst feeds the filter only its best sample, and the convergence rule needs two accepted samples. So at connect the session runs bursts back to back until it converges (two bursts, 16 exchanges, a few ms on a LAN). After that it runs one burst every 10 s.
- **Session structure:** the session is one actor event loop over an inbox stream. Inputs are transport frames, deadline timers, `client/time` timeouts and burst ticks. Per-connection state lives in actor properties. The first try used captured locals, which Swift 6 region isolation rejected.
- **Timeouts and sleeps:** handshake and reply timeouts use the real clock. The injected `sleeper` is used only for reconnect backoff and the 10 s burst interval. The test `TestSleeper` returns at once for sleeps under 10 s and parks longer ones until cancelled.
- **Disconnect events:** `stop()` emits `.disconnected(nil)`. Unexpected disconnects emit `.disconnected(error)`.

## Gotchas

- `OSAllocatedUnfairLock.withLock` takes a `@Sendable` closure, so the test stubs are `@unchecked Sendable` classes.
- `SendspinTimeFilter.error` returns `Int64.max` before the first sample. The C++ rounds `sqrt(inf)`, which would trap in Swift.

## Plan

### Decisions (from the research)

- **Transport:** the authenticated proxy on the Music Assistant API port, path `/sendspin`, first frame `{"type":"auth","token":…,"client_id":…}` → `{"type":"auth_ok"}`. Same host and port as the API, authenticated with the token SkinAmp already stores; no port 8927, no pairing. This is what MA's own desktop app does.
- **Wire:** the legacy unencrypted wire (`client/hello` with `client_id` and `version: 1`, one legacy `server/hello`, 9-byte audio header). MA 2.10.6 and MA dev (aiosendspin 10.x) both accept it by default. Noise/`KKpsk2` (spec `main`) is out of scope; isolate the wire in `SendspinWire` so it can be added later.
- **Role:** `player@v1` only. **Codec:** `pcm` only, 16-bit, stereo, one sample rate supplied by the caller (the output rate), so the server resamples.
- **Clock:** a Swift port of Sendspin/time-filter (`main` 531e2707) with the burst strategy (8 sequential exchanges, keep the lowest `max_error`, every 10 s).
- **Client clock:** microseconds of `clock_gettime_nsec_np(CLOCK_UPTIME_RAW)`, the same base as `mach_absolute_time` and so as `AVAudioTime` host time (#0106 relies on that). Injected as `SendspinClock` so tests use a fake.

### Package wiring

`Packages/PlayerKit/Package.swift`: add product and target `SendspinKit` (no dependencies; Foundation only) and `.testTarget(name: "SendspinKitTests", dependencies: ["SendspinKit"], resources: [.copy("Fixtures")])`. Comment: "Sendspin player protocol client (#0066). Foundation only: no AudioCore, no MusicAssistantKit; the token and URL come in through `SendspinConnectionConfiguration`." `project.yml`: add `- package: PlayerKit/SendspinKitTests` to the test scheme list (next to `PlayerKit/MusicAssistantKitTests`); the app links the library in #0109.

### Files (all new, `Packages/PlayerKit/Sources/SendspinKit/`)

1. **`SendspinMessages.swift`** — `Codable`, `Sendable` models for the legacy wire, field names exactly as in `docs/sendspin-notes.md` sections 3 to 6 (snake_case `CodingKeys`):
   - Outgoing: `SendspinClientHello` (`clientID`, `name`, `version = 1`, `supportedRoles = ["player@v1"]`, `deviceInfo: SendspinDeviceInfo` (`productName`, `manufacturer`, `softwareVersion`), `playerSupport` keyed `"player@v1_support"`: `SendspinPlayerSupport` (`supportedFormats: [SendspinAudioFormat]`, `bufferCapacity`, `supportedCommands: ["volume","mute"]`)); `SendspinClientTime(clientTransmitted:)`; `SendspinClientState(available:, player: SendspinPlayerState)` with `SendspinPlayerState` (`volume` 0…100, `muted`, `staticDelayMs = 0`, `requiredLeadTimeMs`, `minBufferMs`, `supportedCommands: []`); `SendspinClientGoodbye(reason:)` with `SendspinGoodbyeReason` (`shutdown`, `restart`, `userRequest = "user_request"`, `anotherServer = "another_server"`).
   - Incoming: `SendspinServerHello` (`serverID`, `name`, `version`, `activeRoles`, `connectionReason`), `SendspinServerTime`, `SendspinStreamStart` (`serverTransmitted?`, `player: SendspinStreamFormat?` with `codec`, `sampleRate`, `channels`, `bitDepth`, `codecHeader?`), `SendspinStreamClear(roles?)`, `SendspinStreamEnd(roles?)`, `SendspinGroupUpdate` (`playbackState?`, `groupID?`, `groupName?`; all optional, as probed), `SendspinServerCommand(player: SendspinPlayerCommand?)` with `command` (`volume`, `mute`, `set_static_delay`, unknown kept as `.other(String)`), `volume?`, `mute?`, `staticDelayMs?`.
   - `enum SendspinIncoming { case serverHello, serverTime, streamStart, streamClear, streamEnd, groupUpdate, serverCommand, ignored(type: String) }` and `static func decode(_ text: String) throws -> SendspinIncoming`, dispatching on `"type"`; unknown types and unknown fields are ignored (spec forward-compatibility rule), malformed known types throw `SendspinError.malformed(type:)`.
   - Encoding: `SendspinOutgoing.encode(_:) -> String` wraps `{"type": …, "payload": …}` with sorted keys (stable for tests).
2. **`SendspinWire.swift`** — `enum SendspinWire { case legacy }` with `audioHeaderLength` (9) and `static func parseAudioChunk(_ data: Data, wire:) throws -> SendspinAudioChunk?`: byte 0 must be `4` (else returns nil: other binary types are ignored), bytes 1…8 big-endian `Int64` server µs, the rest is the payload (copied into its own `Data`). Too short → `SendspinError.malformed(type: "audio")`. `SendspinAudioChunk { serverMicros: Int64; payload: Data }`. A comment records the spec-`main` 13-byte layout (`send_ahead` UInt32 BE at bytes 9…12) for when an encrypted wire is added; do not implement it now.
3. **`SendspinTimeFilter.swift`** — `struct SendspinTimeFilter: Sendable` with `Config` (the eight defaults from the notes), `mutating func update(measurement: Int64, maxError: Int64, timeAdded: Int64)`, `func computeServerTime(_ client: Int64) -> Int64`, `func computeClientTime(_ server: Int64) -> Int64`, `var error: Int64` (rounded `sqrt(offsetCovariance)`), `var sampleCount: Int`, `mutating func reset()`. A line-for-line port of `cpp/sendspin_time_filter.cpp` (no mutex: callers own it). Keep the C++'s first-sample and second-sample special cases and the `use_drift` significance test.
4. **`SendspinClockSync.swift`** — `struct SendspinClockSample { t1, t2, t3, t4: Int64 }` with `measurement`, `maxError` (formulas in the notes); `struct SendspinClockBurst` collecting up to 8 samples and returning `best` (lowest positive `maxError`); `var isConverged: Bool` on the filter wrapper `SendspinClockState` (true once at least two samples were accepted and one burst finished). `public protocol SendspinClock: Sendable { func nowMicros() -> Int64 }` and `SystemSendspinClock` (`CLOCK_UPTIME_RAW` µs).
5. **`SendspinTransport.swift`** — `public enum SendspinFrame: Sendable, Equatable { case text(String), binary(Data), closed(code: Int?, reason: String?) }`; `public protocol SendspinTransport: Sendable { func connect() async throws; func send(text: String) async throws; func receive() async throws -> SendspinFrame; func close(code: Int) async }` and `SendspinTransportFactory { func makeTransport(url: URL) -> any SendspinTransport }`. `URLSessionSendspinTransport` on `URLSessionWebSocketTask`: `.data` frames become `.binary` (unlike `MAWebSocketTransport`, which turns data into text), `maximumMessageSize` raised to 4 MiB, scheme mapping http→ws, https→wss, path = base path + `/sendspin`. Close code and reason come from `closeCode`/`closeReason`.
6. **`SendspinConnectionConfiguration.swift`** — `public struct SendspinConnectionConfiguration: Sendable { baseURL: URL; token: String (never logged, `CustomStringConvertible` redacts it like `MusicAssistantToken`); clientID: String; name: String; deviceInfo: SendspinDeviceInfo; format: SendspinAudioFormat; bufferCapacity: Int = 1_048_576; requiredLeadTimeMs: Int = 300; minBufferMs: Int = 150 }` and `func sendspinURL() -> URL` (`/sendspin` appended to any reverse-proxy prefix).
7. **`SendspinIdentity.swift`** — `public struct SendspinIdentity { clientID: String; name: String }` with `static func load(defaults: UserDefaults, hostName: String) -> SendspinIdentity`: the client id is `"skinamp-" + UUID().uuidString.lowercased()` created once and stored under `SendspinIdentity.clientIDKey` (`"sendspin.clientID"`); the name is `"SkinAmp (\(hostName))"`. The id is never reused for the encrypted wire later (MA's downgrade protection would refuse it); a future Noise client mints a new one.
8. **`SendspinSession.swift`** — `public protocol SendspinSessionDriving: Sendable { func events() async -> AsyncStream<SendspinEvent>; func start() async; func stop(reason: SendspinGoodbyeReason) async; func report(volume: Int, muted: Bool) async }` (the seam #0108's tests fake), and `public actor SendspinSession: SendspinSessionDriving`:
   - `init(configuration:, transports: any SendspinTransportFactory = URLSessionSendspinTransportFactory(), clock: any SendspinClock = SystemSendspinClock(), sleeper: any Clock<Duration> = ContinuousClock(), reconnect: SendspinReconnectPolicy = .standard)`.
   - `public func events() -> AsyncStream<SendspinEvent>` (one subscriber is enough; buffering `.unbounded` because audio must not be dropped by the stream itself).
   - `public enum SendspinEvent: Sendable { case connected(SendspinServerHello), synchronized, streamStarted(SendspinStreamFormat), audio(SendspinAudioChunk, localMicros: Int64), streamCleared, streamEnded, setVolume(Int), setMute(Bool), groupUpdated(SendspinGroupUpdate), disconnected(SendspinError?) }`.
   - `public func start()` runs the loop: connect → send auth frame (`{"type":"auth","token","client_id"}`, built in one place, never logged) → wait ≤10 s for `{"type":"auth_ok"}` (a close with code 4001 → `SendspinError.unauthorized(reason)` and **no** retry until `start()` is called again; anything else → `.handshake`) → send `client/hello` → wait ≤10 s for `server/hello` (`active_roles` must contain `player@v1`, else `.roleRejected`) → first clock burst (each `client/time` waits ≤2 s for its `server/time`, matched by `client_transmitted`) → send `client/state` with `available: true` once `isConverged` (all within the 5 s the server allows; if the burst is slow, send `available: false` at 4 s and `true` when converged) → receive loop. Bursts repeat every 10 s from a child task; replies are matched by `client_transmitted` inside the receive loop.
   - Time conversion: each `.audio` event carries `localMicros = filter.computeClientTime(chunk.serverMicros)` taken when the chunk arrives (chunks arrive at most a few seconds ahead, so a later filter update would move it by nanoseconds). Chunks arriving before convergence are dropped and counted (cannot happen in practice: the server sends audio only after `available: true`). `public func localMicros(forServer: Int64) -> Int64?` (nil until converged) stays for tests and diagnostics.
   - `public func report(volume: Int, muted: Bool)` sends `client/state` with the full player object (spec: every message carries `available` and the full role object). `public func setAvailable(_:)`.
   - `server/command` volume/mute → `.setVolume`/`.setMute` events (the consumer applies, then calls `report`). `set_static_delay` is not offered, so ignore it.
   - `public func stop(reason: SendspinGoodbyeReason = .shutdown)`: send `client/goodbye`, close 1000, end the loop, no reconnect.
   - Reconnect: on an unexpected close or network error, emit `.disconnected(error)`, then back off with `SendspinReconnectPolicy` (1, 2, 5, 10, 30 s cap, ±20 % jitter; copy `ReconnectPolicy`'s shape, which lives in MusicAssistantKit and must not be imported) and reconnect from the top, resetting the time filter (a new server process means a new clock).
   - Logging: `Logger(subsystem: "com.brennanmke.SkinAmp", category: "Sendspin")`; never the token, never the URL host (log `baseURL.scheme` and whether a path prefix exists only).
9. **`SendspinError.swift`** — `unauthorized(String?)`, `handshake(String)`, `roleRejected`, `malformed(type: String)`, `timeout(String)`, `transport(String)`; `Equatable`, `Sendable`, `LocalizedError` with short user texts (e.g. "Music Assistant refused the Sendspin connection (token)").

### Notes for the implementer

- Swift 6, strict concurrency: the session is an actor; the stub transport is `@unchecked Sendable` with an `OSAllocatedUnfairLock`, as the MA stub is.
- `URLSessionWebSocketTask` is not unit-tested here (no network in the VM); keep it thin.
- Do not import MusicAssistantKit: the app passes the URL and token in (#0109).
