## Description

Build the skinned playlist window from `pledit` sprites showing the queue in `pledit.txt` colors and font.

## Acceptance criteria

- Resizable in Winamp's fixed increments (confirm in Webamp).
- Reorder by drag, remove, select, double-click to play, current-track highlight.

## Plan

### Scope and decisions

A second borderless skinned window, the Playlist Editor, that shows the local player's queue (the "This Mac" output) in `pledit.bmp` sprites and `pledit.txt` colours, resizes in Winamp's 25x29 steps, and edits the queue: select (click, cmd-click, shift-click, all/none/invert), reorder by dragging rows, remove (selected, crop, all), double-click to play, files dropped in. Normal mode only: shade mode is #0031, docking and position/queue persistence are #0030. Status stays `open`; this plan writes no code.

Three layers, each pure where it can be, in this order:

1. **SkinKit**: `pledit.txt` parser and `Skin.playlistStyle`; `PlaylistLayout` (all geometry, in skin pixels, as `MainSliders` does for the main window); `PlaylistScroll` and `PlaylistText` (Webamp's scroll and text rules).
2. **AudioCore**: `PlayQueue.move(_:by:)`, `PlayQueue.remove(at: IndexSet)`, `PlayQueue.crop(keeping:)`, `Player.moveTracks`/`removeTracks`, and the pure `PlaylistSelection`.
3. **App**: `PlaylistModel` (binding + selection + scroll + size), `PlaylistWindowView` (SwiftUI, skin pixel coordinates, scaled like `PlayerView`), `PlaylistWindowController` (AppKit host built from #0025's `SkinWindow`/`SkinShapeView`/`TitleBarDragView`), and the `isPlaylistWindowOpen` wiring #0023 left open.

Reference sources (Webamp `master`, `packages/webamp/`, read from the scratchpad checkout; the citations below are to those files): `js/components/PlaylistWindow/index.tsx`, `TrackList.tsx`, `TrackCell.tsx`, `TrackTitle.tsx`, `PlaylistScrollBar.tsx`, `PlaylistResizeTarget.tsx`, `PlaylistMenu.tsx`, `AddMenu.tsx`, `RemoveMenu.tsx`, `SelectionMenu.tsx`, `MiscMenu.tsx`, `ListMenu.tsx`, `PlaylistActionArea.tsx`, `RunningTimeDisplay.tsx`, `PlaylistShade.tsx`; `js/components/ResizeTarget.tsx`, `VerticalSlider.tsx`, `MiniTime.tsx`; `css/playlist-window.css`; `js/skinSelectors.ts` (lines 64-152, sprite to element map); `js/skinSprites.ts` (`PLEDIT`, already ported to `SkinSprites.swift` lines 70-130); `js/skinParserUtils.ts` `getPlaylistStyle` (154-185); `js/selectors.ts` (`defaultPlaylistStyle` 553-559, `getNumberOfVisibleTracks` 254-264, `getOverflowTrackCount`, `getPlaylistScrollPosition`, `getScrollOffset`, `getVisibleTrackIds` 266-307, `getRunningTimeMessage` 145-152, `getWPixelSize` 471-480); `js/reducers/playlist.ts` (selection, `DRAG_SELECTED`, `REMOVE_TRACKS`); `js/actionCreators/playlist.ts` (`dragSelected` 109-137, `scrollNTracks` 68-79, `scrollPlaylistByDelta` 81-99, `cropPlaylist`, `removeSelectedTracks`, `removeAllTracks`); `js/utils.ts` (`moveSelected` 246-267, `percentToIndex` 160-164, `getTimeStr` 66-87); `js/trackUtils.ts` `trackName`; `js/constants.ts` (`WINDOW_RESIZE_SEGMENT_WIDTH = 25`, `WINDOW_RESIZE_SEGMENT_HEIGHT = 29`, `TRACK_HEIGHT = 13`, `WINDOW_WIDTH = 275`, `WINDOW_HEIGHT = 116`, `CHARACTER_WIDTH = 5`).

**`Parsers/PlaylistStyleParser.swift`** (new) and **`PlaylistStyle`** (public, in the same file):

```swift
public struct PlaylistStyle: Sendable, Hashable {
    public var normal: RGBColor             // text
    public var current: RGBColor            // text of the playing row
    public var normalBackground: RGBColor   // list background
    public var selectedBackground: RGBColor // selected rows
    /// Windows font name from pledit.txt, e.g. "Arial", "Tempus Sans ITC". The App maps it to an NSFont.
    public var font: String
    /// Webamp selectors.ts defaultPlaylistStyle: #00FF00, #FFFFFF, #000000, #0000C6, Arial.
    public static let defaults: PlaylistStyle
}

enum PlaylistStyleParser {
    /// Port of Webamp getPlaylistStyle: the `[Text]` section of pledit.txt over the defaults, key by key.
    static func parse(_ data: Data) -> (style: PlaylistStyle, fallbacks: [String])
    static func parse(text: String) -> (style: PlaylistStyle, fallbacks: [String])
}
```

Rules (skinParserUtils.ts 154-185): decode as UTF-8 like `RegionParser` (`String(decoding:as:)`); `IniParser.parse(text)["text"]` (IniParser lowercases sections and keys, trims, strips one pair of quotes, so `Normal=#FEC910 ` reads as `normal` / `#FEC910`); no section or no file gives `.defaults`. For `normal`, `current`, `normalbg`, `selectedbg`: prefix `#` when missing, cut to 7 characters, then parse `#RRGGBB` as hex into `RGBColor`; a value that is not six hex digits (Webamp hands it to CSS, which drops it) falls back to that key's default and appends `"pledit.txt <key> '<value>' unusable; default"` to fallbacks. `font`: the trimmed value, `Arial` when absent or empty. `mbfg`/`mbbg` (menu bar colours) are parsed by Webamp but unused by it and by us: ignore. Missing file: fallback `"pledit.txt missing; Webamp default playlist colours"`. Never a warning (`sampleSkinsAreOk` asserts warnings empty).

**`Skin.swift`**: `public let playlistStyle: PlaylistStyle` with `init(..., playlistStyle: PlaylistStyle = .defaults, ...)`. **`SkinParser.swift`**: `archive.file("pledit", extensions: ["txt"])` through the parser, fallbacks appended, remove `pledit.txt` from the TODO comment. `SkinArchive` already matches base names case-insensitively inside subfolders.

### AudioCore (PlayerKit)

**`PlayQueue.swift`**:

- `public mutating func move(_ selected: Set<Int>, by offset: Int) -> Bool`: port of `moveSelected` (utils.ts 246-267) with `dragSelected`'s clamp (offset limited to `-first ... count-1-last`); returns false when nothing moved. Implemented as a permutation `newOrder: [Int]` (new position -> old index); `tracks` is reordered and `currentIndex`, `shuffleOrder`, `nextPass` are remapped through the inverse map, so the current track keeps its identity and the shuffle bookkeeping stays a permutation of `tracks.indices`. `shufflePosition` is unchanged (it indexes `shuffleOrder`, whose entries are remapped in place).
- `public mutating func remove(at indices: IndexSet)`: calls the existing `remove(at:)` from the highest index down, so the shuffle bookkeeping and current-index rules are reused.
- `public mutating func crop(keeping: Set<Int>)`: `remove(at: IndexSet(indices not in keeping))`.

**`Player.swift`**: `public func moveTracks(_ selected: Set<Int>, by offset: Int)` (queue move, then `reconcileSchedule()`, because the pre-scheduled next file may now be wrong) and `public func removeTracks(at indices: IndexSet)`: compute `removingCurrent` once, set `currentTime = 0` before the queue change when it is removed (as `removeTrack(at:)` does), mutate the queue in one go, then apply `removeTrack(at:)`'s transport rule once (restart on the new current with the same play/pause intent, or `stop()` when the queue emptied; else `reconcileSchedule()`). Do not loop `removeTrack(at:)`, which would start and kill tracks for every index.

### App

**`App/Playlist/PlaylistModel.swift`** (new, `@MainActor @Observable`): owned by `PlayerModel` as `let playlist: PlaylistModel`, created with `PlaylistModel(player: stack.player)`.

- State: `selection: PlaylistSelection`, `scrollPosition: Double` (0...100), `steps: PlaylistLayout.Steps` (persisted under `playlistWindowSize` as `[Int]`, default `[0, 0]`), `openMenu: PlaylistLayout.Menu?`, `isDraggingScroll`, `isPressingClose/Shade`.
- Binding: the window is a view of `player.queue` (`Player` is `@Observable`; `PlayerModel` already reads `player.queue` for the marquee number and status). `rows` are built from `player.queue.tracks` over the visible range only (`PlaylistScroll.visibleRange`), so a 10,000-track queue renders a dozen `Text`s. `currentIndex = player.queue.currentIndex`. `MusicBackend` has no queue read API (#0062 scoped it out), so for a non-local `selectedOutput` the list is empty and the running time blank; a remote queue is a later backend addition, not this issue. `PlayerModel.selectedOutput` is read through a weak back-reference or passed in; simplest: `PlaylistModel` takes an `isLocal: () -> Bool` closure from `PlayerModel`.
- Edits call `Player` directly: `playRow(_:)` -> `player.play(at:)`; `removeSelected()`, `crop()`, `removeAll()` (-> `player.clearQueue()`, which also stops, like Webamp's `removeAllTracks`), `dragSelected(by:)` -> `player.moveTracks`. They do not go through `TransportCommand`: the serial command stream exists for transport ordering, and the queue is only reachable locally anyway.
- Scrolling: `scroll(by rows: Int)`, `wheel(deltaY:)` (points / scale, so the skin-pixel rule holds at 2x), `setScrollValue(_:)` from the handle; `scrollPosition` is clamped whenever the queue shrinks.
- `runningTimeText` (selected over total, durations of unknown tracks count 0, selectors.ts 128-152), `miniTimeDigits` (from `player.currentTime`, `player.queue.current?.duration`, `PlayerModel.timeMode`; blank when stopped), `toggleTimeMode` forwards to `PlayerModel`.
- Files: `add(urls:)` -> `PlayerModel.open(urls, replace: false)` (appends; a dropped `.wsz` loads as the skin, like the main window). Webamp inserts at the drop row (index.tsx `handleDrop`); appending is accepted here and noted as a follow-up (`PlayQueue.insert(_:at:)` would need the same permutation remap as `move`).

### Risks and open questions

- **SwiftUI drag + modifier keys**: `DragGesture` has no modifier flags; reading `NSEvent.modifierFlags` at the first change works on macOS but is a side channel. If the row gestures fight (double-click swallowed by the drag, or the drag starting on click), replace `PlaylistTrackListView`'s gesture layer with a small `NSView` (`mouseDown` with `clickCount`/`modifierFlags`, `mouseDragged`, `mouseUp`) hosted by `NSViewRepresentable`, keeping the SwiftUI drawing. The pure model is unaffected.
- **Text at 2x**: `scaleEffect(2)` on `Text` may render soft or blocky; Webamp's doubled mode is a CSS transform too. If it looks wrong, draw rows into a `CGContext` at `scale` (as `VisRenderer` does for the vis) instead of scaled `Text`.
- **Fonts**: Windows names are mapped by exact PostScript/family name; some skins name fonts with suffixes (`Arial Black`) that exist, others do not. Arial is the safe fallback; log nothing.
- **Row clipping**: Webamp computes `visibleRows` from 58 + 29h, not the padded 52 + 29h, so at h = 3 the last row is cut by 4 px. Faithful to Webamp; do not "fix" it.
- **Non-local outputs**: the window shows nothing for a remote output. Acceptable for now; a `MusicBackend.queue(on:)` stream is the eventual fix (#0062 left it out).
- **Queue persistence** is #0030; a relaunch starts with an empty list.
- **Insert at drop row**: appending instead of inserting at the row under the pointer; needs `PlayQueue.insert(_:at:)` with the same remap as `move`. Follow-up if wanted.
- **`Player.removeTracks` while loading**: the transport rule copies `removeTrack(at:)`; the loading test above guards it. `reconcileSchedule()` after a move may restart the current file from its current frame when the scheduled next no longer follows; that is the existing `.restartCurrent` branch and is gapless-safe.
- **Menu click-away**: a press on the title bar drag view (AppKit) does not reach SwiftUI; close the menu from `PlaylistWindowController.dragBegan()` and on `windowDidResignKey` as well as from SwiftUI presses.

- `BlinkingView` (main window status) is no longer private so the mini time reuses it.
- Failure skipping (#0068) and notices (#0045) needed no change: `removeTracks` mirrors `removeTrack(at:)`'s transport rule.
