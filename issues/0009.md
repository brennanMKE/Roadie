## Description

Add a `PlexKit` library: async `URLSession` client with `Accept: application/json`, `X-Plex-Token` header, a stable `X-Plex-Client-Identifier`, paging headers, and Codable models for sections, artists, albums, tracks, media and parts.

## Acceptance criteria

- Endpoints from `docs/plex-music-library.md`: `/identity`, `/library/sections`, `type=8/9/10`, `/children`, `title=` search. Section id is never hard-coded.
- Paging uses `X-Plex-Container-Start` / `-Size` and reads `totalSize`.
- Tests use a `URLProtocol` stub with JSON fixtures recorded from joe (token stripped).
- Opt-in integration test runs when `PLEX_URL` and `PLEX_TOKEN` are set.
- The token never appears in logs or error messages.

## Plan

### Scope and decisions

This issue delivers the Plex HTTP layer only: models, a client, paging, errors, a `URLProtocol` stub with recorded fixtures, and an opt-in integration test. It does **not** implement address normalization or the three-step connection test (#0010), the Keychain store or Settings UI (#0011), ATS / Local Network keys (#0012), downloads and the cache (#0013), or the plex.tv PIN flow and `/resources` (#0014). The seams those need are listed at the end.

- **A separate package, `Packages/PlexKit`**, not a target inside `Packages/PlayerKit` as `docs/plan.md` and the module table in `Issues.md` currently say. PlexKit is Foundation-only (no AVFoundation, no AudioCore, no UI), so it gets its own `swift test` step that has no audio or real-time tests in it, and #0013's `TrackCache` can depend on both PlexKit and AudioCore without a cycle. Update the two docs in the code commit: the `PlexKit` row in `Issues.md` → `(Packages/PlexKit)`, and the architecture block in `docs/plan.md` (`Packages/PlexKit/  Plex HTTP client, models, sign-in, connection test`). `TrackCache` stays listed under PlayerKit; #0013 decides where it actually lands.
- **Swift 6 language mode, strict concurrency.** `// swift-tools-version: 6.0`, `platforms: [.macOS(.v14)]`, Swift Testing, no `defaultIsolation: MainActor` (mirrors `Packages/PlayerKit/Package.swift`). Every public type is a `Sendable` value; the client is a `struct`.
- **Two library targets.** `PlexKit` (the product the app will link) and `PlexKitStub` (the `URLProtocol` stub plus the fixture JSON as `Bundle.module` resources). The stub is its own product because `docs/testing-in-vm.md` already plans to launch the app under UI tests with `-UITestStubPlex YES` and "the `URLProtocol` stub and recorded JSON fixtures from PlexKit's unit tests"; keeping it in a library, not the test target, is what makes that possible later. Nothing links `PlexKitStub` today except `PlexKitTests`.
- **The token is a type, not a string.** `PlexToken` wraps the string, is *not* `Codable`, and prints as `PlexToken(redacted)` from `description`, `debugDescription` and `customMirror`. The client only ever puts it in the `X-Plex-Token` header, never in a URL, so no `URLError`, `URLRequest.url` or log line can carry it.
- **Verification is the VM script.** `scripts/run-tests-vm.sh` gains a `plexkit-tests` step. The guest has no `PLEX_URL`/`PLEX_TOKEN`, so the integration test is skipped there by `.enabled(if:)`, which is the behaviour the ground rule "no secrets in the guest" requires. The integration test still compiles in the guest, so a signature drift fails the build, not just the opt-in run.

### 2. Models (`Sources/PlexKit/Models/`)

All `public struct … : Codable, Hashable, Sendable`, `Identifiable` where there is a `ratingKey`/`key`. Every field that Plex does not always send is optional; `Media`/`Part` arrays default to `[]` when absent (decode with `decodeIfPresent … ?? []`). Capitalized JSON keys (`MediaContainer`, `Metadata`, `Directory`, `Media`, `Part`, `Location`) get explicit `CodingKeys`. Field names below are Plex's; **confirm each against the recorded fixtures** before finalising — if a fixture shows a different type (for example an integer `ratingKey` on some server versions), follow the fixture and note it in `## Fix`.

### 3. Client (`PlexClient.swift`, `PlexEndpoints.swift`)

```swift
public struct PlexClient: Sendable {
    public let baseURL: URL                 // e.g. http://joe:32400 (#0010 normalises the user's text into this)
    public let token: PlexToken?            // nil is allowed: /identity needs none, and #0010's first check runs without one
    public let clientIdentifier: String     // stable UUID string, X-Plex-Client-Identifier
    public let product: String              // "SkinAmp"
    public let version: String              // app version string
    public let timeout: TimeInterval        // default 15 s; #0010 relies on a bounded "can't reach"
    public let session: URLSession          // default .shared; tests pass one whose configuration has protocolClasses = [StubURLProtocol.self]

    public init(baseURL: URL, token: PlexToken?, clientIdentifier: String,
                product: String = "SkinAmp", version: String = "0.1.0",
                timeout: TimeInterval = 15, session: URLSession = .shared)

    /// Builds a GET with every Plex header set. Public so #0013 can download a part with the
    /// same headers (token in the header, never in the URL) and #0010 can issue the identity check.
    public func request(path: String, query: [URLQueryItem] = [], page: PlexPageRequest? = nil) -> URLRequest
}

extension PlexClient {
    public func identity() async throws -> PlexIdentity                                   // GET /identity
    public func librarySections() async throws -> [PlexLibrarySection]                   // GET /library/sections (Directory)
    public func musicSections() async throws -> [PlexLibrarySection]                     // filter isMusic
    public func artists(in section: PlexLibrarySection.ID, page: PlexPageRequest = .first) async throws -> PlexPage<PlexArtist>   // /library/sections/<id>/all?type=8
    public func albums(in section: PlexLibrarySection.ID, page: PlexPageRequest = .first) async throws -> PlexPage<PlexAlbum>     // type=9
    public func tracks(in section: PlexLibrarySection.ID, page: PlexPageRequest = .first) async throws -> PlexPage<PlexTrack>     // type=10
    public func searchTracks(in section: PlexLibrarySection.ID, title: String, page: PlexPageRequest = .first) async throws -> PlexPage<PlexTrack>   // type=10&title=
    public func albums(of artist: PlexArtist.ID, page: PlexPageRequest = .first) async throws -> PlexPage<PlexAlbum>   // /library/metadata/<id>/children
    public func tracks(of album: PlexAlbum.ID, page: PlexPageRequest = .first) async throws -> PlexPage<PlexTrack>     // /library/metadata/<id>/children
}
```

Rules the implementation follows (each has a test in section 7):

- **Headers on every request:** `Accept: application/json`, `X-Plex-Client-Identifier`, `X-Plex-Product`, `X-Plex-Version`, `X-Plex-Platform: macOS`, and `X-Plex-Token` only when `token != nil`. The token goes in the header and nowhere else. `request(path:query:page:)` is the single place headers are set.
- **Paging headers** `X-Plex-Container-Start` and `X-Plex-Container-Size` are **both** sent on every list call (sending only `Size` is ignored by the server, per the Homelab notes). `identity()` and `librarySections()` send neither.
- **URL building:** `URLComponents` on `baseURL`, path appended with `appending(path:)` so a base with a path (a `plex.direct` URI never has one, but don't assume) still works; query items through `URLQueryItem` so `title=cowboys & aliens` is percent-encoded by Foundation. The section id in `/library/sections/<id>/all` is always the caller's argument; grep the package for `sections/5` in review — it must not appear outside fixtures.
- **Fetch pipeline** (one private generic `func fetch<T: Decodable>(_ request: URLRequest) async throws -> T`): `session.data(for:)` → wrap thrown `URLError` as `.transport(code)` → non-`HTTPURLResponse` is `.transport(.badServerResponse)` → status 401 → `.unauthorized`, 404 → `.notFound`, other non-2xx → `.httpStatus(Int)` → `Content-Type` not containing `json` → `.notJSON(contentType:)` → `JSONDecoder().decode` failure → `.decoding(path: String, detail: String)` where `detail` is the `DecodingError`'s own description (coding path and type), never the response body.
- **Logging:** `os.Logger(subsystem: "com.brennanmke.SkinAmp", category: "PlexKit")`. One `debug` line per request with method and path (`privacy: .public`), one `error` line per failure with the status or error case. Never log headers, the full `URLRequest`, or the response body.
- **Page result:** list calls return `PlexPage` built from the envelope: `items = metadata ?? directory ?? []`, `offset = body.offset ?? page.start`, `size = body.size ?? items.count`, `totalSize = body.totalSize ?? offset + size`.

### 4. Paging, token, identifier, errors

```swift
public struct PlexPageRequest: Hashable, Sendable {
    public var start: Int
    public var size: Int
    public init(start: Int = 0, size: Int = 100)
    public static let first = PlexPageRequest()
}

public struct PlexPage<Item: Hashable & Sendable>: Hashable, Sendable {
    public var items: [Item]
    public var offset: Int
    public var size: Int
    public var totalSize: Int
    public var hasMore: Bool { offset + items.count < totalSize }
    public var next: PlexPageRequest? { hasMore ? PlexPageRequest(start: offset + items.count, size: max(size, 1)) : nil }
}

extension PlexClient {
    /// Walks pages until `hasMore` is false. `limit` caps the total (default 10_000) so a server
    /// that keeps answering can't run the loop forever; a zero-item page also stops it.
    public func allItems<Item>(pageSize: Int = 200, limit: Int = 10_000,
                               _ fetch: (PlexPageRequest) async throws -> PlexPage<Item>) async throws -> [Item]
}
```

```swift
public struct PlexToken: Hashable, Sendable, CustomStringConvertible, CustomDebugStringConvertible, CustomReflectable {
    public let rawValue: String             // #0011's Keychain store reads this; nothing else should
    public init(_ rawValue: String)
    public var description: String { "PlexToken(redacted)" }
    public var debugDescription: String { description }
    public var customMirror: Mirror { Mirror(self, children: []) }   // `dump` prints nothing
}
// Deliberately NOT Codable: a token must not be able to ride along in a JSON index or a settings file.
```

```swift
public enum PlexClientIdentifier {
    public static let defaultsKey = "PlexClientIdentifier"
    /// Returns the stored identifier, creating and storing a UUID string on first use.
    /// Not a secret; UserDefaults is the right place. #0014's PIN flow uses the same value.
    public static func stored(in defaults: UserDefaults = .standard) -> String
}
```

```swift
public enum PlexError: Error, Hashable, Sendable, LocalizedError {
    case invalidBaseURL
    case transport(URLError.Code)           // no response at all (DNS, refused, timeout). #0010 maps this to "Can't reach the server…"
    case unauthorized                       // 401. #0010 maps to "Signed in, but this account can't access this server."
    case notFound                           // 404
    case httpStatus(Int)                    // any other non-2xx
    case notJSON(contentType: String?)      // the server ignored Accept (an HTML login page, a proxy)
    case decoding(path: String, detail: String)

    public var errorDescription: String? { … short English per case; none interpolates a request, header or body … }
}
```

`transport` carries only the `URLError.Code`, not the `URLError` (whose `userInfo` holds the failing URL and sometimes the request). The URL would not contain the token anyway, but a code is `Hashable`, `Sendable`, and keeps the error small.

### 5. Stub and fixtures (`Sources/PlexKitStub/`)

```swift
public final class StubURLProtocol: URLProtocol {
    public struct Route: Sendable {
        public var method: String = "GET"
        public var path: String                       // "/library/sections"
        public var query: [String: String] = [:]      // matched as a subset of the request's query items
        public var containerStart: Int? = nil         // matched against X-Plex-Container-Start when non-nil
        public var status: Int = 200
        public var headers: [String: String] = ["Content-Type": "application/json"]
        public var body: Data = Data()
        public var error: URLError? = nil             // when set, the load fails with it instead of responding
    }
    public struct RecordedRequest: Sendable { public var url: URL; public var method: String; public var headers: [String: String] }

    public static func register(_ routes: [Route])    // replaces the table
    public static func reset()                        // clears routes and recordings
    public static var recorded: [RecordedRequest]     // every request seen since reset
    public static func session() -> URLSession        // ephemeral configuration with protocolClasses = [Self.self]
}
```

The route table and the recordings are static (that is how `URLProtocol` works), guarded by `OSAllocatedUnfairLock<State>` so the class satisfies Swift 6 without `nonisolated(unsafe)`. An unmatched request answers 404 with an empty body and is still recorded, so a test that expects a route to be hit can assert on `recorded`. Matching: path equality, query subset, and the container-start header when the route sets one (that is how the two pages in `allItemsWalksPages` are distinguished).

### 6. Recording and scrubbing the fixtures (host, network only)

Done by the implementer on the host; it needs no build and never runs tests. Commit the recorder as `scripts/record-plex-fixtures.sh` so the fixtures can be refreshed later. The script:

1. Reads the token into a shell variable and never echoes it. It never writes the token anywhere: no file, no `set -x`, no log. Nothing in this script is to be pasted into an issue or commit message.
2. Records each fixture with `curl`, using the paging headers themselves to keep responses small (3 items each).
3. Pipes every response through a `jq` scrub.
4. Greps the result for the token and refuses to finish if it is found.

```sh
#!/bin/zsh
# Records PlexKit's test fixtures from the dev server and scrubs them. Host only.
set -euo pipefail
set +o xtrace
T=$(ssh joe 'defaults read com.plexapp.plexmediaserver PlexOnlineToken')
P="${PLEX_URL:-http://joe:32400}"
F="$(dirname "$0")/../Packages/PlexKit/Sources/PlexKitStub/Fixtures"
mkdir -p "$F"

SCRUB='
  (.. | objects | select(has("machineIdentifier")) | .machineIdentifier) |= "0123456789abcdef0123456789abcdef01234567"
  | (.. | objects | select(has("uuid")) | .uuid) |= "00000000-0000-0000-0000-000000000000"
  | (.. | objects | select(has("librarySectionUUID")) | .librarySectionUUID) |= "00000000-0000-0000-0000-000000000000"
  | (.. | objects | select(has("file")) | .file) |= "/Media/Music/scrubbed"
  | del(.. | objects | .Location?)
'

rec() {  # rec <name> <path> [start] [size] [extra curl args...]
  local name=$1 path=$2 start=${3:-0} size=${4:-3}; shift 4 2>/dev/null || shift $#
  curl -sfS -G -H "Accept: application/json" -H "X-Plex-Token: $T" \
       -H "X-Plex-Container-Start: $start" -H "X-Plex-Container-Size: $size" \
       "$@" "$P$path" | jq "$SCRUB" > "$F/$name.json"
}

rec identity /identity
rec sections /library/sections
SEC=$(jq -r '.MediaContainer.Directory[] | select(.type == "artist") | .key' "$F/sections.json" | head -1)
rec artists-page "/library/sections/$SEC/all" 0 3 --data-urlencode type=8
rec albums-page  "/library/sections/$SEC/all" 0 3 --data-urlencode type=9
rec tracks-page  "/library/sections/$SEC/all" 0 3 --data-urlencode type=10
TOTAL=$(jq '.MediaContainer.totalSize' "$F/tracks-page.json")
rec tracks-last-page "/library/sections/$SEC/all" $((TOTAL - 1)) 3 --data-urlencode type=10
ARTIST=$(jq -r '.MediaContainer.Metadata[0].ratingKey' "$F/artists-page.json")
rec artist-children "/library/metadata/$ARTIST/children" 0 3
ALBUM=$(jq -r '.MediaContainer.Metadata[0].ratingKey' "$F/artist-children.json")
rec album-children "/library/metadata/$ALBUM/children" 0 3
WORD=$(jq -r '.MediaContainer.Metadata[0].title | split(" ")[0]' "$F/tracks-page.json")
rec tracks-search "/library/sections/$SEC/all" 0 3 --data-urlencode type=10 --data-urlencode "title=$WORD"

# Scrub check: the token must not be in any fixture, and nothing may look like one.
if grep -rqF -- "$T" "$F"; then print -u2 "!! token found in fixtures -- NOT committing"; exit 1; fi
if grep -rqiE 'X-Plex-Token|authToken' "$F"; then print -u2 "!! token-like field in fixtures"; exit 1; fi
print "Recorded $(ls "$F" | wc -l | tr -d ' ') fixtures into $F ($(du -sh "$F" | cut -f1))"
```

Notes for the implementer:

- `rec`'s positional handling is sketched; make it robust (`start`/`size` default, then the remaining args pass to curl). Use `-G --data-urlencode` for query parameters so `title=` with spaces and `&` is encoded.
- `/identity` and `/library/sections` ignore the paging headers; harmless.
- The `tracks-search` word is derived from the first recorded track title; check the result has 1–3 items, and pick another word by hand if it is 0.
- After recording, read each fixture once by eye for anything that should not be committed (a person's email, a plex.tv username, an `authToken`, `myPlex*` fields, the home LAN IP). Section `Location` paths are removed by the scrub, `Part.file` is replaced, `machineIdentifier` and every `uuid` are placeholders. Titles and artist names from the music library are fine to commit; if any feel private, replace them by hand and keep the structure.
- Before the code commit, with the token still in `$T` in that shell: `git diff --cached | grep -cF -- "$T"` must print `0`, and `grep -rF -- "$T" Packages/ scripts/ docs/` must print nothing. Then `unset T`.
- Target size: well under 100 KB in total. A page of 3 tracks is about 5 KB.

### 7. Unit tests (`Tests/PlexKitTests/`, Swift Testing)

`ModelDecodingTests` (fixtures straight into `JSONDecoder`, no client):

1. `identityDecodes` — `machineIdentifier` is the placeholder, `version` non-empty.
2. `sectionsDecodeFromDirectoryAndMusicFilter` — all directories decode; exactly those with `type == "artist"` are `isMusic`; the music section's `key` is read from the fixture, not asserted as `"5"`.
3. `artistsPageDecodes` — 3 items, `totalSize >= 3`, `offset == 0`, each has `ratingKey`, `key` ending in `/children`, non-empty `title`.
4. `albumsPageDecodes` — `parentTitle`, `year`, `leafCount`, `thumb` decode when present; absent fields are `nil` not errors.
5. `tracksPageDecodesMediaAndParts` — each track has `media.count >= 1`, `media[0].parts.count >= 1`, `primaryPart?.key` starts with `/library/parts/`, `size != nil`, `durationSeconds` within 1 s of `media[0].duration / 1000`, `bitrate`/`audioChannels` present for at least one track, `keyStamp != nil`, `fileExtension` is `mp3` or `m4a`.

### 12. Risks

- **Fixture shapes vs. this plan.** The field list in section 2 is from memory of Plex's JSON, not from joe. The implementer treats the recorded fixtures as the truth: adjust optionality and types (string vs. integer `ratingKey`, presence of `offset`, whether `Part` carries `updatedAt`) and say so in `## Fix`. Making almost everything optional is the safety net.
- **`URLProtocol` under Swift 6.** `URLProtocol` subclasses are loaded by Foundation off the main actor; static state must be lock-protected (`OSAllocatedUnfairLock`), and `startLoading` must deliver the response and data through `client?.urlProtocol(…)` on the same thread it was called. Do not use `nonisolated(unsafe)` static vars. If `URLSession.data(for:)` with a protocol class behaves oddly in the guest's Xcode 27 toolchain, fall back to a hand-rolled `AsyncThrowingStream` of `(Data, URLResponse)` only inside the stub, not in the client.
- **Static stub table means serialized tests.** `PlexClientTests` is `.serialized`; model tests are not, and stay fast. If more suites need the stub later, key routes by an `X-Stub-Session` header the test adds — not needed now.
- **Trailing slash / path join.** `URL(string: "http://joe:32400/")` plus `appending(path: "library/sections")` versus `"/library/sections"`: write the join once, test it with both base forms (`http://joe:32400` and `http://joe:32400/`).
- **`Accept` is not honoured by every error path.** A 401 from Plex is XML/HTML. Map on status before checking `Content-Type`, so 401 is `.unauthorized` rather than `.notJSON`.
- **Plex's `title=` is word-prefix, not substring.** The client only forwards the parameter; the browser (M3) decides what to search. Document in the `searchTracks` doc comment so M3 doesn't assume substring.
- **The integration test cannot run in the pipeline.** The only environment with both network access to joe and the token is the host, where the project rule is "no `swift test`". The acceptance criterion is met by the test existing, skipping cleanly, and being documented; whether the implementation or review subagent may run it on the host (Foundation-only package, no audio, no GUI, so the two reasons for the VM rule do not apply) is an **open question for the orchestrator**. The default is: do not run it; leave it for the user, and say so in `## Verification`.
- **Shell history.** `T=$(ssh joe …)` puts only the command in history, not the token; never `echo $T`, never `set -x` while `T` is set, never paste a fixture into a chat or issue before the scrub check has passed.
- **Package location differs from the docs.** `Issues.md` and `docs/plan.md` say PlexKit lives in `Packages/PlayerKit`; this plan puts it in `Packages/PlexKit` and edits both docs in the code commit. If the orchestrator prefers the original layout, the only changes are the package path in `project.yml` and the script's step (`swift test --package-path Packages/PlayerKit` already runs there), and `PlexKitStub` becomes a target of PlayerKit.
