## Description

Jump to File (`J`, ⌘J) was one of the two places the user saw the wrong track play (#0187) and the place they saw an empty list (#0190). Nothing drives it. This issue adds `JumpToFileUITests` on the local queue (the Music Assistant case is one test in #0206), covering [docs/design/test-automation.md](../docs/design/test-automation.md) §5.6.

## Plan

Launch as #0203 does (folder library, 9 fixture tracks, playlist open).

### `Tests/RoadieUITests/JumpToFileUITests.swift`

- `opensWithJAndCommandJ`: with the main window key, `typeKey("j")` → `jump.search` exists and has keyboard focus (`hasFocus`), `jump.row.0…8` list every queue row in order; Esc closes (`jump.search` gone). ⌘J from the Library window (key) also opens it (the menu bar item works from any window).
- `typingFilters`: type `tone c` → one row, `3. Tone Artist - Tone C`; clear, type `other` → the single's row; type `zzz` → no rows and `jump.empty` says no match (check the actual empty text for a no-match vs an empty playlist; the panel has two states).
- `returnPlaysTheChosenRow` (**#0187, local**): type `tone d`, `typeKey(.return)` → the panel closes, `pl.row.3` has `current=true`, `probe.currentIndex == 3`, `main.marquee` starts with `4. `. Reopen, type `tone b`, double-click `jump.row.0` → row 1 plays. Reopen, press ↓ twice with an empty query and Return → row 2 plays (arrow selection).
- `queueButtonAndEscape`: type `tone e`, click `jump.queue` → the panel stays open (check: does Queue close the panel? follow `JumpToFilePanel`), `pl.row.4` has `marker=[1]`; click again → the button reads Dequeue and the marker goes; Esc closes.
- `emptyStateMentionsTheLibrary` (#0190): launch without `-RoadieOpenFiles`, ⌘J → `jump.empty` text contains "Library" (the #0190 wording), and `jump.row.0` doesn't exist.
- `menuBarItemOpensIt`: Playback › Jump to File… opens it; the pop-up's Playback ▸ Jump to File… too.

## Tests

Expect list: `opensWithJAndCommandJ,typingFilters,returnPlaysTheChosenRow,queueButtonAndEscape,emptyStateMentionsTheLibrary,menuBarItemOpensIt`
