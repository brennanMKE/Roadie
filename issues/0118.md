# 0118 — The Output menu can only pick one speaker

| | |
|---|---|
| **Status** | open |
| **Module** | App / MusicAssistantKit |
| **Platform** | macOS |
| **First seen** | 2026-10-20 |

## Description

Reported by the user on 0.1.0-2671617. The Library toolbar's Output menu is single-choice, so playing to both HomePods at once isn't possible unless a group already exists in Music Assistant. The user wants to select several outputs.

## Expected behavior

- Each output (This Mac and every speaker) has a checkbox; checking several plays to all of them in sync, using Music Assistant's player grouping (the first checked becomes the group leader).
- Checking or unchecking a speaker while playing adds it to or drops it from the running playback, without restarting the track.
- The toolbar label names the selection (one name, or "Kitchen + 1").
- Existing Music Assistant groups still appear and can be picked.
