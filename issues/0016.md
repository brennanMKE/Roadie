| | |
|---|---|

## Description

Add a SwiftUI browser window: artists → albums → tracks, plus search, loading pages lazily.

## Acceptance criteria

- Uses PlexKit paging; scrolling a long list does not block the UI.
- Search uses the `title=` filter and debounces input.
- Loading, empty and error states are shown.
