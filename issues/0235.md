## Description

Winamp opened its visualization (MilkDrop) in a window of its own with Ctrl+Shift+K, the clutter bar's V menu, the main menu's Visualization submenu or a right-click on the built-in vis. Roadie has only the 76×16 visualizer in the main window; there's nowhere to show a full-size visualization, and nothing to draw one with until MilkDropMetalKit is 1.0.

This issue adds the window and everything under it that later issues build on: the Roadie-owned renderer seam, the Core Graphics **classic visualizer** (five full-window takes on Winamp's spectrum and scope, no Metal), the render loop with its energy rules, the stereo feed from #0232, the ways to open and close it, its persistence, the probe and the identifiers. Preset keys, auto-advance, full screen and the overlay come next (#0236–#0238).

Design: [docs/design/visualization.md](../docs/design/visualization.md) §1.1, §2.1, §2.2, §3.2–§3.5, §4.2, §4.4.

## Root cause

An addition, not a bug: Roadie had only the 76×16 main-window visualizer, with no full-size window and no renderer to draw one.

## Fix

As planned:
- **Renderer seam and classic visualizer:** `App/Visualization/` holds the `VisualizationRenderer` protocol and factory, plus `ClassicVisualizer`. The classic visualizer draws five styles into a 240-wide bitmap shown nearest-neighbour, with `VisBars` falloff, the skin's vis colours and a crossfade between presets.
- **Model:** `VisualizationModel` holds the navigator, the settings, `StereoFeedReader`, open and rendering state, the audio source and the frame rate.
- **Window:** `VisualizationWindowController` handles the display link, occlusion, minimize and hide. `VisualizationHostView` holds the renderer view, which is the `vis.canvas` image element, and the `vis.preset` label.
- **Ways in:**
  - Window › Visualization ⇧⌘K.
  - SkinKit `MainMenu` Visualization submenu (`toggleVisualization`, `isVisualizationOpen`).
  - `VisualizerMenu`, shared by the clutter bar V and by a right-click on the built-in vis (`SkinWindowController`).
  - `AppDelegate` follows `isOpen` and reopens the window at launch.
- **Tests and tooling:** `AXID.Vis`, `TestProbe.visualization`, and Debug `-RoadieVisRenderer` / `-RoadieVisSeed`.

Changes from the plan:
- The protocol gained `setColors(_:)`, so skin switches reach the renderer.
- Frame autosave is skipped when the defaults aren't `.standard`, so tests never write the real defaults.
- Column-layout placement needed no new code: `WindowDockingCoordinator` already moves any non-skinned key window off the column.
- Existing tests that pin the main menu's command set were updated: `PlayerModelDispatchTests` has a row for the new command, and `MainMenuTests.everyCommandAppearsOnce` now expects 28.

## Plan

### Files (new unless noted)

`App/Visualization/` (a new folder; the existing `App/Visualizer/` is the main window's):

- **`VisualizationRenderer.swift`**: the `@MainActor protocol VisualizationRenderer` from design §3.2 (`view`, `kindName`, `canLoad(_:)`, `load(_:transition:)`, `feed(_:channels:sampleRate:)`, `draw(at:)`, `setReducedMotion(_:)`, `problems`), and `enum VisualizationRendererFactory { static func make(configuration: RoadieConfiguration, colors: [SkinKit.RGBColor]) -> any VisualizationRenderer }`: Debug `-RoadieVisRenderer classic|milk` (an unknown value logs and uses classic); otherwise classic (until #0243 adds the MilkMetal branch).
- **`ClassicVisualizer.swift`**: `final class ClassicVisualizer: VisualizationRenderer`, `kindName "classic"`.
  - `view`: a layer-backed `NSView` whose `layer.contents` is a `CGImage`, `magnificationFilter = .nearest`, black background, `contentsGravity = .resize`.
  - A bitmap `CGContext` of `width = 240`, `height = round(240 * viewHeight / viewWidth)` clamped 90…240, rebuilt on resize; colours from the skin's `viscolor.txt` (`setColors(_:)`, called where `PlayerModel` calls `visualizer.setColors`), `VisRenderer.defaultColors` without a skin.
  - `feed`: copies the newest 1,024 frames into a preallocated window (mono mix and the two channels), runs AudioCore's public `SpectrumAnalyzer(fftSize: 1024, sampleRate:)` (rebuilt when the rate changes) for the spectrum; with no feed for 0.1 s of `draw` time, the spectrum decays to zero (bars fall, as Winamp's do when stopped).
  - `draw(at:)` per `ClassicStyle`: **spectrum** (75 bars with peaks, `VisBars` falloff stepped at 60 Hz as `VisualizerModel.tick` does), **oscilloscope** (mono line), **spectrumAndScope** (bars with the scope over them), **mirror** (bars up and down from the centre line), **stereoScope** (left in the top half, right in the bottom).
  - `load(_:transition:)`: switches style; with `transition > 0` crossfades the outgoing frame image into the new one over that time (two layers' opacity), 0 cuts. `canLoad`: classic presets; in Debug also `.milk` (drawn as spectrum, the preset's name in the title) so later issues can test catalogue and list behaviour before #0243 (design §3.3).
- **`VisualizationModel.swift`**: `@MainActor @Observable final class VisualizationModel`, created by `PlayerModel` beside `visualizer` (`let visualization: VisualizationModel`).
  - Owns `navigator: PresetNavigator` (#0233) over `PresetCatalog.ordered(classics + …)` filtered by `renderer.canLoad`, `settings: VisualizationSettings` (#0234; only `lastPreset`, `order`, `locked`, `windowOpen` are used in this issue), the renderer (built lazily on first open), and `reader: StereoFeedReader` (#0232) over `player.analyzer`.
  - `private(set) var isOpen`, `isRendering`, `currentPreset`, `audioSource: AudioSource` (`.local`, `.remote(name)`, `.none`).
  - `open()`, `close()`, `toggle()`: set `isOpen`, persist `windowOpen`. `AppDelegate` observes `isOpen` and shows / closes the window controller (as `observeEQWindow` does).
  - `setVisible(_ visible: Bool)` (from the controller: window on screen, not miniaturized, `occlusionState.contains(.visible)`, app not hidden): `isRendering = isOpen && visible`; turns `player.analyzer.setStereoEnabled(isRendering)` and resets the reader on resume.
  - `load(_ preset:, transition:)`: calls the renderer; on throw `navigator.markFailed` and keeps the previous; on success `currentPreset`, `settings.lastPreset`, window title.
  - `tick(now:)` (from the controller's display link): `reader.read(elapsed:)` → `renderer.feed`; `renderer.draw(at: renderTime)` where `renderTime` accumulates only while rendering.
  - `static func audioSource(selectedOutput:thisMacID:outputName:state:) -> AudioSource`: remote when the output isn't This Mac (design §4.4), `.none` when stopped; observed from `PlayerModel.selectedOutput` / `playbackState`.
  - `preferredFrameRate`: 60 when `audioSource == .local` and playing, else 30; 30 when `ProcessInfo.processInfo.isLowPowerModeEnabled` or `thermalState >= .serious` (observed notifications).
- **`VisualizationWindowController.swift`**: `final class VisualizationWindowController: NSWindowController, NSWindowDelegate`.
  - `NSWindow(contentRect: 640×400, styleMask: [.titled, .closable, .miniaturizable, .resizable])`, `collectionBehavior.insert(.fullScreenPrimary)` (used by #0237), `backgroundColor = .black`, `minSize 320×200`, `setFrameAutosaveName("VisualizationWindow")`, `identifier "vis.window"` and `setAccessibilityIdentifier("vis.window")`, title "Visualization — <preset>". First placement: right of the main window's group (no saved frame).
  - Content: `VisualizationHostView` (below) holding `renderer.view` (autoresizing to fill).
  - Delegate: `windowWillClose` → `model.visualization.close()`; `windowDidMiniaturize` / `windowDidDeminimize`, `didChangeOcclusionState`, `NSApplication.didHide/didUnhide` → `setVisible`.
  - The display link: `hostView.displayLink(target:selector:)` added to `.main` `.common`, `preferredFrameRateRange` from the model, paused while `!isRendering`; invalidated on close.
  - In UI-test column layout (`-RoadieWindowLayout column`) it's moved right of the column when it becomes key, as the Library is (`WindowDockingCoordinator.moveOffColumn`).
- **`VisualizationHostView.swift`**: `NSView` that holds the renderer view (and, from #0238, the overlay). `isAccessibilityElement` false; the renderer view is an accessibility image element `vis.canvas`, label "Visualization", value the preset name. A hidden-free text element for the preset name: an `NSTextField` label `vis.preset` in a top strip, visible (small, top-left, shadowed) in this issue; #0238 folds it into the overlay's top strip.

## By hand

1. Play a track. ⇧⌘K: a black window opens right of the player, titled "Visualization — Classic Spectrum", bars moving in the skin's vis colours. Switch skins (⌘]): the colours follow.
2. Resize it small and large: the picture fills it, chunky pixels, no stretching artefacts at the edges.
3. Close it with the red button; ⇧⌘K opens it again where it was.
4. Clutter bar V and right-click on the small built-in vis: Start/Stop Visualization is at the bottom; the built-in modes still work. Right-click elsewhere on the main window still shows the main menu.
5. Quit with the window open, relaunch: it reopens (not full screen) on the same preset.
6. Energy: with the window open and music playing, minimize it, or cover it fully with another window: Activity Monitor's CPU for Roadie drops to what it is with the window closed.
7. Play on a Music Assistant speaker: the bars stay flat (no audio reaches this Mac); #0238 adds the explanation.
