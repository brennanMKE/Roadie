## Description

Add an AirPlay route picker to the skinned window so the user can choose one or more speakers from inside SkinAmp.

## Acceptance criteria

- An `AudioOutputRouting` module wraps `AVRoutePickerView` (`NSViewRepresentable`) and `AVRouteDetector`; detection is enabled only while the window is visible, and the control is hidden when no AirPlay devices exist.
- The control fits the skin: a skinned button forwards the click to a hidden picker. The picker has no public "present" method, so the workaround (finding its internal `NSButton` and calling `performClick`) is isolated behind one function and documented as fragile.
- Route changes are observed and the player keeps playing at the same position across them.
- Wired to the playback stack the spike chose (`player` set or nil per #0050's results).

## Notes

See handoff step 2 in [docs/airplay-macos-handoff.md](../docs/airplay-macos-handoff.md). Winamp had no AirPlay button, so where it sits is a design call (for example, a clutterbar-style hot spot or a menu item plus shortcut).
