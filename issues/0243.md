## Description

After #0235–#0242 the visualization window, its keys, overlay, list, settings and accessibility all work, but they draw only Roadie's five classic visualizations: no `.milk` preset renders. The renderer is MilkDropMetalKit's `MilkMetal` (`MilkRenderer`, `MilkPreset`), which the user is finishing in `../MilkDropMetalKit`: "We will use MilkDropMetalKit once it is ready." It isn't tagged yet; its 1.0 review (`docs/api-1.0.md` in that repo) lists the API changes still to decide.

**Blocked until MilkDropMetalKit has a `1.0.0` tag on https://github.com/brennanMKE/MilkDropMetalKit.** Check from the host with `git ls-remote --tags https://github.com/brennanMKE/MilkDropMetalKit.git` (or `gh release view 1.0.0 -R brennanMKE/MilkDropMetalKit`); never with `gh` in the VM.

Design: [docs/design/visualization.md](../docs/design/visualization.md) §3.2, §3.3, §4.2, §5, §8.3, §9; [docs/milkdrop-metal-handoff.md](../docs/milkdrop-metal-handoff.md) §8.

### `MilkVisualizer`

`App/Visualization/MilkVisualizer.swift`: `final class MilkVisualizer: VisualizationRenderer`, `kindName "milk"`.

- `init?(device: MTLDevice)`: `MilkRenderer(device:pixelFormat: .bgra8Unorm)`; nil if it throws. `view`: Roadie's own `MetalVisualizationView` (an `NSView` with a `CAMetalLayer`, `device`, `pixelFormat`, `framebufferOnly`, opaque, `drawableSize` = bounds × backing scale, updated on resize and `viewDidChangeBackingProperties`), not `MilkView`, because Roadie's display link (#0235) drives frames and pausing (design §3.2; api-1.0.md F7).
- `canLoad`: classic presets no (the classic renderer draws them; see "Mixed lists" below), `.milk` yes.
- `load(_:transition:)`: `MilkPreset(contentsOf: url)` parsed off the main actor first (`Task.detached`, it's `Sendable`), then `renderer.load(preset, transition:)` on the main actor; `problems` from `presetErrors` (logged, not shown). A throw → the model's existing failure path (#0235: `markFailed`, toast "Couldn't load <name>").
- `feed`: `renderer.feed(samples:channels: 2, sampleRate:)` with #0232's reader output, from the main actor only (single producer, api-1.0.md F4). If 1.0 paces `feed` itself (F5 option b), check the picture doesn't lag by a window (by hand, step 4); if it does, feed the reader's newest frames without the cursor lag and say so in `## Fix`.
- `draw(at:)`: `layer.nextDrawable()` (skip the frame when nil), a command buffer from Roadie's `MTLCommandQueue`, `renderer.render(to: drawable.texture, commandBuffer:time:)`, `present`, **always `commit`** (render waits on a 3-frame semaphore; an uncommitted buffer stalls the main thread, api-1.0.md F3).
- `setReducedMotion`: `transitionPattern = .crossfade` when on, `.random` off.

### Mixed lists and the factory

- The navigator lists classic presets and `.milk` presets together (design §5.1). `VisualizationModel` keeps one `ClassicVisualizer` and one `MilkVisualizer` and routes each `load` to the one whose `canLoad` is true; switching between kinds swaps the visible view with a crossfade of the two views (the outgoing view keeps drawing for the blend time, then stops). The renderer seam stays as is; the model holds `[any VisualizationRenderer]`.
- `VisualizationRendererFactory`: Release and Debug without a hook build both when `MTLCreateSystemDefaultDevice()` is non-nil, else classic only (and `.milk` presets drop out of the list). `-RoadieVisRenderer classic` (the UI tests' default) builds classic only, as today; `-RoadieVisRenderer milk` builds both.
- The Debug-only rule that lets the classic renderer "draw" `.milk` presets (#0235) is removed; Settings' presets folder row (#0241) now shows in Release.

## By hand

1. Play music, open the visualization: it starts on spike-tunnel; the picture reacts to the bass. → and ←: MilkDrop presets with MilkDrop 2 blends (wipes, plasma, radial).
2. Full screen on the built-in display and an external one: smooth at 60 fps (F5 readout), no tearing; Activity Monitor's GPU and CPU reasonable; minimize: both drop to idle.
3. Settings › Visualization › Your presets folder: a folder of `.milk` presets (e.g. a pack you own): the count appears, L lists them, they render; a broken one shows "Couldn't load" and is skipped.
4. Pacing: tap a beat-heavy track's kick against the picture: it pulses on the beat, not a tenth of a second late, and doesn't step in chunks.
5. Reduce Motion: transitions are plain crossfades. Dim Flashing Lights: darker, slow crossfades.
6. Music Assistant speaker: the picture idles calmly on silence; switch to This Mac (Sendspin): it reacts.
7. Classic presets still work between MilkDrop ones (→ from the last classic goes to the first MilkDrop preset with a crossfade).
