# 0038 — Full skin corpus has not been tested

| | |
|---|---|
| **Status** | open |
| **Module** | SkinKit |
| **Platform** | macOS |
| **First seen** | 2026-10-12 |

## Description

Run SkinKit against a random 1,000-skin sample and the full corpus; fix crashes, record the failure rate, and measure performance.

## Acceptance criteria

- Zero crashes; ≥95% render with no missing sprites; numbers recorded in the brief.
- Performance measured across the full corpus: median and p95 parse-plus-render time per skin, total run time, and peak memory, recorded in the brief.
- The slowest skins are listed, and any hot spots found are fixed or filed as issues.
