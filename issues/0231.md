## Description

Umbrella for milestone **M18: Visualization**. Roadie has Winamp 2.x's tiny built-in visualizer (spectrum and scope in the main window) and nothing like the MilkDrop window Winamp users remember. The visualizer engine is being built in a separate package, MilkDropMetalKit (`../MilkDropMetalKit`, product `MilkMetal`; not 1.0 yet). This milestone builds everything Roadie owns around it, now, and adopts the package when it's tagged.

The user, 2026-10-29:

> Winamp had really great visualizations. We are working on recreating them with Swift and Metal in ../MilkDropMetalKit right now. Plan out how Roadie will support visualizations. What I want for full screen mode to show the song and artist and playback details but when the mouse cursor has been idle it should disappear and just show the visualization. The arrow keys should move between visualizations. Make sure to replicate the classic Winamp behavior beyond that. Once the plan is done break it down into issues in a milestone and start working on it.

And earlier: "We will use MilkDropMetalKit once it is ready."

Scope:

1. A separate, resizable **visualization window**, opened the Winamp ways (⇧⌘K for Ctrl+Shift+K, the clutter bar's V menu, the skinned main menu's Visualization submenu, right-click on the built-in vis), remembered across launches, that stops rendering when closed, minimized or hidden.
2. **Full screen** (⌥Return, double-click, ⌃⌘F; Esc leaves) with an **overlay** of title, artist, album, play state, elapsed/total, next track, output and volume that hides with the cursor after 3 s idle and comes back on mouse movement.
3. **Keys:** ← → previous/next preset (the user's request), ↑ ↓ volume, and MilkDrop's own: Space/⌫ next/previous with a blend, H hard cut, R random/sequential, \` lock, L preset list, T song title, F1/? help, F2–F5 readouts, Z X C V B transport.
4. **Classic MilkDrop behaviour:** automatic preset changes (16 s, varied, 2.7 s blends), the song title on track change, history, lock, last preset remembered, a presets folder, Settings › Visualization.
5. **Audio:** a stereo, allocation- and lock-free sink beside the mono `VisSampleRing`, paced per frame; an honest idle state when Music Assistant plays on a speaker (no PCM reaches this Mac).
6. **Accessibility:** labelled overlay, VoiceOver keeps it up, Reduce Motion pauses automatic changes and softens transitions, Dim Flashing Lights dims, and a one-time flashing notice.
7. A Roadie-owned **renderer seam** with a Core Graphics **classic visualizer** (five full-window takes on Winamp's spectrum and scope) so all of the above is built and tested now, in the VM, without Metal; then **MilkDrop presets** through MilkMetal once its `1.0.0` tag exists.

Kept, adapted and dropped Winamp/MilkDrop behaviour, item by item, is in the design's §1. Dropped: preset editing and saving, ratings, desktop mode, hard cuts on beats (off by default in MilkDrop 2), sprites and messages, a skinned frame.

## Design

[docs/design/visualization.md](../docs/design/visualization.md) (2026-10-29): the Winamp/MilkDrop behaviour inventory (§1), the window, full screen, overlay, keys, right-click menu, song title, readouts, help, preset list and settings (§2), the `VisualizationKit` models and the App's renderer seam, classic visualizer and render loop (§3), the stereo sink, pacing and remote playback (§4), presets (§5), settings keys and Debug hooks (§6), accessibility and photosensitivity (§7), testing in the VM (§8), risks (§9), order (§10) and the open questions below (§11).

Open questions for the user (design §11; the plans use the defaults):

1. ↑ ↓ in the vis window: **volume** (Winamp's bare keys, which MilkDrop passed through), so only ← → change meaning.
2. Overlay idle time: **3 s**, settable (2, 3, 5, 10 s, Never).
3. Overlay while paused or stopped: **stays up**; it hides only while playing.
4. Ship the window with the classic visualizations before MilkDrop lands: **yes**.
5. Bundled presets: **the package's own MIT demo presets**, until a curated pack with clear licences exists.
6. Hard cuts on beats: **not in M18**.
7. Start preset: **the last one shown**.
8. Window frame: **native**, not skinned.
9. Visualization Settings shortcut: **⌥⌘K** (⌘K stays the Skin Library).
