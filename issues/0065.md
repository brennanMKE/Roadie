# 0065 — A local music folder cannot be used as a library

## Description

The last-fallback source: point SkinAmp at a folder organized like the Plex library, `Artist/Album/<tracks>`, and browse and play it through AudioCore without any server.

## Acceptance criteria

- Settings › Library: choose the folder (open panel), shown with its path; the choice persists.
- A `FolderBackend` conforming to `MusicBackend` indexes artists from top-level folders and albums from their subfolders, reading track metadata with `LocalTrackLoader` (#0006); embedded or folder artwork (`cover.jpg`, `folder.jpg`) for album art.
- Loose files and odd layouts are handled gracefully (tracks directly under an artist, discs as `Disc 1/` subfolders, unsupported files skipped and reported).
- The index is built off the main actor, cached, and refreshed when the folder changes.
- Unit tests build a small generated folder tree in a temp directory (generated audio, as #0006's tests do).

## Notes

The app is unsandboxed today, so a plain path works; if it is ever sandboxed this needs a security-scoped bookmark.
