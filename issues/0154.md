## Description

M14 work item W3 from [docs/design/release.md](../docs/design/release.md). Depends on: W2.

## Expected behavior

XcodeGen project `Roadie`, targets `Roadie`, `RoadieThumbnail`, `RoadiePreview`, scheme `Roadie`, `RoadieApp`, entitlements files; `run-tests-vm.sh`, `verify.sh`, `make-dmg.sh`, check scripts, VM clone prefix and lease label renamed. `verify.sh --launch --dmg` passes and produces `release/Roadie.app.zip`; no `SkinAmp` left in `project.yml` or `scripts/`.

## Root cause

The XcodeGen project, its three targets and scheme, the entitlements files, `SkinAmpApp.swift`, and every script that
builds, checks, launches or packages the app still used the SkinAmp name. The VM runner builds by project and scheme
name, so all of these had to change in one commit.

## Fix

- `project.yml`: project `Roadie`; targets `Roadie`, `RoadieThumbnail`, `RoadiePreview`; scheme `Roadie`; display
  names `Roadie`, `Roadie Thumbnail`, `Roadie Preview`; entitlements paths renamed. `App/Info.plist` was regenerated to
  match.
- The entitlements files and `App/RoadieApp.swift` (`struct RoadieApp`) were renamed with `git mv`. They are 100% and 99%
  renames, so history follows them.
- `run-tests-vm.sh`: `-project Roadie.xcodeproj -scheme Roadie` for Debug and Release, `Roadie.app` paths,
  `pgrep -x Roadie` and `quit app "Roadie"`, and `release/Roadie.app.zip`. The clone prefix is `roadie-test-`, the
  export temp dir is `roadie-test-export.*`, the lease label is `roadie` and the memory request is `roadie-run-tests-vm`.
  The stale-clone cleanup matches `^(roadie|skinamp)-test-(date)-(time)-(pid)$` for one transition. The prefix is
  now group 1, so the date and time are `$match[2]$match[3]` and the pid is `$match[4]`. I checked these indices.
- `verify.sh` reports `release/Roadie.app.zip`. `make-dmg.sh` unpacks `Roadie.app` and writes
  `build/dist/Roadie-<version>-<build>-<commit>.dmg` with volume name `Roadie`. `check-quicklook.sh` looks for
  `RoadieThumbnail.appex`/`RoadiePreview.appex`, the `RoadiePreview` process and `Roadie*` crash reports and log lines.
  The comments and usage text in `check-entitlements.sh` and `check-info-plist.sh` were updated.

## Verification

`scripts/verify.sh --head --launch --dmg` at 9b35556 passed (run 20261023-013611-44114). It ran 11 steps and 1566 tests
in 14 test runs. The Debug app built from `Roadie.xcodeproj`/`Roadie` and launched and quit as `Roadie`. Every Quick Look
check passed against `RoadieThumbnail.appex`/`RoadiePreview.appex`, and `identifiers` passed. The host stayed silent.
`app-release` produced `release/Roadie.app.zip` (build 20261023.0838). `project.yml` has no `SkinAmp` left.

The SkinAmp strings left in `scripts/` are deferred to #0155 (W4), and that is acceptable. The design gives W3 the build,
path and packaging names and gives W4 the environment variables (`SKINAMP_SLOW_TESTS` → `ROADIE_SLOW_TESTS`, which
needs the Swift tests to change at the same time). W4's acceptance criterion is "no `SkinAmp` in `scripts/` beyond the
allowlist". What remains is in four places:
- `SKINAMP_SLOW_TESTS`.
- The user-facing strings in the Python scripts (`probe-sendspin.py`, `record-ma-fixtures.py`,
  `tests/test_record_writes_cleanup.py`).
- `check-identifiers.sh`'s legacy Plex constant and comment.
- `worklog.py`'s `DEFAULT_DIR`. It names the Claude project folder for this checkout, so it stays until the local
  folder is renamed.

The transitional `skinamp-test-` cleanup pattern is allowlisted by Gate A. The stale local `SkinAmp.xcodeproj` is
gitignored and was left alone.
