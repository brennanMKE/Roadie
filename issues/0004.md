# 0004 — Player has no 10-band equalizer

| | |
|---|---|
| **Status** | open |
| **Module** | AudioCore |
| **Platform** | macOS |
| **First seen** | 2026-10-12 |

## Description

Configure `AVAudioUnitEQ` with 10 parametric bands at 60, 170, 310, 600, 1k, 3k, 6k, 12k, 14k, 16k Hz plus a preamp (`globalGain`), with on/off and presets.

## Acceptance criteria

- Band gains range −12…+12 dB, matching Winamp.
- EQ state is a plain value type the UI can bind to and persist.
- Built-in presets (Flat, Rock, Pop, …) load and apply.
