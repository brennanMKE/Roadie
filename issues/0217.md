## Description

`SkinLibraryModel` is at 40 % in #0212's baseline. `SkinBrowserWindowView` is at 1 %, and `MuseumCellView` (196 lines), `MuseumStatusView` (181), `SkinCellView` (115), `SkinGridView` and `MuseumGridView` are at 0 %. #0211 left three follow-ups here: `SkinLibraryModel.countsText` after a scan of the test skins, `applyDefaultFolderIfNeeded` with no folder set (needs an injectable `DefaultSkinsFolder.url()`), and main-menu skin navigation (`.nextSkin`/`.previousSkin`/`.randomSkin`) with an indexed skins list, which #0211 kept as crash checks only.

## Plan

1. `SkinLibraryModel` (`Tests/RoadieTests/SkinLibraryModelTests.swift`), on a temp folder seeded from `TestSkins/` (or the SkinKit fixture skins when the cache is absent):
   - `countsText` before choosing a folder ("No folder chosen"), with a folder but no index ("Not indexed yet"), and after `scan()` (`N skins in M files`)
   - `setFolder`, `resetIndex` and `addDownloaded`
2. Make `DefaultSkinsFolder.url()` injectable: a `defaultFolder: () -> URL` init parameter on `SkinLibraryModel`, defaulting to the real one. Test `applyDefaultFolderIfNeeded` with no folder set (it adopts the injected URL and returns true), with a folder already set (no change), and with an unwritable URL (false, no folder).
3. Main-menu skin navigation: with an indexed list of three test skins, `.nextSkin`, `.previousSkin` and `.randomSkin` through `PlayerModel.perform(_:)` (`PlayerModel+MainMenu.swift`) change `skinBrowser`'s current skin. Next and previous wrap. Random never returns the current skin when there are two or more. These replace #0211's crash-only rows in `PlayerModelDispatchTests`.
4. `SkinBrowserWindowView`'s `SkinsSource` and the status-bar text, and `MuseumStatusView`'s content choice (loading, error, empty, results): move them into `SkinBrowserModel`/`MuseumBrowserModel` helpers or `static` functions and test them with `SkinMuseumStub`.

## Tests

`countsTextFollowsScan`, `defaultFolderAppliedWhenUnset`, `defaultFolderKeptWhenSet`, `defaultFolderUnwritable`, `mainMenuNextPreviousRandomSkin`, `skinsStatusText`, `museumStatusContent`. Expect list: all of them.

## Which tier

**Fast:** `scripts/verify.sh --expect <the tests above>`. The new tests must not need the network, a real Keychain or a speaker. They use the stubs and injectable seams the plan names.
