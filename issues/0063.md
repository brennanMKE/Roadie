# 0063 — Settings has no library source picker or Music Assistant connection

| | |
|---|---|
| **Status** | open |
| **Module** | App / MusicAssistantKit |
| **Platform** | macOS |
| **First seen** | 2026-10-13 |

## Description

Settings gains a **Library Source** picker: Music Assistant (default) | Plex | Local folder, and a Music Assistant section to connect to the server.

## Acceptance criteria

- The source picker defaults to Music Assistant on a fresh install and persists the choice.
- Music Assistant section: Bonjour discovery of `_music-assistant._tcp` (service type per #0060), a manual host:port field, a token field stored in the Keychain (separate item from Plex's), Test Connection with clear messages, and a connection status indicator.
- The existing Plex tab (#0011, #0014) stays as the alternative source's settings; the folder source's settings come with #0065.
- Info.plist: add `NSBonjourServices` with the MA service type; `scripts/check-info-plist.sh` currently asserts that key is absent, so update the check to allow exactly that entry and nothing broader. The Local Network usage string covers MA as well as Plex.
- Same token rules as #0011: no token on disk outside the Keychain, in logs or UI; failed reads never delete it.

## Notes

Model the settings model on `PlexSettingsModel` (state machine, cancellation, token-dirty rules), and keep views in `App/Settings/`.
