## Description

Umbrella for milestone **M13: Playlists**: manage playlists, favorites, Music Assistant's automatic playlists and the queue, backed by Music Assistant. It ships no code itself; it stays open until every child is resolved, closed or won't-fix. Design: [docs/design/playlists.md](../docs/design/playlists.md) (Fable, 2026-10-21), whose §4 work items W0–W13 are the children below and whose §5 lists the open decisions.

The original request:

Requested by the user: "I'd like to be able to manage playlists. That does not seem to do much yet. Can you leverage Music Assistant features here? I see that UI has automatic playlists and likely ways to manage playlists."

Today the Library window's Playlists section only lists Music Assistant playlists and plays them. Music Assistant's API (docs/ma-protocol/commands.json) already supports much more:

- `music/playlists/create_playlist`, `update`, `remove`
- `music/playlists/playlist_tracks`, `add_playlist_tracks`, `remove_playlist_tracks`
- `player_queues/save_as_playlist` (the current queue becomes a playlist)
- `music/recommendations` / `music/recommendations/items` (the "automatic" rows the Music Assistant web app shows, e.g. recently played, random picks, in progress)
- `music/favorites/add_item` / `remove_item`, `players/add_currently_playing_to_favorites`
- `music/radios/*`, `builtin/add_radio`
- `music/playlists/import_playlist` / `export_playlist`

SkinAmp also has the Winamp playlist editor (PL window) with ADD / REM / SEL / MISC / LIST buttons; its LIST › Save/Load could map to Music Assistant playlists when Music Assistant is the source.

## Expected behavior

- Library › Playlists: create, rename and delete playlists; open one to see its tracks; reorder and remove tracks; add tracks (or an album/artist) to a playlist from anywhere in the Library via a context menu "Add to Playlist ▸".
- Save the current queue as a playlist (Playback menu and the PL window's LIST › Save).
- Music Assistant's automatic playlists/recommendations appear in the Library sidebar, browsable and playable.
- Favorites: heart/unheart the current track and items in the Library; a Favorites view.
- Playlists only editable where the provider allows it (Music Assistant marks read-only playlists, e.g. from streaming providers); others show as read-only.
- Works with the Music Assistant backend; other backends hide what they can't do (capabilities).
