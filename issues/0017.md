# 0017 — Duplicate artist spellings and missing album art clutter the browser

| | |
|---|---|
| **Status** | open |
| **Module** | PlexKit / App |
| **Platform** | macOS |
| **First seen** | 2026-10-12 |

## Description

Group artists whose names differ only by `&`/`and`, a trailing `;`, or case, and show a placeholder for albums without a `thumb`.

## Acceptance criteria

- Normalization is a pure function with unit tests using the real examples (`AJ & Jordan` / `AJ and Jordan`).
- Album art loads from the `/photo/:/transcode` URL at thumbnail size and is cached in memory.
