## Root cause

The backend API had no favorites calls, and the Library rows had nothing that showed or changed whether an item is a favorite. The W1 `isFavorite` fields (#0134) were decoded but never shown.

## Fix

- `MusicBackend` gains `.favorites` (1 << 6), plus `setFavorite(_:_:)` and `favoriteCurrentTrack(on:)`. By default both throw `.unsupported(.favorites)`. Music Assistant declares `.favorites`, and `StubMusicBackend` records both calls.
- `MusicAssistantBackend+Favorites.swift` holds the three request builders and the implementation:
  - Favoriting sends `music/favorites/add_item` with the item's URI.
  - Unfavoriting sends `music/favorites/remove_item` with `media_type` and `library_item_id`. A URI that isn't `library://` is refused before anything is sent.
  - Favorite Current Track sends `players/add_currently_playing_to_favorites` to the player behind the output; This Mac maps to its Sendspin wrapper.
  - All three go through #0137's `perform`, so an error 12 marks the command unsupported.
- `PagedList.update(id:_:)` patches a loaded item in place.
- `FavoritesModel` (owned by `LibraryBrowserModel.favorites`):
  - A flip shows at once through the `overrides` map and is restored if the command fails.
  - **Deviation:** W5 (#0139) hasn't landed. A successful command counts as confirmation: the value moves to a `confirmed` map, the cached paged lists are patched, and the override is cleared.
  - **Deviation:** the entry point for changes made elsewhere is `apply(favorite:for:)`, not `apply(LibraryChange)`. W5 can forward to it.
  - `nil` and `false` read as not favorited, so dislikes are ignored (decision 9).
- Hearts on track, album, artist and playlist rows (`FavoriteButton.swift`): shown on hover or when favorited, always available to VoiceOver.
- Favorite/Unfavorite in the context menus for tracks, albums (including search results), artists and playlists. With several items selected, the menu favorites all of them unless every one already is a favorite.
- Playback › Favorite Current Track (⌃⌘L) is disabled for the local queue (decision 8) and for sources without favorites.
- **Deviation:** there is no ⌘L in the Library window, because ⌘L is already Playback › Library (#0115). ⌃⌘L collides with nothing.
