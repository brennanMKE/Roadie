# 0120 — Turning on EQ or PL hides the main window

| | |
|---|---|
| **Status** | open |
| **Module** | App / WindowDocking |
| **Platform** | macOS |
| **First seen** | 2026-10-20 |

## Description

Reported by the user on 0.1.0-2671617 (MacBook). Turning on the equalizer or the playlist editor (the EQ and PL buttons on the main window, or presumably Window › Equalizer / Playlist Editor) shows that window but the main player window disappears. The main window should stay visible, with the new window docked below it as in Winamp.

## Expected behavior

- Showing EQ or PL leaves the main window on screen and where it was; the new window docks under it (or where it was last placed).
- Hiding EQ or PL leaves the main window alone.
- Works on a fresh install (no saved layout) and with a saved layout, and on a smaller laptop screen.
