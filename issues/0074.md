## Description

The user decided on 2026-10-14 to drop direct Plex Media Server support. Music Assistant already offers Plex as one of many music sources, so SkinAmp's own Plex client, sign-in, server picker, download cache and Plex backend are redundant. The source order becomes Music Assistant (default) → local folder.


**Hold lifted (2026-10-19, user's decision):** the user can't use Plex ("it is hostile to integrations") and wants the app usable on Music Assistant alone. Remove direct Plex now, without waiting for #0066; #0066 (Sendspin playback on This Mac) follows and is the way Plex music reaches the Mac, through Music Assistant's Plex provider. ~~On hold (2026-10-18): don't remove direct Plex support until Music Assistant can play through this Mac.~~ The plan below was written against `main` at 21355e2; re-check it against current `main` (#0063, #0064, #0067, #0075, #0084 have landed since) before implementing.

## Acceptance criteria

- Remove the `PlexKit`, `PlexKitStub` and `PlexBackendKit` targets and their tests, the Plex Settings tab and sign-in flow, the Plex `LibrarySource` and its fallback probe, `PlexPlaybackStack`, and the Plex fixtures and `scripts/record-plex-fixtures.sh`.
- Remove `TrackCache`, the Cache Settings tab and the progressive-download path from #0039 if nothing else uses them once Plex is gone; keep anything the folder source or Music Assistant needs (decide in the plan, with a reason).
- The "This Mac" output (`LocalPlayerOutput`) moves out of the Plex composition root so the folder source and, later, Music Assistant's local playback keep it.
- Plex entries in the saved queue (#0071) are dropped or skipped cleanly on restore.

- Docs (`docs/plan.md`, `docs/plex-music-library.md`, `docs/music-assistant-integration.md`, `README.md`) say Plex is reached through Music Assistant.
- The VM run passes with the Plex suites gone and no Plex symbols left (`grep -ri plex` shows only history, docs about the change, and Music Assistant's Plex provider).

import AudioCore

/// Everything "This Mac" playback needs, built in the right order (player, then the output over it). The app's
/// composition root is the only place that builds it; every backend that plays through AudioCore shares `output`.

### 5. `LocalPlayback/QueueSnapshot.swift` and `QueueAutosaver.swift`

`QueueSnapshot.swift`:
- `StoredSource` keeps only `case file(path: String)`; `CodingKeys` becomes `kind, path`; `init(from:)` keeps `case "file"` and the `default:` that throws `DecodingError` (that is what `"plex"` and any other kind become); `encode` keeps the file case.

- In `load()` and `save()` delete the `.plex` cases.
- New API on `QueueStore`:

```swift
/// What `loadQueue()` found: the queue minus items of kinds this build cannot play.
public struct LoadedQueue: Equatable, Sendable {
    public var snapshot: QueueSnapshot
    /// Items dropped because their source kind is unknown (a queue saved with the removed Plex source).
    public var droppedItems: Int
}

/// nil exactly when `load()` was nil before; otherwise the surviving items in order, `currentIndex` remapped.
public func loadQueue() -> LoadedQueue?
/// `loadQueue()?.snapshot`.
public func load() -> QueueSnapshot?
```

Rules: file missing, unreadable, not JSON, `version != 1`, or `items` otherwise malformed → nil, file left alone (as today). Items with `source == nil` are skipped (before the id de-duplication). `currentIndex` → the new position of the same item when it survived, else nil. `droppedItems` is the count; `Logger(subsystem: "com.brennanmke.SkinAmp", category: "QueueStore").info("queue restore dropped \(n) item(s) of an unknown kind")` once when `n > 0` (no path, no key). Loading never writes.

`QueueAutosaver.swift`: add

```swift
/// Writes the current queue now, even when it has not changed since `start()` (a restore that dropped items).
public func saveNow()
```

Body: `pending?.cancel(); pending = nil; saveCount += 1; do { try store.save(output.queueSnapshot()) } catch { log.error(…) }` (the body of `flush()` without its `saveCount == 0 && snapshot == baseline` guard). `flush()` keeps its guard.

### 7. `App/LegacyDataCleanup.swift` (new)

```swift
import Foundation
import LibraryBrowser
import Security
import os

/// One-time removal of what the removed Plex source (#0074) left on this Mac: its Keychain item, its defaults
/// and the track cache. Runs first in `PlayerModel.init`; idempotent through `versionKey`; logs counts and
/// statuses only. In the Tart guest nothing exists, so every step is a no-op and nothing can prompt.
@MainActor
enum LegacyDataCleanup {
    static let versionKey = "legacyCleanupVersion"
    static let version = 1
    static let defaultsKeys = ["PlexServerSelection", "PlexClientIdentifier", "TrackCacheLimitBytes"]
    static let keychainService = "com.brennanmke.SkinAmp.plex"
    static let removedSourceID = "plex"

    static func run(defaults: UserDefaults = .standard, bundleIdentifier: String? = Bundle.main.bundleIdentifier)
}
```

`run`, each step independent of the others' outcome:

1. `guard defaults.integer(forKey: versionKey) < version else { return }`.
2. `removeObject(forKey:)` for each of `defaultsKeys`; if `defaults.string(forKey: LibrarySourceController.defaultsKey) == removedSourceID`, remove that key too (the controller then picks Music Assistant; a user who chose the folder keeps it).
3. Keychain: `SecItemCopyMatching` with `kSecClass: kSecClassGenericPassword`, `kSecAttrService: keychainService`, `kSecMatchLimit: kSecMatchLimitAll`, `kSecReturnAttributes: true` and **no** `kSecReturnData` (never prompts, never decrypts). `errSecItemNotFound` → nothing. `errSecSuccess` → `SecItemDelete([kSecClass: kSecClassGenericPassword, kSecAttrService: keychainService])`, logging the `OSStatus` at `error` unless it is `errSecSuccess`/`errSecItemNotFound`. Other statuses: log the number, skip. The token is never read.
4. Cache: `FileManager.default.urls(for: .cachesDirectory, in: .userDomainMask)[0]` + `bundleIdentifier ?? "com.brennanmke.SkinAmp"` + `Tracks`. If it exists, remove it in `Task.detached(priority: .utility)` (captures only the `URL`), logging the result. Not retried on failure (macOS purges Caches).
5. `defaults.set(version, forKey: versionKey)` after steps 2 and 3.

Logging: `Logger(subsystem: "com.brennanmke.SkinAmp", category: "LegacyCleanup")`, one `info` line: removed defaults count, Keychain found/absent, cache dir removed/absent. This is the one source file allowed to spell "Plex" (constants and comments). No test target covers `App/`; `app-launch` in the guest exercises the all-absent path; section 12 lists what the user checks.

### 14. Risks and gotchas
