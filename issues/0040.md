# 0040 — Removing the current track while paused starts playback

| | |
|---|---|
| **Status** | open |
| **Module** | AudioCore |
| **Platform** | macOS |
| **First seen** | 2026-10-12 |

## Description

`Player.removeTrack(at:)` on the current track while the player is `.paused` starts the next track playing, because `startCurrentTrack()` always plays. Found in the #0002 review.

## Steps to reproduce

1. Queue two or more tracks and play the first.
2. Pause.
3. Remove the current track (`removeTrack(at:)` with the current index).

## Expected behavior

The next track becomes current and the player stays `.paused` at its start (or `.stopped` if the queue is now empty).

## Actual behavior

The next track starts playing.

## Notes

See `Packages/PlayerKit/Sources/AudioCore/Player.swift` (`removeTrack(at:)`, `startCurrentTrack()`) and the `## Review notes` in [#0002](0002.md). A headless `Player` test can cover it, like the existing `PlayerTests`.
