# 0062 — The UI is tied to Plex instead of a source-neutral music backend

| | |
|---|---|
| **Status** | open |
| **Module** | PlayerKit / App |
| **Platform** | macOS |
| **First seen** | 2026-10-13 |

## Description

Introduce a `MusicBackend` protocol and source-neutral domain models (artist, album, track, playlist, output, now playing) so the browser and skinned UI never see MA, Plex or folder types. Move the existing Plex code behind a `PlexBackend` adapter.

## Acceptance criteria

- `MusicBackend` covers connect, search, paged artists/albums, album tracks, playlists, outputs, play, transport and a now-playing stream, as sketched in the doc's section 5.1, adjusted to what #0060 and the M2 Plex client actually support.
- `PlexBackend` wraps PlexKit and TrackCache; Plex tracks still resolve to cached local files for AudioCore.
- Backends that play through AudioCore (Plex, folder) and backends that control remote players (MA) both fit: outputs and transport are part of the protocol, with "This Mac" as an output.
- App and browser code depends only on `MusicBackend` and the domain models. Unit tests run each adapter against stubs.

## Plan

### Scope and decisions

This issue adds three small targets to `Packages/PlayerKit` and moves the app's Plex wiring behind them. It writes no browser (#0016), no artist de-duplication or art cache (#0017), no Settings changes (#0063), no Music Assistant code (#0060/#0061), no folder backend (#0065) and no fallback (#0067). Music Assistant's message shapes are unverified, so nothing here encodes an MA assumption; the protocol is shaped so an MA adapter can conform without changing the browser, and the places where MA may need an adjustment are called out in section 10.

- **Three targets, not one.** `MusicBackendKit` (Foundation only: the protocol and the domain models), `LocalPlayback` (the "This Mac" output over `AudioCore.Player`, shared later by the folder backend), and `PlexBackendKit` (the Plex adapter). `MusicAssistantKit` (#0061) must stay free of AudioCore and PlexKit, so the protocol cannot live next to either; `FolderBackend` (#0065) will play through AudioCore like Plex does, so the AudioCore bridge must not live inside the Plex adapter. Dependency direction: `MusicBackendKit` ← `LocalPlayback` (+ `AudioCore`) ← `PlexBackendKit` (+ `PlexKit`, `TrackCache`). AudioCore, PlexKit and TrackCache are untouched except for two additive search endpoints in `PlexEndpoints.swift`.
- **Module names end in `Kit` because the protocol is called `MusicBackend` and the adapter `PlexBackend`.** A module and a type with the same name makes every qualified lookup inside that module (`MusicBackend.Page`) resolve to the type instead of the module. `MusicBackendKit` / `PlexBackendKit` avoid that; `LocalPlayback` holds `LocalPlayerOutput`, so no clash there.
- **Domain type names do not collide with AudioCore.** AudioCore owns `Track`, `PlaybackState`, `RepeatMode`, `PlayQueue`, `NowPlayingSnapshot`. The domain uses `LibraryArtist`, `LibraryAlbum`, `LibraryTrack`, `LibraryPlaylist`, `MediaID`, `NowPlaying` (with a nested `NowPlaying.State`), `OutputDevice`, `TransportCommand`. The app imports both modules without qualification.
- **One identifier type, `MediaID`, with a `kind`.** Plex uses `ratingKey`, MA will use `library://…` URIs, the folder backend a relative path. A play request is `[MediaID]`; a backend expands an album or playlist id into its tracks (Plex client-side, MA server-side via `play_media`). The doc's `MediaRef` is this type.
- **Paging is offset-based with an optional total.** `PageRequest(offset:limit:)` → `Page(items:offset:total:nextOffset:)`. Plex knows `totalSize`; MA's `library_items` takes `limit`/`offset` (per the doc) and may not report a total, so `total` is optional and `nextOffset` is set by the backend (offset + count when there is more). A backend that turns out to be cursor-based gets a `cursor: String?` added to both types later; nothing in the browser would change.
- **Outputs and transport are explicit, with "This Mac" as a stable output id.** `OutputDevice.thisMac` has id `"this-mac"`. `play`, `transport` and `nowPlaying` take an `OutputDevice.ID`, as the doc sketches, so an MA backend can list HomePods beside its players without a "selected output" hidden inside the backend. The app holds the selection.
- **`nowPlaying(on:)` is a coarse stream, not a clock.** It yields a `NowPlaying` snapshot on subscription and on every track, state, seek or volume change, with `elapsed` and `updatedAt`; the UI extrapolates while playing (`elapsed(at:)`). That is what `MPNowPlayingInfoCenter` does and what MA events will look like. For This Mac the skinned window may keep binding to `Player.currentTime` at 30–60 Hz, which is AudioCore, not Plex; #0064 switches the window to the stream for MA.
- **The "This Mac" output owns the local queue.** `LocalPlayerOutput` (`@MainActor`, in `LocalPlayback`) takes `AudioCore.Track`s paired with their `MediaID`s, enqueues them on `Player`, keeps a `UUID → MediaID` registry so `NowPlaying.item` is the library id, routes `TransportCommand`s and publishes the stream from `Player.addEventObserver`. `PlexBackend` only maps `PlexTrack → Track` with the existing `Track(plexTrack:machineIdentifier:)` and hands the pairs over. Plex tracks therefore still resolve to cached local files exactly as today: the `Player`'s `PlexTrackResolver` → `TrackCache` path is untouched, and so are `CachePinner` and `NowPlayingBridge`.
- **`PlexBackend` is an actor.** It reads `PlexServerSelection` + token through a provider closure on `connect()` (like `PlexPartDownloader.settingsClientProvider`), runs the existing `PlexConnectionTest`, picks the music section, and keeps `(client, sectionKey, machineIdentifier)`. It remembers every `PlexTrack` it has listed, keyed by `ratingKey`, so a `.track` id can be played without a second request; an id it never listed throws `.notFound`. (A `GET /library/metadata/<id>` fallback is a follow-up that needs a recorded fixture.)
- **Playlists are declared unsupported by Plex for now.** PlexKit has no playlist endpoint and no recorded fixture; `PlexBackend.capabilities` omits `.playlists` and `playlists(page:)` throws `.unsupported(.playlists)`. The browser hides what a backend does not declare. Adding `/playlists` is a follow-up issue with a fixture recorded by `scripts/record-plex-fixtures.sh`.
- **Search is three parallel Plex queries.** Plex's `title=` filter is per type; `searchArtists`/`searchAlbums` are added to `PlexEndpoints.swift` beside `searchTracks` (same list call with `type=8`/`9`). The three run in a task group and merge into `SearchResults`.
- **Artwork goes through the protocol as an opaque `ArtworkRef`.** For Plex the ref is the `thumb` path; `artwork(_:maxPixels:)` fetches `/photo/:/transcode?url=<thumb>&width=&height=&minSize=1&upscale=1` through `PlexClient.request` (token in the header) with the backend's own ephemeral no-cache `URLSession` (`PlexPartDownloader.makeSession()`), so Foundation's `Cache.db` never holds a Plex response. The in-memory cache and placeholder are #0017.
- **No launch-time I/O.** `PlayerModel` builds the backend but never calls `connect()`; the browser (#0016) connects when it opens. Transport and the stream on This Mac work without a connection. The Keychain is read only inside `connect()` and, as today, inside the part downloader.
- **The composition root is the only app code that names Plex.** `PlayerModel.init` calls `PlexPlaybackStack.standard()`; everything else in `PlayerModel` and the views uses `any MusicBackend`, `OutputDevice`, `NowPlaying`. The Settings tabs stay source-specific by design (`PlexSettingsView` imports PlexKit, `CacheSettingsView` imports TrackCache); #0063 adds the picker.
- **Verification is `scripts/run-tests-vm.sh --launch` only.** No `swift test`, `xcodebuild` or app launch on the host. Every test answers from `StubURLProtocol` routes or an in-process player; no test opens an audio device (section 9 says how), nothing reaches joe, no token exists in the guest, and no error, log line, URL or file may carry the test secret.

public struct OutputDevice: Identifiable, Hashable, Sendable {
    public struct ID: Hashable, Sendable, Codable, RawRepresentable { public var rawValue: String }
    public enum Kind: Hashable, Sendable { case thisMac, remote }
    public var id: ID; public var name: String; public var kind: Kind; public var isAvailable: Bool
    public static let thisMacID = ID(rawValue: "this-mac")
    public static let thisMac = OutputDevice(id: thisMacID, name: "This Mac", kind: .thisMac, isAvailable: true)

public enum TransportCommand: Hashable, Sendable {
    case play, pause, togglePlayPause, stop, next, previous
    case seek(TimeInterval)
    case setVolume(Float)   // 0...1
}

public enum PlayMode: Hashable, Sendable {
    /// Replace what is queued and start at `startIndex` of the expanded items.
    case replace(startIndex: Int = 0)
    /// Append; playback starts only if the output was idle with nothing queued.
    case append

public struct NowPlaying: Hashable, Sendable {

    public var output: OutputDevice.ID
    public var state: State
    public var item: MediaID?            // nil for a local file opened outside any backend
    public var title: String?; public var artist: String?; public var album: String?
    public var duration: TimeInterval?
    /// Position at `updatedAt`; use `elapsed(at:)` while playing.
    public var elapsed: TimeInterval
    public var updatedAt: Date
    public var volume: Float?
    public var artwork: ArtworkRef?
    public static func idle(on output: OutputDevice.ID, at date: Date = Date()) -> NowPlaying
    public func elapsed(at now: Date) -> TimeInterval   // elapsed + (now - updatedAt) when playing, else elapsed; clamped to duration
}

### 3. `MusicBackendKit`: the protocol (`Sources/MusicBackendKit/MusicBackend.swift`)

```swift
public protocol MusicBackend: AnyObject, Sendable {
    /// "plex", "musicAssistant", "folder": the key Settings and logs use.
    var sourceID: String { get }
    var displayName: String { get }
    var capabilities: BackendCapabilities { get }

    /// Reads settings, reaches the server, picks the library. Idempotent; throws `MusicBackendError`.
    func connect() async throws
    func disconnect() async

    func artists(page: PageRequest) async throws -> Page<LibraryArtist>
    /// `artist == nil` lists every album.
    func albums(of artist: MediaID?, page: PageRequest) async throws -> Page<LibraryAlbum>
    func tracks(of album: MediaID) async throws -> [LibraryTrack]
    func playlists(page: PageRequest) async throws -> Page<LibraryPlaylist>
    func tracks(ofPlaylist playlist: MediaID) async throws -> [LibraryTrack]
    func search(_ query: String, limit: Int) async throws -> SearchResults
    /// Bytes of an image no larger than `maxPixels` on its long side.
    func artwork(_ ref: ArtworkRef, maxPixels: Int) async throws -> Data

    func outputs() async throws -> [OutputDevice]
    /// Album and playlist ids expand to their tracks, in order.
    func play(_ items: [MediaID], on output: OutputDevice.ID, mode: PlayMode) async throws
    func transport(_ command: TransportCommand, on output: OutputDevice.ID) async throws
    /// Yields the current snapshot at once, then one per change. Ends when the subscriber cancels.
    func nowPlaying(on output: OutputDevice.ID) async -> AsyncStream<NowPlaying>
}
```

Actor conformers mark `sourceID`, `displayName` and `capabilities` `nonisolated` (`public nonisolated let sourceID = "plex"`). `nowPlaying(on:)` is `async` so an actor can hop to the main-actor output without a `nonisolated` escape hatch.

### 4. `LocalPlayback`: `LocalPlayerOutput` (`Sources/LocalPlayback/LocalPlayerOutput.swift`)

```swift
/// An AudioCore `Track` plus the library id it came from (nil for a plain local file).
public struct LocalQueueItem: Hashable, Sendable {
    public var track: Track; public var id: MediaID?
}

/// `AudioCore.Player` as the "This Mac" output: queue, transport and the now-playing stream.
@MainActor
public final class LocalPlayerOutput {
    public let player: Player
    public static let device = OutputDevice.thisMac
    public init(player: Player)

    /// `.replace`: clearQueue, enqueue, play(at: startIndex) (clamped). `.append`: enqueue; play(at: firstNew) only
    /// if the player was stopped with an empty queue (the `importLocalFiles` rule).
    public func play(_ items: [LocalQueueItem], mode: PlayMode)
    public func perform(_ command: TransportCommand)   // play/pause/togglePause/stop/next/previous/seek(to:)/volume =
    public func snapshot(at date: Date = Date()) -> NowPlaying
    /// Subscription-time snapshot, then one per `PlayerEvent` and per `perform(.setVolume)`.
    public func nowPlaying() -> AsyncStream<NowPlaying>
    /// Live subscriptions (tests).
    public private(set) var subscriberCount: Int
}
```

Rules:

- The registry `ids: [UUID: MediaID]` is filled in `play(_:mode:)` from each item's `track.id`, cleared on `.replace`, and pruned to `player.queue.tracks` ids after each enqueue (local files opened through the app's own `player.enqueue` are simply absent → `item == nil`).
- `snapshot`: `state` maps `PlaybackState` one-to-one; `title/artist/album/duration/item` from `player.queue.current` (nil → all nil, state stays whatever the player says); `elapsed = player.currentTime`; `volume = player.volume`; `output = Self.device.id`.
- `nowPlaying()`: `AsyncStream(bufferingPolicy: .bufferingNewest(1))`; register a `player.addEventObserver` whose handler yields `snapshot()`; yield the initial snapshot before returning; `onTermination` hops to the main actor (`Task { @MainActor in … }`) to `removeEventObserver` and decrement `subscriberCount`. Volume changes are not `PlayerEvent`s, so `perform(.setVolume)` yields to every live continuation (keep them in a dictionary keyed by a UUID).
- `perform(.seek(t))` → `player.seek(to: t)`; `.setVolume(v)` → `player.volume = v` (Player clamps). Never touches the engine directly.

### 6. `PlexBackendKit`: `PlexBackend` (`Sources/PlexBackendKit/PlexBackend.swift`)

```swift
/// What the backend needs from Settings. Not Codable (it holds the token); prints redacted.
public struct PlexBackendSettings: Sendable, CustomStringConvertible, CustomDebugStringConvertible, CustomReflectable {
    public var selection: PlexServerSelection

public actor PlexBackend: MusicBackend {
    public typealias SettingsProvider = @Sendable () throws -> PlexBackendSettings?

    public nonisolated let sourceID = "plex"
    public nonisolated let displayName = "Plex"
    public nonisolated let capabilities: BackendCapabilities = [.search, .artwork, .localOutput]

    /// `session` is used for every request the backend makes (JSON, artwork). Ephemeral and uncached by default.
    public init(settings: @escaping SettingsProvider, clientIdentifier: String, output: LocalPlayerOutput,
                session: URLSession = PlexPartDownloader.makeSession(), connectionTimeout: TimeInterval = 15)

    /// Saved selection from `defaults`, token from `tokenStore`; nil when the address is empty or there is no token.
    public static func settingsProvider(defaults: UserDefaults = .standard,
                                        tokenStore: any PlexTokenStore = KeychainPlexTokenStore()) -> SettingsProvider

    public private(set) var isConnected: Bool
    public private(set) var machineIdentifier: String?   // after connect()
    // … the protocol methods
}
```

Behaviour, each rule tested in section 9:

- **`connect()`**: provider → nil ⇒ `.notConfigured("Add the Plex server address and sign in under Settings › Plex.")`, no request. Otherwise `PlexConnectionTest(clientIdentifier:session:timeout:).run(address:token:)`; `PlexConnectionFailure` maps: `.invalidAddress` → `.notConfigured(message)`, `.unauthorized` → `.unauthorized`, `.noMusicLibrary` → `.notConfigured(message)`, `.unreachable` → `.unreachable(message)`, `.cancelled` → rethrow `CancellationError()`. The section is `selection.selectedSection(in: connection.musicSections)`, else the only music section, else `.notConfigured("Choose a music library under Settings › Plex.")`. Store `PlexClient(baseURL: connection.baseURL, token:, clientIdentifier:, session:)`, the section key and `connection.identity.machineIdentifier`. Calling `connect()` again re-reads settings (so a changed address takes effect). `disconnect()` clears all three and the track memory.
- **Library calls before `connect()`** throw `.notConnected`; `PlexError` from the client maps to `.unauthorized` (401) or `.backend(error.errorDescription)`; `CancellationError` passes through.
- **Mapping** (`Sources/PlexBackendKit/PlexMapping.swift`, pure functions, unit-tested):
  - `LibraryArtist(id: MediaID(.artist, ratingKey), name: title, sortName: titleSort, artwork: thumb.map(ArtworkRef.init))`.
  - `LibraryAlbum(id: .album ratingKey, title, artistID: parentRatingKey.map { .artist }, artistName: parentTitle, year, trackCount: leafCount, artwork: thumb ?? parentThumb)`.
  - `LibraryTrack(id: .track ratingKey, title, artistID: grandparentRatingKey, artistName: grandparentTitle ?? "", albumID: parentRatingKey, albumName: parentTitle, trackNumber: index, discNumber: parentIndex, duration: durationSeconds, bitrate: media.first?.bitrate, sampleRate: nil, channels: media.first?.audioChannels, artwork: thumb ?? parentThumb)`.
  - `Page.make(items:request:total: plexPage.totalSize)` with `PlexPageRequest(start: offset, size: limit)`.
- **Listing**: `artists` → `client.artists(in:page:)`; `albums(of: nil)` → `client.albums(in:)`; `albums(of: artist)` → `client.albums(of: artist.rawValue)` (kind must be `.artist`, else `.notFound`); `tracks(of: album)` → `client.allItems { client.tracks(of:page: $0) }` so a long album is complete; every `PlexTrack` returned by `tracks(of:)` or `search` is remembered in `knownTracks[ratingKey]`.
- **`search(query, limit)`**: empty/whitespace query → `.empty` without a request; else three concurrent calls (`searchArtists`, `searchAlbums`, `searchTracks`, each `PlexPageRequest(start: 0, size: limit)`) in a `withThrowingTaskGroup`, merged in artists/albums/tracks order.
- **`playlists`/`tracks(ofPlaylist:)`** → `.unsupported(.playlists)`.
- **`artwork(ref, maxPixels)`**: `client.request(path: "/photo/:/transcode", query: [url: ref.rawValue, width: maxPixels, height: maxPixels, minSize: "1", upscale: "1"])` with `Accept: image/*`; `session.data(for:)`; 200–299 → bytes, 401 → `.unauthorized`, 404 → `.notFound(MediaID(.album, ref.rawValue))`… simpler: any non-2xx → `.backend("The server answered with status N.")`; `URLError` → `.unreachable(PlexError.transport(code).errorDescription)`.
- **`outputs()`** → `[LocalPlayerOutput.device]`, no connection needed.
- **`play(items, on:, mode:)`**: output must be `thisMacID` else `.unknownOutput`; needs a connection (`.notConnected`) because tracks need `machineIdentifier`; expand: `.track` → `knownTracks[id]` or `.notFound(id)`; `.album` → `tracks(of:)` (which also records them); `.artist`/`.playlist` → `.unsupported(.playlists)` for playlist, albums-then-tracks for artist is optional, `.notFound` is acceptable for this pass. Map each with `Track(plexTrack:machineIdentifier:)`; skip (log `info`) the ones that throw `.notPlexTrack`; if nothing remains throw `.backend("None of these tracks has a file on the Plex server.")`; `await output.play(items, mode:)` on the main actor.
- **`transport(cmd, on:)`**: `thisMacID` → `await output.perform(cmd)`; anything else `.unknownOutput`. No connection needed.
- **`nowPlaying(on:)`**: `thisMacID` → `await output.nowPlaying()`; anything else an empty, immediately finished stream.
- **Logging**: `Logger(subsystem: "com.brennanmke.SkinAmp", category: "PlexBackend")`: `info` for connect outcomes by case name, counts per listing (`debug`), never an address, query, token, or error body. `PlexClient.fetch` already logs method + path.

### 7. `PlexBackendKit`: the app's composition (`Sources/PlexBackendKit/PlexPlaybackStack.swift`)

Moves the construction currently in `PlayerModel.init` out of the app:

```swift
/// Everything the app needs to play Plex through AudioCore, built in the right order (cache → resolver → player → pinner → backend).
@MainActor
public struct PlexPlaybackStack {
    public let cache: TrackCache
    public let player: Player
    public let pinner: CachePinner            // installed
    public let output: LocalPlayerOutput
    public let backend: PlexBackend

    public static func standard(defaults: UserDefaults = .standard,
                                tokenStore: any PlexTokenStore = KeychainPlexTokenStore()) -> PlexPlaybackStack
}
```

`standard()` does what `PlayerModel.init` does today: `TrackCache(directory: .defaultDirectory(), limitBytes: CacheSettingsModel.storedLimit(in:), downloader: PlexPartDownloader(clientProvider: .settingsClientProvider(defaults:tokenStore:)))`, `Player(resolver: PlexTrackResolver(cache:savedMachineIdentifier:))` with the same defaults-reading closure, `CachePinner(cache:player:).install()`, `LocalPlayerOutput(player:)`, `PlexBackend(settings: .settingsProvider(defaults:tokenStore:), clientIdentifier: PlexClientIdentifier.stored(in: defaults), output:)`. ### 13. Risks and gotchas

- **Actor conformance details.** Protocol properties on `PlexBackend` must be `nonisolated let`; `nowPlaying(on:)` is `async` for that reason. `LocalPlayerOutput` is `@MainActor` and therefore `Sendable`; the actor stores it in a `let` and `await`s its methods.
- **Stream termination runs off the main actor.** `AsyncStream.onTermination` is `@Sendable`; hop with `Task { @MainActor in … }` before touching the output's state. Use `bufferingNewest(1)`: a slow subscriber must see the latest snapshot, not a backlog.
- **`Player.state = .loading` is synchronous, the stream is not.** The play indicator in the app now updates one hop later; acceptable, and the tests poll.
- **Do not reach the engine in tests.** Any track that `AVAudioFile` can open makes `Player.begin` call `ensureGraph()` and `graph.start()`, which opens the output device. Random stub bytes and non-existent paths are the only inputs these test targets may use.
- **`StubURLProtocol` route order and `times`.** Routes match first-wins; a 401 override for a path must be registered instead of, not after, the fixture route. Both the connection test and the client use `handle.session`, or the recorded requests will not be seen.
- **`PlexConnectionTest` sends `/identity` without the token** (by design); the backend's client is built with the token afterwards. The `settingsProvider` must not log the address at `info` with a `plex.direct` host containing the server hash; the existing log lines log `host` only, keep it that way.
- **Keychain in the guest.** `PlexBackend.settingsProvider(tokenStore:)` is only ever called with `KeychainPlexTokenStore` from `PlexPlaybackStack.standard()`, which the app calls, not the tests. Tests pass closures. A keychain prompt in the headless guest would hang the run.
- **Memory of `knownTracks`.** Unbounded by design for this pass (a listing is at most thousands of small structs); `disconnect()` clears it. Note it in `## Gotchas` if it bothers the reviewer.
- **Three parallel search requests per query** are fine behind the browser's debounce (#0016); do not add a client-side cache here.
