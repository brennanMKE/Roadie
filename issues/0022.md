### Elapsed/remaining toggle

Webamp: `#time` `onClick` dispatches `TOGGLE_TIME_MODE`; the reducer flips `ELAPSED` ↔ `REMAINING` (default `ELAPSED`); `Time.tsx` shows `timeElapsed` or `duration - timeElapsed` and the minus sign only in remaining mode. Here: `PlayerModel.toggleTimeMode()` flips `timeMode` and writes it to UserDefaults; `TimeDigits.shown(mode:elapsed:duration:)` does the subtraction and clamps at 0 (metadata duration and file length can disagree by under a second, so the raw difference goes slightly negative at the end). Elapsed and remaining both floor to whole seconds, as `getTimeObj` does.

### Binding to the player and update rate

- No new timer for the digits: `MainWindowView` reads `model.mainWindowStatus`, which reads `player.currentTime`; `@Observable` re-evaluates the body on every 100 ms tick while playing. The digits change once a second and SwiftUI diffs four small `Image`s, so this is cheap. If Instruments shows otherwise, wrap the digits in a child view that takes `Int(elapsed)` so the child body runs once a second.
- Pause blink: `.pause #time` runs `blink 2s step-start 1s infinite`, i.e. the time stays visible for 1 s after pausing, then hides 1 s / shows 1 s. Implement with `TimelineView(.periodic(from: pauseDate, by: 1))` (or a `Task` with `Task.sleep(for: .seconds(1))`) that only exists while `status.blinksTime`, toggling `.opacity(0)` on the time group; it must be torn down when state leaves `.paused` so the app has no idle wakeups.
- Track change and seek need nothing extra: `currentTime` is reset to 0 before the queue publishes the new track, and `seek(to:)` sets it directly.
- Mono/stereo and kHz prefer `player.currentFormat` (the opened file) and fall back to the `Track` metadata, so Plex tracks show the right values and local tracks show them while still loading.

## Root cause

The main window drew only the play/pause/stop indicator. Nothing turned the player's position, track metadata or file format into time digits, kbps/kHz text or mono/stereo, and there was no elapsed/remaining toggle.

## Fix

Followed the plan: SkinKit `Display/` holds `TimeDigits` (+`TimeMode`), `MediaInfoText`, the `Skin` digit helpers and the pure `MainWindowStatus`/`Transport`; `AudioCore` gains `PlaybackFormat` and `Player.currentFormat` (set from `fileFormat` in `begin`, on pre-scheduled advance; cleared in `stop` and at the start of `startCurrentTrack`); the App gets `MainWindowStatusLayer` (new `App/MainWindowStatusView.swift`) replacing the inline indicator, and `PlayerModel.timeMode`/`toggleTimeMode()`/`mainWindowStatus`. Time click area is 59x13 at (39, 26); pause blink is a child view whose task lives only while paused.

Adaptations to landed code:
- #0020: no separate `DigitFont` selection. `Skin.usesNumsEx` and `Skin.resolve` already pick NUMS_EX over NUMBERS, so `digitSpriteName(n)` is just `DIGIT_n` and the minus/no-minus sprites are `MINUS_SIGN`/`NO_MINUS_SIGN` (resolved to the `_EX` cell when NUMS_EX exists). `Skin.minusFrame` carries the geometry that differs (NUMBERS 5x1 at (38, 32); NUMS_EX 9x13 at (38, 26)).
- #0021: kbps/kHz are drawn with `skin.textImage(_:)` at (111, 43) and (156, 43); no placeholder needed.
- #0062: `PlayerModel` follows a `NowPlaying` stream, so the transport comes from `nowPlaying.state`. On This Mac, elapsed is `player.currentTime`, bitrate/format come from `player.queue.current` and `player.currentFormat`; for other outputs elapsed is `nowPlaying.elapsed(at:)` and bitrate/format are nil (the snapshot has none).
- `MediaInfoText`: the plan's examples were checked against Webamp's actual code. `massageKhz` shows only the first digit for <= 10 kHz (so 10000 Hz reads " 1") and characters 1...2 for >= 100; `massageKbps` shows the first two digits plus `H` for >= 1000 and the first digit plus `C` for >= 10000 (1411 -> "14H", 12345 -> " 1C"). Ported faithfully.
- `MINUS_SIGN`/`NO_MINUS_SIGN` names are exposed as `Skin.minusName`/`noMinusName`; the minus frame is a property rather than the plan's tuple. The `DigitFontTests` assert through `resolve` accordingly.
- 3-px work indicator is cropped in the view (`frame(width: 3, ...).clipped()`).
