# 0240 — There is no way to pick a visualization preset from a list

| | |
|---|---|
| **Status** | open |
| **Module** | App |
| **Platform** | macOS |
| **First seen** | 2026-10-29 |

## Description

MilkDrop's L opened a preset browser over the picture: the presets folder as a list, arrows to move, Enter to load. With #0236 Roadie's visualization can only step through presets one at a time; with a folder of hundreds of `.milk` files (after #0241 and #0243) that's no way to find one.

Design: [docs/design/visualization.md](../docs/design/visualization.md) §2.8, §5.2.

## Plan

- `VisualizationModel.isListOpen` (introduced as a stand-in flag by #0237; real now), toggled by L (`presetList`) and the right-click menu's Presets… (enabled now). While open: overlay hold `.browser`, auto-advance suspended; Esc closes it first (#0237's order).
- `VisualizationPresetListView` (SwiftUI, in the overlay hosting view, centred panel max 480×70 % of the height, dark material; `vis.browser`):
  - a search field (`vis.browser.search`), focused on open; typing filters by `localizedStandardContains` on the name;
  - a `List` of `navigator`'s presets in catalogue order (`vis.browser.row.N`, N in the filtered list; label = name; value `current` for the shown preset, `failed` for a failed one), with a trailing source tag "Classic" / "MilkDrop" / "Yours" (secondary); failed rows dimmed with "Couldn't load"; the current row selected and scrolled to on open;
  - ↑ ↓ move the selection (the list handles them while it has focus; the search field forwards ↑ ↓ and Return to the list via `onKeyPress`), Return or double-click loads the selected (`navigator.select(id:)`, 1.7 s blend) and closes, Esc closes.
- Keys while the list is open go to it, not `VisKeyMap` (the host view's `keyDown` returns early when `isListOpen`), except Esc and ⌥Return.
- The list reads the presets once on open (the catalogue changes only when Settings' folder changes, #0241).

## By hand

1. Full screen, press L: a list over the picture with the current preset highlighted; the picture keeps moving behind it; the overlay stays up.
2. Type a few letters: the list narrows. ↑ ↓ and Return: that preset blends in, the list closes.
3. Double-click a row: same. Esc: closes without changing anything; a second Esc leaves full screen.
4. With a large user folder (after #0241/#0243): the list opens quickly and scrolls smoothly.
