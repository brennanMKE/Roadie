## Root cause

M14 renamed the app to Roadie (W2 to W4), but the README, the tracker heading and `project.json`, the current docs and
NOTICE still described SkinAmp, and release.md's Gate A named a `scripts/check-rename.sh` that didn't exist yet.

## Fix

- README rewritten for Roadie: tagline "Roadie: a Winamp-skinned player for Music Assistant", the download site,
  requirements (macOS 14, a Music Assistant server and token), development through XcodeGen and `scripts/verify.sh`,
  a docs index, and credits. "The project was called SkinAmp during development." is its only old-name mention.
- `issues/Issues.md` heading and `issues/project.json` `name` are now Roadie. The `url` stays until the GitHub rename (W14).
- `docs/testing-in-vm.md`, `docs/sendspin-notes.md`, `docs/music-assistant-integration.md` and
  `docs/issues-workflow.md` now say Roadie. `docs/plan.md` gains an M14 section.
- NOTICE adds ZIPFoundation (MIT). Its copyright line, "2017-2025 Thomas Zoechling", matches the checked-out LICENSE.
- Review fixes (83f5e05):
  - `Issues.md` said `SKINAMP_SLOW_TESTS`; it's now `ROADIE_SLOW_TESTS`.
  - `ma-protocol-notes.md` and `design/playlists.md` named the recorder's playlist "SkinAmp fixture"; it's "Roadie fixture".
  - `design/playlists.md` named the old media-id UTI; it's `co.sstools.roadie.media-id`.
  - Added `scripts/check-rename.sh`. It's host-only and read-only, uses `git grep`, has an explicit allowlist and isn't a VM step.
  - release.md's Gate A now matches reality:
    - the script and its allowlist;
    - the actual README sentence;
    - the transitional `skinamp-test-` cleanup is recorded as dropped in #0155 (§2.1 step 3, W3, W5, open question 10).
