# 0234 — Nothing decides when a visualization changes preset on its own, when its overlay hides, or what its keys do

| | |
|---|---|
| **Status** | open |
| **Module** | VisualizationKit |
| **Platform** | macOS |
| **First seen** | 2026-10-29 |

## Description

Four rules of the visualization window are timing and key logic that should be pinned by fast tests before any window exists (design §2.4, §2.5, §1.4, §6):

- **Auto-advance:** MilkDrop changes preset every 16 s plus a random extra, pauses while locked or while its browser is open, and restarts the countdown after a manual change.
- **Overlay idle:** the song overlay and the cursor hide 3 s after the mouse last moved, come back on movement, and stay up while paused, while VoiceOver runs, while a menu, the list or help is open, and while the pointer is on the overlay.
- **Keys:** ← → previous/next, Space/⌫, H, R, \`, L, T, F1/?, F2–F5, ⌥Return, Esc, Z X C V B, ↑ ↓; no ⌘ combinations; letters don't repeat.
- **Settings:** the keys, types and defaults the window and Settings pane share.

None exists. This issue adds them to `VisualizationKit` (#0233).

## Plan

All in `Packages/PlayerKit/Sources/VisualizationKit/`, Foundation only, no clocks: every time is a `TimeInterval` the caller passes (the app passes `CACurrentMediaTime()`), every random choice uses #0233's `SplitMix64`.

### `AutoAdvanceClock.swift`

```swift
public struct AutoAdvanceClock: Sendable {
    public struct Policy: Equatable, Sendable {
        public var isEnabled: Bool; public var interval: TimeInterval; public var varies: Bool
        public static let maxExtra: TimeInterval = 10
    }
    public init(policy: Policy, seed: UInt64)
    public var policy: Policy                      // setting it re-plans from the last restart
    public private(set) var deadline: TimeInterval?
    public private(set) var isSuspended: Bool
    public mutating func restart(at now: TimeInterval)       // deadline = now + interval (+ uniform 0…maxExtra if varies); nil if disabled
    public mutating func suspend(at now: TimeInterval)
    public mutating func resume(at now: TimeInterval)        // deadline += suspended duration
    public mutating func isDue(at now: TimeInterval) -> Bool // true once when now >= deadline and not suspended; clears deadline
}
```

The caller (the window, #0236) restarts it after every load, manual or automatic, and suspends it for: window not rendering, browser/help/menu open, the flashing notice, Reduce Motion (#0242). Lock is the navigator's (`advanceAutomatically()` returns nil); the clock still fires and the caller just restarts it.

### `OverlayVisibility.swift`

```swift
public struct OverlayVisibility: Sendable {
    public enum Hold: Hashable, Sendable { case notPlaying, voiceOver, browser, help, menu, pointerOnOverlay, notice }
    public init(idleTimeout: TimeInterval?, now: TimeInterval)   // nil or <= 0 = never hide; starts visible
    public var idleTimeout: TimeInterval?
    public private(set) var isOverlayVisible: Bool
    public private(set) var isCursorHidden: Bool
    public private(set) var holds: Set<Hold>
    public mutating func show(at now: TimeInterval)                     // window opened / entered full screen
    public mutating func pointerMoved(at now: TimeInterval, inside: Bool)
    public mutating func pointerExited(at now: TimeInterval)
    public mutating func setHolds(_ holds: Set<Hold>, at now: TimeInterval)
    public mutating func tick(at now: TimeInterval)
    public var nextDeadline: TimeInterval? { get }                      // lastActivity + timeout, nil when held or never
}
```

Rules: movement (inside) shows the overlay and the cursor and records `lastActivity`; `tick` at or after `lastActivity + timeout` with no holds hides the overlay, and hides the cursor only if the pointer is inside; `pointerExited` marks the pointer outside (cursor never hidden then; the overlay still hides on time); any hold shows it and the cursor at once and stops the countdown; releasing the last hold restarts the countdown from that moment. Keys don't feed it.

### `VisKeyMap.swift`

```swift
public enum VisKey: Hashable, Sendable { case character(String), left, right, up, down, space, delete, escape, returnKey, function(Int) }
public enum VisTransport: Sendable { case previous, play, pause, stop, next, volumeUp, volumeDown }
public enum VisReadout: String, CaseIterable, Sendable { case title, time, preset, fps }
public enum VisCommand: Hashable, Sendable {
    case nextPreset, previousPreset, hardCut, toggleOrder, toggleLock, presetList, showSongTitle, help
    case toggleReadout(VisReadout), toggleFullScreen, escape, transport(VisTransport)
}
public enum VisKeyMap {
    public static func command(for key: VisKey, command: Bool, control: Bool, option: Bool, shift: Bool, isRepeat: Bool) -> VisCommand?
    /// One row per command for the help card and the right-click menu (#0236, #0239), in design §2.5's order.
    public static let rows: [(keys: String, title: String, command: VisCommand)]
}
```

Mapping (design §2.5): right/space → `nextPreset`; left/delete → `previousPreset`; `h` hardCut; `r` toggleOrder; `` ` `` toggleLock; `l` presetList; `t` showSongTitle; F1 or `?` help; F2 title, F3 time, F4 preset, F5 fps; ⌥Return toggleFullScreen (option allowed only here); escape; `z x c v b` transport; up/down volume. Letters case-insensitive (Caps Lock). `isRepeat`: only up/down return a command. ⌘ or ⌃ → nil always; ⇧ → nil except `?` (which needs ⇧ on most layouts: accept `?` with or without shift). `VisKey` keeps AppKit out: the app maps `NSEvent` (`charactersIgnoringModifiers`, `specialKey`) to it.

### `VisualizationSettings.swift`

A struct with every key in design §6 (`autoAdvance`, `autoAdvanceSeconds` clamped 5…300, `autoAdvanceVaries`, `blendSeconds` 0…10, `order`, `locked`, `lastPreset`, `presetsFolder: String?`, `overlayIdleSeconds` (0 = never), `songTitleOnTrackChange`, `readouts: Set<VisReadout>`, `openOnPlay`, `windowOpen`, `changeWithReduceMotion`, `flashNoticeShown`), `static let defaults`, `static func load(from: UserDefaults) -> Self` (missing or wrong-typed keys fall back to the default, out-of-range values clamp), `func save(to: UserDefaults)`, and `var autoAdvancePolicy: AutoAdvanceClock.Policy`. Constants: `static let keyBlend: TimeInterval = 1.7` (keys and the list), `static let reducedMotionMinimumBlend: TimeInterval = 5` (Dim Flashing Lights, #0242). Key names `visualization.<name>` as the table.
