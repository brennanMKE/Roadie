# 0013 — Plex tracks are not downloaded to a local LRU cache

| | |
|---|---|
| **Status** | open |
| **Module** | TrackCache |
| **Platform** | macOS |
| **First seen** | 2026-10-12 |

## Description

Add a `TrackCache` library that downloads Plex parts to `~/Library/Caches/<bundle id>/Tracks/`, indexes them, and evicts least-recently-used files above a size limit.

## Acceptance criteria

- Cache key = server `machineIdentifier` + part id + part `updatedAt`; extension from the part.
- Download to a temp file, check size against `Part.size`, then move into place; concurrent requests for the same key share one download.
- Index records size and last access; every play touches it; rebuilt from disk if missing or corrupt; partial temp files removed on launch.
- LRU eviction after each insert down to the limit (default 2 GB); the playing and prefetched tracks are pinned.
- Prefetch the next queued track when a track starts; cancel on skip.
- Settings › Cache shows usage, the limit, and Clear cache.
- Unit tests: eviction order, pinning, size accounting, index rebuild, with temp dirs and a stub downloader.
