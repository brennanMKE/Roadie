# 0080 — Transport has no Winamp keyboard shortcuts or Playback menu

| | |
|---|---|
| **Status** | open |
| **Module** | App |
| **Platform** | macOS |
| **First seen** | 2026-10-18 |

## Description

The skinned windows ignore Winamp's transport keys. Winamp uses **Z** previous, **X** play, **C** pause, **V** stop, **B** next, left/right arrows to seek 5 s, up/down for volume, **L** open file. SkinAmp's menu bar (`App/SkinAmpApp.swift`) has File and Window commands but no Playback menu, so the transport is only reachable by clicking the skin or with media keys.

Expected: a Playback menu with Previous, Play, Pause, Stop, Next, Seek Forward/Back, Volume Up/Down, Shuffle and Repeat, and the Winamp letter keys working while any skinned window is key. Shortcuts must not fire while a text field (for example Library search or Settings) has focus, and must not clash with existing commands (⌘L, ⌘K, ⌘O and the window shortcuts).
