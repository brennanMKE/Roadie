# 0258 — Roadie ships no MilkDrop presets, and Release hides the presets folder setting

| | |
|---|---|
| **Status** | open |
| **Module** | App |
| **Platform** | macOS |
| **First seen** | 2026-10-30 |

## Description

With [#0243](0243.md) and [#0257](0257.md) the window can draw `.milk` presets beside the classics, but a Release build has none to draw: Roadie bundles no presets, and Settings › Visualization's presets folder row is Debug-only (#0241's `showsPresetsFolder`). MilkDropMetalKit 1.0.0 doesn't vend presets (its `MilkMetal` target has no resources and no list API); its `Presets/` folder holds 42 MIT presets written for the package, one per renderer feature, with `spike-tunnel.milk` as the showcase and `gallery.json` giving each a title. This is the piece that puts MilkDrop in front of users for 0.0.5.

Split from #0243 on 2026-10-30 (see its `## Notes`). Design: [docs/design/visualization.md](../docs/design/visualization.md) §5.1, §5.3, §8.3, §11 question 5 (default: the package's own MIT presets).

## Plan

### Bundle the package's presets

- `scripts/update-milkdrop-presets.sh [TAG] [REPO]` (host only, read-only on the package; defaults `1.0.0` and `../MilkDropMetalKit`): `git -C "$REPO" archive "$TAG" Presets | tar -x` into a temp dir, then replace `App/Visualization/Presets/` with its `*.milk`, `gallery.json` and `README.md`, and write `App/Visualization/Presets/VERSION` with the tag and commit (`git -C "$REPO" rev-parse "$TAG^{commit}"`). Refuses when `TAG` doesn't exist; never checks out, fetches or builds in `REPO`. Run it once for `1.0.0` (→ `d9c4fb4`) and commit the 42 presets (64 KB).
- All 42, as design §11 question 5 defaults (see `## Notes` for the user's choice). Licence: the package's MIT (`Presets/README.md`: "written for this package and released under its MIT licence"); `NOTICE` (MilkDropMetalKit's entry from #0243) gains one line: "Roadie bundles the presets from MilkDropMetalKit 1.0.0's Presets/ folder, under the same MIT licence."
- `project.yml`: the folder ships as one folder reference in the app's resources (`Contents/Resources/MilkDropPresets/`), not as 42 loose files in the group: in the `Roadie` target, exclude `Visualization/Presets` from `sources: [App]` and add `- path: App/Visualization/Presets`, `type: folder`, `buildPhase: resources` (check the result with `xcodegen generate` and the Info.plist/bundle check; name the destination whatever XcodeGen gives, and read it through one constant).

### Catalogue

- `PresetCatalog.bundled(in folder: URL) -> [VisualizationPreset]` (VisualizationKit): `scan(folder:source: .bundled)`, then names from `gallery.json` when it's there (`file` → `title`, e.g. "Spike Tunnel", "Mode 0: Circle"), else the file name. Ids stay `bundled:<file name>`. A missing folder or unreadable JSON gives the scan with file names. Unit tested over a temp folder.
- `VisualizationModel`: `bundledPresets` loaded once (off the main actor in `init`, like `reloadCatalogue`) from `Bundle.main`'s preset folder; `prepareRenderer` and `applyCatalogue` list `classics + bundledPresets + userPresets`. Catalogue order stays §5.1's: classics, then every `.milk` by name. Tests inject the folder (an `init` parameter or a `bundledPresetsFolder` property set before first open), never `Bundle.main` of the test runner by accident.
- Default start preset: when `visualization.lastPreset` is unset (a fresh install), start on `bundled:spike-tunnel.milk` if the renderer can load it, else the first classic (design §5.3 changes; a remembered preset that's gone still falls back to the first classic).

### Release

- `showsPresetsFolder`: true when the renderer can draw `.milk` (`renderer?.canLoad` of a `.milk` preset, or the factory's answer before first open), in Debug and Release; false only without a Metal device, where the row would add presets nothing can draw.

- docs/milkdrop-metal-handoff.md's upgrade note (#0243): also run `scripts/update-milkdrop-presets.sh <tag>`.
- `website/help.html` `#visualization`: one sentence on the bundled MilkDrop presets and adding your own folder in Settings › Visualization.
- `CHANGELOG.md` › Unreleased › Added: "MilkDrop presets in the Visualization window: 42 presets from MilkDropMetalKit, and your own folder of .milk files in Settings › Visualization. The classic visualizations stay in the list."

## By hand

1. A fresh install (or `defaults delete co.sstools.roadie visualization.lastPreset`), play music, open the visualization: it starts on Spike Tunnel; the picture reacts to the bass. → and ←: MilkDrop presets with MilkDrop 2 blends (wipes, plasma, radial).
2. Full screen on the built-in display and an external one: smooth at 60 fps (F5 readout), no tearing; Activity Monitor's GPU and CPU reasonable; minimize: both drop to idle.
3. Release build: Settings › Visualization shows Your presets folder; a folder of `.milk` presets (e.g. a pack you own): the count appears, L lists them, they render; an empty or unreadable one shows "Couldn't load" in the list and is skipped.
4. Pacing: tap a beat-heavy track's kick against the picture: it pulses on the beat, not a tenth of a second late, and doesn't step in chunks.
5. Reduce Motion: transitions are plain crossfades. Dim Flashing Lights: darker, slow crossfades. Look at the flashing ones (Invert, Beat Flash) with Dim Flashing Lights on and off.
6. Music Assistant speaker: the picture idles calmly on silence; switch to This Mac (Sendspin): it reacts.
7. Classic presets still work between MilkDrop ones (← from Spike Tunnel's neighbours reaches the classics with a crossfade).
