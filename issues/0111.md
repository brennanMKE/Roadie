# 0111 — A long Sendspin connection keeps every finished timer task until it disconnects

| | |
|---|---|
| **Status** | open |
| **Module** | SendspinKit |
| **Platform** | macOS |
| **First seen** | 2026-10-19 |

## Description

Found in review of #0105. In `Packages/PlayerKit/Sources/SendspinKit/SendspinSession.swift`, `after` and `afterSleeper` append every per-exchange timeout task and every burst-tick task to `connectionTasks`, and that array is only emptied on disconnect. A connection that stays up grows it by about 9 tasks every 10 s, roughly 3,000 an hour, so memory grows for as long as SkinAmp stays connected as a Music Assistant player.

## Expected behavior

- Finished or cancelled timer tasks are removed (or a single timer per purpose is reused), so the number of tracked tasks stays bounded on a connection of any length.
- Disconnect still cancels every outstanding task.
- A test drives many burst intervals through the injected sleeper and asserts the tracked task count stays bounded.
