| | |
|---|---|

| **Platform** | macOS |

## Description

`ClientConnectionTests.pingIsSentEveryIntervalWhileConnected` (MusicAssistantKitTests) failed once in the VM with `pingCount` 1 where 2 was expected (review run `20261018-211623-56833` of #0079, which does not touch this code). It passed on the re-run.

The #0079 reviewer's reading: the test's `sleeperCount == 1` wait can match the pong-timeout sleeper before the next interval sleeper is registered, so the clock advances too early. The test comes from #0061.

Expected: the test waits for the interval sleeper specifically (or for a state that only exists once it is registered), and passes every time.
