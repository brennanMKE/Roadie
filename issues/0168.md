## Description

website/index.html shows a placeholder where the screenshot goes. The user asked for a carousel of a few skins on the home page, with dots near the bottom, swipe between slides, and an automatic change every 3 seconds.

## Expected behavior

- A repeatable script makes the screenshots in a silent Tart VM: Roadie connected to Music Assistant (credentials from `.env`, never printed or committed), playing tracks from the Electronic playlist on This Mac only, main/EQ/playlist docked, one capture per featured skin, checked for server address/id before commit.
- website/index.html shows the screenshots in a carousel: 3 s autoplay, swipe/drag, dot buttons, pause on hover/focus, still under prefers-reduced-motion, skin name and author on each slide. No libraries; check-website.sh passes.

## Relation

- Parent: [#0151](0151.md)
- Related: [#0167](0167.md)

## Fix

- `scripts/make-screenshots.sh` (+ `scripts/capture-roadie-windows.swift`): builds Roadie in a silent Tart VM (`--no-audio`, guest muted, one leased clone), docks main/EQ/playlist on a plain desktop, plays eight Electronic tracks (copied from joe, never committed) as local files on This Mac, captures each skin 4 s into Daft Punk's Technologic, writes 550x870 PNG + lossless WebP + `manifest.json`.
- Music Assistant was deliberately not connected in the guest: on connect Roadie adopts an output that is already playing and can send it transport commands (#0118/#0121), which could reach a real speaker. `.env` is not read.
- Home page carousel (`website/js/carousel.js`, styles in `css/style.css`): scroll-snap strip with native swipe, mouse drag, arrow keys, dot buttons, 3 s autoplay paused on hover/focus/hidden page and off under reduced motion.
- Featured: Asian Dragon, The NightCrawler. Left out for trademarks/characters: Deus AMP, Make Me Sad, Winamp Classic.

## Verification

`scripts/make-screenshots.sh` exit 0, host audio silent; every PNG inspected (no server address/id). `scripts/check-website.sh` OK. WebKit render at 1280 and 400 px: autoplay advanced and wrapped. `scripts/verify.sh --head` PASS (12 steps, 1568 tests, audio silent).
