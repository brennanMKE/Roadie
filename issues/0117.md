# 0117 — Changing the Output doesn't move what's playing

| | |
|---|---|
| **Status** | open |
| **Module** | App / MusicAssistantKit |
| **Platform** | macOS |
| **First seen** | 2026-10-20 |

## Description

Reported by the user on 0.1.0-2671617. While a Music Assistant track plays on This Mac, choosing Kitchen (a HomePod) in the Library toolbar's Output menu doesn't move playback. It keeps playing where it was; only after stopping, and possibly starting another song, does the new output take effect.

## Expected behavior

- Choosing another output while something plays moves the current queue there right away, at the same position (Music Assistant's queue transfer), and the old output stops.
- The same applies in both directions: This Mac ↔ a speaker, and speaker ↔ speaker.
- If nothing is playing, the choice only sets where the next play goes, as today.
