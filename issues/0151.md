## Description

Prepare the app for public release from a static website, renamed **Roadie**, with the tagline:

> Roadie: a Winamp-skinned player for Music Assistant

Umbrella for the release milestone (M14). Children to be filed once the plan is written.

## Decisions (user, 2026-10-23)

- **Name:** Roadie, everywhere. Rename fully: app name, Xcode project, targets, schemes, module and code identifiers, docs, DMG, About and menus.
- **Bundle identifier:** `co.sstools.roadie` (was `com.brennanmke.skinamp`). Exported UTTypes, defaults keys, Keychain items and app-support paths move to the new prefix.
- **Distribution:** a static website at https://roadie.sstools.co/ on the user's EC2 host. Requirements, paths, appcast rules and the per-release hand-off are in [docs/website-hosting.md](../docs/website-hosting.md). This repo prepares `website/` and publishes GitHub releases (`vX.Y.Z`, assets `Roadie-X.Y.Z.dmg` + `.sha256`); deploying is done outside the repo.
- **Updates:** Sparkle 2 with an EdDSA-signed appcast served from the website.
- **Versions:** semantic versioning (`MAJOR.MINOR.PATCH`) for CFBundleShortVersionString and DMG names; CFBundleVersion stays the UTC `YYYYMMDD.HHMM` build number (#0127) and is what Sparkle compares.
- **Signing:** Developer ID signed, notarized and stapled (notarytool keychain profile stored once by the user).

- **GitHub repo:** the user renames the repo once the in-repo rename is ready; the remote URL, local folder and any repo links are updated together with the user at that point, not before.

## Expected behavior

- One release script turns a tagged version into a notarized, stapled `Roadie-X.Y.Z.dmg`, a signed appcast entry with release notes, and the files to upload to the site.
- A static website (landing page with the tagline, screenshots, download button, release notes, appcast.xml).
- Roadie checks for updates via Sparkle (Check for Updates… menu item, automatic checks setting) and installs them.
- Existing SkinAmp users' settings, Music Assistant servers and Keychain token carry over on first launch of Roadie.

## Open questions

- Where the Sparkle EdDSA private key lives (Keychain on the release Mac is Sparkle's default).
- Trademark: "Winamp" in the tagline is descriptive use; confirm the wording and any disclaimer on the site and in About.
- Minimum macOS version stated on the site.
- Release notes source (CHANGELOG.md vs. per-release file).
