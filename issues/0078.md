# 0078 — The main window's options button opens no menu

| | |
|---|---|
| **Status** | open |
| **Module** | App |
| **Platform** | macOS |
| **First seen** | 2026-10-18 |

## Description

The options button at the left of the main window's title bar (`MAIN_OPTIONS_BUTTON`, `App/TitleBarView.swift:19`) has an empty action. In Winamp it opens the main menu (play file, play location, windows, skins, options such as time elapsed/remaining, always on top, double size, EQ and playlist toggles, playback, exit). Right-clicking the main window opens the same menu in Winamp.

Expected: clicking the options button, or right-clicking the main window, opens an `NSMenu` with the Winamp entries SkinAmp supports, wired to existing `PlayerModel` actions (open, add, open skin, the window and shade toggles, time elapsed/remaining, transport). Entries for features not built yet (for example double size before #0079) are left out rather than shown disabled.
