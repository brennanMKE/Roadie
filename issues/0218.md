## Description

#0212's baseline has `PlayerModel+PlaylistFiles` at 15 % (LIST › Load and Save, export and import of a library playlist) and `PlaylistWindowOverlays` at 12 % (the AppKit row-hit, drag and resize views over the playlist). `JumpToFilePanel` (251 lines) and `PlaylistPickerSheet` (141) are at 0 %. #0211 left the follow-up "Jump to File through the panel": #0210 tested `JumpToFileController`, but nothing drives the panel that owns it.

## Plan

1. `PlayerModel+PlaylistFiles` (`Tests/RoadieTests/PlaylistFilesTests.swift`): inject the open and save panels (a closure seam that returns a URL) so these run headless:
   - `loadList` chooses by target: local loads a file, Music Assistant opens the picker
   - `loadPlaylistFile` loads an `.m3u`/`.pls` fixture into the queue
   - `savePlaylistFile` writes what it read
   - `exportLibraryPlaylist` and `importLibraryPlaylist` go through `MusicBackendStub`
2. `PlaylistListInputView` (`Tests/RoadieTests/PlaylistOverlaysTests.swift`):
   - `row(atY:)` at scale 1 and 2, scrolled, past the end
   - `dragOperation` for file URLs, library `MediaID`s and internal row moves
   - `PlaylistWindowOverlays.layout` frames, including shaded
   Build them with plain `NSView` containers; no window server events.
3. `JumpToFilePanel`: drive `show(model:)` headless. Type into the search field through its delegate, and check the table's rows follow `JumpToFileController`. Enter plays the row, and Queue adds it to up-next. This answers #0211's follow-up.
4. `PlaylistPickerSheet`: its list and choose action against `MusicBackendStub`'s playlists, as far as they are logic.

## Tests

`loadListOpensFileOnLocal`, `loadPlaylistFileFillsQueue`, `savePlaylistFileRoundTrips`, `exportImportLibraryPlaylist`, `rowAtYAtBothScales`, `dragOperationByPasteboard`, `overlayFramesFollowLayout`, `jumpPanelSearchFiltersRows`, `jumpPanelEnterPlays`, `jumpPanelQueueAddsUpNext`. Expect list: all of them.

## Which tier

**Fast:** `scripts/verify.sh --expect <the tests above>`. The new tests must not need the network, a real Keychain or a speaker. They use the stubs and injectable seams the plan names.
