# 0225 — A genre can't be opened to its albums, artists and tracks, or played or shuffled as a whole

| | |
|---|---|
| **Status** | open |
| **Module** | LibraryBrowser / App / MusicAssistantKit |
| **Platform** | macOS |
| **First seen** | 2026-10-27 |

## Description

After #0224 the Library lists genres, but selecting one shows only its name: none of its albums, artists or tracks, and no way to play it. This issue fills the genre detail (a header with the counts and Play / Shuffle, then Albums | Artists | Tracks lists whose rows behave like the rest of the Library: play, play next, add to queue, add to playlist, favorite, drag to the playlist editor) and gives the genre rows Play, Shuffle, Play Next and Add to Queue, with double-click and Return to play. Design: [docs/design/genres.md](../docs/design/genres.md) §2.3–§2.5, §4.3.

## Plan

1. **`GenresModel`** (from #0224) gains:
   - `enum GenreKind: String, CaseIterable { case albums, artists, tracks }`, `availableKinds(_ genre:)` (count > 0, in that order), `selectedKind` (per genre for the session: a `[MediaID: GenreKind]`, defaulting to the first available kind);
   - `albums: PagedList<LibraryAlbum>`, `artists: PagedList<LibraryArtist>`, `tracks: PagedList<LibraryTrack>`, reloaded with `backend.albums/artists/tracks(inGenre:page:)` when the selected genre changes, each loaded only when its kind is first shown;
   - their failures → `onFailure`; `reload()` also reloads the shown kind of the open genre.
   - If a kind's count is non-zero but its first page is empty (design risk 5), drop it from `availableKinds` for that genre and log it; the count line keeps the server's numbers.
2. **Detail view** (`App/Browser/GenreDetailView.swift`, new; replaces #0224's placeholder in `LibraryWindowView.detailColumn`), shaped like `FavoritesDetailView`:
   - header: name (`.title2.bold()`), `GenreList.countsText`, then `Button("Play", systemImage: "play.fill")` (`library.genre.play`) and `Button("Shuffle", systemImage: "shuffle")` (`library.genre.shuffle`), with `.accessibilityLabel("Play \(name)")` / `"Shuffle \(name)"`; disabled while not connected;
   - a segmented `Picker` (`library.genre.kind`) over `availableKinds` when there are two or more; none for one;
   - the shown kind's list with the existing rows: albums as in `AlbumListView` (`libraryContainerActions`, `libraryDraggable`, artwork), pushing the album's tracks through a `NavigationStack` bound to `library.selectedAlbum` as Favorites does; artists as in `ArtistListView`'s rows (context menu via `libraryContainerMenu`; selecting one switches to `.artists` with it selected, as Favorites' artists do: reuse that code path); tracks with the `TrackListView` row layout and `libraryTrackActions(rows:album: nil, model:)` plus `libraryDraggable`;
   - paging through `PagedListView` for each list;
   - AXID `library.genre.detail` on the container.
3. **Genre rows** (`GenreListView` from #0224): `.contextMenu` with Play, Shuffle, Play Next, Add to Queue (`PlayRequest.play/shuffle/next/append(genre:)` from #0223, through `player.playFromLibrary`); double-click (simultaneous `TapGesture(count: 2)`, as the playlist rows do) and Return (the list's primary action) play; ⌥Return shuffles. No Add to Playlist, no Favorite, not draggable (design §2.2, risk 7).
4. **The play path**: `PlayerModel.playFromLibrary` already branches on `request.shuffled` (#0223). Check the local-playback gate (`LocalPlaybackGate.refusal`) treats a genre like any Music Assistant container: nothing to change expected.
5. **Fallback check** (design §4.3): the by-hand run (step 3 below) tells whether the server accepts a genre URI. If it refuses, the #0223 fallback is what plays; say in `## Fix` which path the real server took and how many tracks Classical queued. If the server accepts but plays only a sample, record that in `docs/ma-protocol-notes.md` › Genres; no code change.
6. **Feature inventory** (`docs/design/test-automation.md` §5.7): add the row "Genre detail: albums, artists, tracks with the Library's row actions and drags; Play / Shuffle a genre; genre row menu" → UI `GenresUITests.genreDetailShowsItsKinds`, `.playPlaysTheGenre`, `.shuffleSendsShuffle`, `.genreRowMenu`, `.genreRowsBehaveLikeTheLibrary`; Unit `GenresModelTests`, `BackendGenresTests`.

## UI tests

`GenresUITests` (from #0224), scenario `libraryIdle`, the speaker selected in `library.output` (so `maRequests` shows the play):

- `genreDetailShowsItsKinds`: click the recorded largest genre → `library.genre.detail`; the counts line; `library.genre.kind` lists only the kinds with counts; picking Albums shows the recorded `genre-albums-filter` rows; Tracks shows the recorded tracks.
- `playPlaysTheGenre`: `library.genre.play` → `maRequests` ends with `play_media media=library://genre/<id> option=replace` (no `shuffle=`); the playlist editor shows the scripted expansion's rows, row 0 current.
- `shuffleSendsShuffle`: `library.genre.shuffle` → `… option=replace shuffle=true`.
- `genreRowMenu`: right-click a genre row → Play, Shuffle, Play Next, Add to Queue, and no Add to Playlist; Play Next → `option=next`; double-click the row → `option=replace`.
- `genreRowsBehaveLikeTheLibrary`: in the detail's Albums, double-click an album → `play_media` with the album URI; right-click a track in Tracks → Add to Queue → `option=add` with the track URI; drag an album row onto `pl.row.1` → `play_media option=add` (a Music Assistant queue appends, #0173 decision 4).

## By hand

1. Against the real server, ⌘L › Genres › Electronic: the header says 403 tracks · 39 albums · 33 artists; Albums lists albums, Artists lists artists, Tracks lists tracks, each scrolling to the end.
2. Classical shows Artists and Tracks only; Dance shows just its tracks with no picker.
3. On a speaker: Play on Classical starts it; the playlist editor shows the queue: note how many tracks were queued and whether they're in order. Shuffle: the queue is shuffled (the main window's shuffle light is on).
4. On This Mac: Shuffle on Rock plays through the Mac.
5. Right-click a genre: Play Next puts it after the current track; Add to Queue appends.
6. In a genre's Albums, drag an album into the playlist editor: it's added; right-click a track › Add to Playlist ▸ Party: the track is in Party.
7. Double-click a genre row plays it; Return on a selected row plays it; ⌥Return shuffles.
