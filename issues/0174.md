## Description

**Needs the user.** Agents can't run Winamp. Spec §1.4 ([docs/music-selection-features.md](../docs/music-selection-features.md)) lists Winamp details that differ between versions and haven't been confirmed. Check them on a real Winamp 5.x: it installs from winamp.com or archive.org and runs in a Windows VM or CrossOver. Use stock Winamp, then Winamp with the bundled `gen_jumpex` (JTFE) where it matters. Webamp can't answer these: it has no Jump to File and no Media Library.

No other issue is blocked on this. Until the findings are in, the plans use the defaults below. When they arrive, update the issues named in each row: plans that haven't been implemented yet, or a follow-up issue under #0173 for code that has already landed.

## What to check

| # | Question | Default the plans use until then | Affects |
|---|---|---|---|
| 1 | Where does the `[n]` marker sit in a playlist row: at the end of the title text, or in front of the time column? Is it drawn in a different colour, or is the row highlighted? | Its own cell just before the time column, in the row's normal text colour (current-track colour on the current row). The title truncates before the marker does. No extra highlight. | #0179, #0180 |
| 2 | When the queue runs out, does playback carry on after the last *queued* track, or go back to where it was when the queue started? Does JTFE have an option, and what is its default? | Not shuffled: carry on from the entry after the last queued track. Shuffled: carry on from the shuffle position where the queue started. | #0177 |
| 3 | Does a bare `Q` in the playlist editor toggle the queue for the selection in stock Winamp 5, or only with JTFE? With a mixed selection, does it toggle each row or queue them all? | `Q` in the playlist editor (not a global hotkey). If every selected row is queued, it dequeues them; otherwise it queues the ones that aren't, at the end of the queue, in row order. | #0179 |
| 4 | What is Winamp 5's shortcut to show or hide the Media Library (thought to be `Alt+L`)? Is it a toggle? | No bare key. The Media Library item uses ⌘L (the menu bar's existing Library shortcut) and opens or brings the window forward. | #0185 |
| 5 | Does playing a queued entry directly (double-click, or Jump to File's Play) take it off the queue? | Yes. | #0177 |
| 6 | When the playing track is queued again, does it play again after itself? | Yes, it may be queued. | #0177 |
| 7 | Does `J` toggle the Jump to File dialog when it's already open, or bring it forward? Does Return close it? | Bring it forward (friendlier on macOS). Play closes the panel. | #0176 |
| 8 | Does Jump to File's Queue (JTFE) leave the dialog open? Does a second Queue on a queued entry dequeue it? | It stays open and toggles, like `Q`. | #0180 |

## How to report
