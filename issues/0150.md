# 0150 — The forward button does nothing while a playlist is playing

| | |
|---|---|
| **Status** | open |
| **Module** | Player / MusicAssistantKit |
| **Platform** | macOS |
| **First seen** | 2026-10-23 |

## Description

Reported on build 0.1.0 (20261022.0456): while listening to a playlist, pressing the main window's forward (next track) button does nothing. Playback continues on the current track.

The playlist was started from the Library (Music Assistant), so the queue is Music Assistant's (#0144). Not yet known whether the output was This Mac (Sendspin) or a speaker, or whether ⌘→ / the media keys / Now Playing next behave the same.

## Steps to reproduce

1. Play a Music Assistant playlist from the Library.
2. Press the forward button in the main window.

## Expected behavior

Playback skips to the next track in the queue, and the PL window and marquee follow.

## Actual behavior

Nothing happens.
