# 0100 — Playlists that list other playlists are skipped instead of expanded

| | |
|---|---|
| **Status** | open |
| **Module** | AudioCore |
| **Platform** | macOS |
| **First seen** | 2026-10-19 |

## Description

`PlaylistFile.resolve` returns `.skip(reason: "nested playlist")` for an entry that is itself a playlist, and `LocalTrackLoader.expandPlaylists` reports it as skipped. Winamp expands a playlist entry that points at another `.m3u`/`.m3u8`/`.pls` in place.

Expected:

- A nested playlist entry is expanded at its position, with its own relative paths resolved against its own folder.
- Cycles (A lists B lists A, or A lists itself) and excessive depth (say more than 8 levels) stop with a skip reason instead of looping.
- Tests with playlist files written to a temp folder in the test: one level, two levels, a cycle, self-reference, missing nested file.
