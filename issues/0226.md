# 0226 — The playlist editor's commands are only reachable through skinned buttons a skin can make unreadable

|---|---|

## Description

The user, 2026-10-27: "This can be hard to do when the skin is insufficient. I do not see the load option here. I had to change to a more complete skin to see it. Is there a way to make it more clear?" The skin was 100cc Class, whose playlist editor draws the ADD, REM, SEL, MISC and LIST buttons as kart racers with no labels ([0226/100cc-playlist-editor.png](0226/100cc-playlist-editor.png)). The user wanted to replace the list with another playlist (LIST › Load) and couldn't find it.

The five buttons' pop-up menus are the only way to reach most of the editor's commands. The menu bar has File › Load Playlist… (a file), File › Save Playlist…, Playback › Load Playlist from Library… and Save Queue as Playlist…, but no New List, Remove All, Crop, Select All/None/Invert, Sort, Reverse, Randomize or Add URL/Folder. The skinned pop-ups also don't show up in the accessibility tree (found in #0203), so VoiceOver can't reach them either.

## Expected

A **Playlist** menu in the menu bar that holds every command the five skinned buttons offer, grouped as they are (Add, Remove, Select, Misc/Sort, List), with keyboard shortcuts where Winamp has them. It works on any skin and with VoiceOver, and is enabled or disabled exactly as the skinned items are (e.g. Music Assistant queue vs local queue).
