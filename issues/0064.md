# 0064 — Music Assistant players cannot be controlled from SkinAmp

| | |
|---|---|
| **Status** | open |
| **Module** | App / MusicAssistantKit |
| **Platform** | macOS |
| **First seen** | 2026-10-13 |

## Description

Controller mode (doc section 5.2, mode 1): SkinAmp browses the MA library and plays it on MA players such as HomePods. MA streams from the server; no audio passes through the Mac.

## Acceptance criteria

- An output picker lists MA players (including HomePods and groups).
- Play an album, track or playlist on the chosen player (`player_queues/play_media`), and drive play, pause, next, previous, seek and volume from the skinned transport buttons.
- Now playing, elapsed time and artwork come from MA events and drive the skinned window, Now Playing and media keys.
- Changes made from MA's web UI (play/pause, track change) show in SkinAmp within about 1 s.
- Doc acceptance: on the home LAN the app discovers MA, authenticates, browses the Plex-backed library, plays an album on a HomePod and reflects external changes.

## Notes

The skinned window currently binds to AudioCore's `Player`. In MA mode the window binds to the backend's now-playing stream instead; #0062 should make that switch possible. Hand-check only for real speakers; tests use stubbed events.
