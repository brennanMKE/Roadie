# 0092 — Renaming a Music Assistant server re-checks every server on each keystroke

| | |
|---|---|
| **Status** | open |
| **Module** | MusicAssistantKit / App |
| **Platform** | macOS |
| **First seen** | 2026-10-19 |

## Description

Found in the #0075 review (commit 80d3e78), not blocking there: the server name field saves on every keystroke, and after the first server choice each save triggers a re-check of every configured server at once, with no debounce. A rename never changes which server it is. Also, until the first server choice the Library window subtitle ends with "· Not checked yet".

Expected: a rename does not trigger a server re-check (or shares the existing 2 s network-change debounce), and the subtitle reads sensibly before the first choice.
