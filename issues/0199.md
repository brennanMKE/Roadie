# 0199 — The skinned windows have no accessibility identifiers or values

| | |
|---|---|
| **Status** | open |
| **Module** | App |
| **Platform** | macOS |
| **First seen** | 2026-10-24 |

## Description

Every control in the main, equalizer and playlist windows is a SwiftUI `Button` with an `EmptyView` label and a sprite-drawing style, or a `SkinSlider`, or a tap-gesture view; the playlist rows are `Text`s under an AppKit `PlaylistListInputView`. XCUITest sees unlabeled buttons and can't tell them apart, can't read what's playing, and can't find row 3. This issue gives every control an identifier from one registry and every display a readable value, adds a state probe for compound state, and changes nothing visually. The Library, Skins and Settings views already have some identifiers (`library.*`, `skins.*`, `ma.*`) and get the missing ones. Design: [docs/design/test-automation.md](../docs/design/test-automation.md) §3.2.

## Plan

### 1. The registry (`App/Accessibility/AXID.swift`, new)

```swift
/// Accessibility identifiers shared by the app and RoadieUITests (one string per control, never typed twice).
enum AXID {
    enum Main { static let play = "main.play"; … }
    enum EQ { static func band(_ i: Int) -> String { "eq.band.\(i)" }; … }
    enum PL { static func row(_ i: Int) -> String { "pl.row.\(i)" }; enum Menu { … } }
    enum Shade { … }
    enum Jump { … }
    enum Library { … }
    static let probe = "state.probe"
    /// Every static identifier, for the uniqueness test.
    static let all: [String]
}
```

The full list is in the design doc §3.2. The file is added to both the app target and `RoadieUITests` (#0200 adds it to the test target's sources with `path:` in `project.yml`, so one file, two targets).

### 2. Main window (`MainWindowView.swift`, `TitleBarView.swift`, `ClutterBarView.swift`, `MainShadeView.swift`, `SliderViews.swift`, `MarqueeView.swift`, `MainWindowStatusView.swift`, `Visualizer/VisualizerView.swift`)

- `transportButton` / `toggleButton` / title-bar and clutter buttons: `.accessibilityIdentifier(AXID.Main.<name>)`, `.accessibilityLabel("Play")`, and for toggles `.accessibilityAddTraits(selected ? .isSelected : [])`. The `ButtonStyle`s don't change.
- `SkinSlider`: `.accessibilityElement()`, `.accessibilityIdentifier`, `.accessibilityValue(valueText)` where the caller passes `"\(Int(volume * 100))"`, `"\(Int(balance * 100))"` and `"\(elapsed) / \(duration)"`, and `.accessibilityAdjustableAction` that calls `onChange`/`onCommit` with ±2 % so `XCUIElement.adjust` works where coordinates are awkward.
- `MainWindowStatusLayer`: one element `main.time` with value `"\(mode) \(mm:ss)"`; `main.kbps`, `main.khz` with their numbers; `main.stereo` with `stereo|mono|none`; the play-state indicator `main.state` with `playing|paused|stopped|loading`.
- `MarqueeView`: `main.marquee`, value the full unscrolled text (`model.marqueeText`, or the override while a notice shows).
- `VisualizerView`: `main.visualizer`, value `spectrum|oscilloscope|off`.
- `MainShadeView`: `shade.main.*` for its transport, position, time and marquee.

### 3. Equalizer (`Equalizer/*.swift`)

`eq.on`, `eq.auto`, `eq.presets` (the `Menu`), `eq.preamp`, `eq.band.0`–`eq.band.9` (values in dB, one decimal), `eq.level.plus|zero|minus`, `eq.graph` (value: the ten band values joined by spaces), `eq.title.shade|close`, `shade.eq.*`.

### 4. Playlist (`Playlist/PlaylistWindowView.swift`, `PlaylistWindowOverlays.swift`)

- `PlaylistTrackListView` rows: on the row `HStack`, `.accessibilityElement(children: .combine)`, `.accessibilityIdentifier(AXID.PL.row(row.index))` (the queue index, not the visible position; add `index` to `PlaylistModel.Row` if it's missing), `.accessibilityLabel(row.number + row.name)`, `.accessibilityValue("marker=\(row.marker) duration=\(row.duration) current=\(row.isCurrent)")`, `.accessibilityAddTraits(row.isSelected ? .isSelected : [])`.
- `PlaylistListInputView` and `PlaylistResizeView`: `override var isAccessibilityElement: Bool { false }` (confirm the default; set it explicitly) so they don't shadow the rows. Their frames are the drop targets; XCUI clicks on a row land on them, which is what we want.
- Menus: each tapped entry in the ADD/REM/SEL/MISC/LIST column gets `.accessibilityAddTraits(.isButton)`, `.accessibilityIdentifier(AXID.PL.Menu.<menu>.<entry>)` and a label (`"Add File"`); the five menu buttons `pl.menu.add|rem|sel|misc|list`.
- `pl.scrollbar` (value: the handle fraction), `pl.scroll.up|down`, `pl.resize`, `pl.transport.*` (the six invisible buttons), `pl.runningTime` (value text), `pl.miniTime`, `pl.title.shade|close`, `shade.pl.*`.

### 5. Jump to File, Library, Skins (`JumpToFile/JumpToFilePanel.swift`, `Browser/*.swift`, `SkinBrowser/*.swift`)

- Panel: `jump.search` (`NSSearchField.setAccessibilityIdentifier`), the table `jump.table`, rows `jump.row.N` via `tableView(_:rowViewForRow:)` or the cell view's identifier, `jump.queue`, `jump.empty`.
- Library: `library.sidebar.<section>` on the sidebar labels, `library.row.artist.<id>` / `.album.` / `.track.` / `.playlist.` on the rows (the `MediaID`'s raw value, sanitised), `library.output` on the output picker, `library.search` on the search field if SwiftUI lets it (else document that the toolbar search field is found by role).
- Skins: `skins.source`, `skins.filter`, `skins.random`, `skins.refresh`, `skins.museum.search`, `skins.museum.cell` (label: the skin's display name; value: `downloaded|available`).

### 6. State probe (`App/Accessibility/StateProbe.swift`, new; `PlayerModel+Probe.swift`, new)

Only when `configuration.isUITest`: `SkinWindowController` for `.main` adds an `NSAccessibilityElement` child (`accessibilityIdentifier = AXID.probe`, role `.staticText`, frame 1×1 at the window's top-left, `accessibilityValue` computed on demand from `PlayerModel.testProbe()`), which returns a JSON string:

```json
{"output":"thisMac","feed":"local","state":"playing","currentIndex":3,
 "queue":[{"title":"Tone Artist - Tone A","marker":"","current":false},…],
 "notice":null,"lastExternalOpen":null,"tokenStore":"memory",
 "maRequests":["player_queues/play_index index=3 queue_id=ap223aed81fe30"]}
```

`maRequests` comes from `ScriptedMusicAssistant.receivedCommands` (#0197; empty when `.live`). `RoadieTests` can call `testProbe()` directly.

### 7. No visual change

Nothing here adds a frame, a border or a focus ring: SwiftUI's accessibility modifiers don't draw. Check `TitleBarButtonStyle`/`SpriteButtonStyle` still receive `configuration.isPressed` the same way (they will; modifiers wrap the button). Run `--skins` so `skintool --png` renders are unchanged (they don't go through SwiftUI, so this is a sanity check only).

## Tests

`Tests/RoadieTests/AXIDTests.swift` (needs #0193):

- `identifiersAreUnique`: `Set(AXID.all).count == AXID.all.count`.
- `identifiersUseTheDottedScheme`: every id matches `^[a-z]+(\.[a-z0-9]+)+$`.
- `mainWindowExposesEveryControl`: build `SkinWindowController(kind: .main, …)` with a test-mode `PlayerModel` (#0194) and a generated skin, don't show it, and walk `window.contentView`'s accessibility tree (`accessibilityChildren()` recursively) collecting identifiers: every `AXID.Main.*` is present once. Same for `.equalizer` and `.playlist` (`playlistRowsAreAccessibilityElements`: with three local tracks, `pl.row.0…2` exist with the expected labels and `current=` values).
- `probeReportsTheQueue`: `testProbe()` on a model with three tracks and index 1 current decodes to the expected JSON.

Expect list: `identifiersAreUnique,identifiersUseTheDottedScheme,mainWindowExposesEveryControl,playlistRowsAreAccessibilityElements,probeReportsTheQueue`

## Which tier

**Fast:** `scripts/verify.sh --expect identifiersAreUnique,identifiersUseTheDottedScheme,mainWindowExposesEveryControl,playlistRowsAreAccessibilityElements,probeReportsTheQueue`, plus one `--skins <test skins cache>` run to show the `skintool --png` renders unchanged.

## By hand

1. Launch with the base skin and open Accessibility Inspector (Xcode › Open Developer Tool): hover the play button → identifier `main.play`; the third playlist row → `pl.row.2`, value `marker= duration=2:30 current=false`; the volume slider → value `75`.
2. Nothing looks different: compare a screenshot of the three windows before and after on the same skin (`screencapture -l <windowid>`), pixel-identical.
3. VoiceOver (⌘F5) reads "Play, button" on the play button and the row text on a row.
