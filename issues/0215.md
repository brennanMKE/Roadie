## Description

Every Library view in `App/Browser/` is at or near 0 % in #0212's baseline. That includes `SearchResultsView` (249 lines), `TrackListView` (234), `FavoritesView` (229), `PlaylistTracksView` (150), `RadioListView` (131), `AddToPlaylistMenu` (89), `DiscoverView` (13 %), `ArtistListView` (23 %), `OutputPickerView` (19 %), `PlaylistNameSheet` (22 %) and `LibraryPlaybackActions` (30 %). The clicking belongs to #0205 and #0206. Some of these views also hold logic that a unit test can reach: which IDs a selection plays, what is added to which playlist, headings, symbols, trimming and confirmation text. This issue tests that logic.

## Plan

1. `PlayerModel.addToPlaylist(_:_:)` and `createPlaylist(named:adding:)` (`AddToPlaylistMenu.swift`): against `MusicBackendStub`, check that the items reach the right playlist, that a new playlist is created then filled, and that a backend without playlist editing leaves a notice. Test file: `Tests/RoadieTests/LibraryPlaylistActionsTests.swift`.
2. Move the pure parts out of the views into `static` or `internal` helpers next to them, with no behaviour change, then test them in `Tests/RoadieTests/LibraryViewLogicTests.swift`:
   - `DiscoverRowView.playable(_:in:)` and `request(_:mode:)`
   - `FavoriteKindsView.title/symbol` and `DiscoverItemRow.symbol` (every case)
   - `TrackListView`'s `heading` and `openPlaylist` choice
   - `PlaylistTracksView.confirmTitle`
   - `PlaylistNameSheet`'s trim and commit rule (blank names refused)
   - `RadioListView.play` and `AddRadioSheet.add` through `RadioURLInput`
   - `OutputPickerView.name(of:)`
3. `LibraryPlaybackActions.swift`: the play and enqueue paths its modifiers call (the `PlayRequest`s they build for a track, an album and a playlist).

## Tests

`addToPlaylistSendsItems`, `createPlaylistThenAdds`, `addToPlaylistUnsupportedShowsNotice`, `discoverPlayableSkipsMappings`, `favoriteKindTitlesAndSymbols`, `trackListHeading`, `playlistNameIsTrimmed`, `radioAddParsesURL`, `outputNameFallsBack`, `libraryActionsBuildRequests`. Expect list: all of them.

## Which tier

**Fast:** `scripts/verify.sh --expect <the tests above>`. The new tests must not need the network, a real Keychain or a speaker. They use the stubs and injectable seams the plan names.
