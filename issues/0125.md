# 0125 — Output panel has no per-speaker volume or view of what each player is playing

| | |
|---|---|
| **Status** | open |

| **Platform** | macOS |

## Description

Requested by the user after trying 0.1.0-c87a381 alongside Music Assistant's own web app and iPhone app. Those apps show:

1. **Every player and what it's playing.** The player list shows each speaker (and SkinAmp's own "SkinAmp" player for This Mac), with its current track and state, so the user can see which one SkinAmp is driving.
2. **An output sheet in Now Playing.** Expanding Now Playing shows an outputs button at the bottom; tapping it lists the outputs of the current playback (the group leader and its members), each with its own volume slider, plus the group's volume.

SkinAmp has the Output panel from #0118 (checkboxes, "Only", groups) but no per-speaker volume, no group volume, and no indication of what each player is playing. The main window's volume slider only drives the target (#0121's leader).

## Expected behavior

- **Per-output volume in the Output panel.** Each checked output (This Mac and every member speaker) has a volume slider (and mute), sent with `players/cmd/volume_set` / `volume_mute` to that player. This Mac's slider sets SkinAmp's own volume.
- **Group volume.** When more than one output is selected, a group slider at the top moves them together (`players/cmd/group_volume`, `group_volume_mute`), and the main window's volume slider drives the group volume, not only the leader's.
- **Volumes follow Music Assistant.** A change made in the web or iPhone app moves SkinAmp's sliders (from the player-updated events #0121 already follows); dragging a slider doesn't fight incoming updates.
- **What each player is playing.** Each row in the Output panel shows the player's state and current track (title · artist, or "Idle"), and marks the one SkinAmp controls, so the panel works like Music Assistant's player list. Picking a row that's already playing something adopts it (per #0121) rather than restarting.
- Tests with the existing fakes cover the volume commands, group volume, following an external volume change, and the per-row now-playing text.
