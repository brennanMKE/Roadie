## Description

#0105 gives SkinAmp a Sendspin session that emits stream events and timed PCM chunks; #0106 lets AudioCore's `Player` play a timed PCM stream through the EQ, balance and visualizer. Nothing connects the two: no object owns the session for "This Mac", starts the player's stream on `stream/start`, feeds it chunks, applies Music Assistant's volume and mute commands, reports local volume changes back, or tells anyone when local playback takes the node away. This issue adds that bridge as a small new target and puts it in `LocalPlaybackStack`, which #0074 created for exactly this ("#0066 adds Music Assistant's Sendspin input here").

## Resolution notes

> 🟢 Resolved 2026-10-19 — `SendspinPlayer` (new `SendspinPlayback` target, built by `LocalPlaybackStack`) now carries Sendspin streams, volume and mute into the `Player` and reports local volume and preemption back; review run 20261019-233745-72123 passed (1265 tests, all 13 expected).

## Root cause

Nothing connected the Sendspin session (#0105) to AudioCore's stream input (#0106), so no object owned the session for "This Mac" or fed its audio to the player.

## Fix

Added the `SendspinPlayback` target with `SendspinPlayer`, as the plan describes. `LocalPlaybackStack` builds it as `sendspin`, and `LocalPlayback` depends on the new target. Construction starts nothing. The event loop runs per session generation, so events from a stopped session are dropped. The bridge clears `isStreaming` before it ends a stream itself. Because of that, any `.streamEnded` or `.streamPreempted` from the player that arrives while `isStreaming` is still true comes from local transport, and `onStreamPreempted` fires once.

Divergences from the plan:
- **Debounce:** `init` takes an injectable `debounce:` (default 150 ms). The tests use real short sleeps.
- **Volume while muted:** `.setVolume` un-mutes. While muted, the bridge reports the remembered level with `muted: true`. If the user moves the slider while muted, the next report un-mutes.
- **Volume observation:** it is armed on `start`, not in `init`, and stops re-arming after `stop`.

### `Sources/SendspinPlayback/SendspinPlayer.swift` (new)

```swift
@MainActor @Observable
public final class SendspinPlayer {
    public enum Status: Equatable, Sendable { case off, connecting, connected(serverName: String), failed(String) }
    public private(set) var status: Status = .off
    public private(set) var isStreaming = false
    public let player: Player
    /// Called when a stream starts (Music Assistant began playing on this Mac, from SkinAmp or elsewhere).
    public var onStreamStarted: (() -> Void)?
    /// Called when local playback took the node (the app asks Music Assistant to stop sending, #0109).
    public var onStreamPreempted: (() -> Void)?
    public init(player: Player, makeSession: @escaping @Sendable (SendspinConnectionConfiguration) -> any SendspinSessionDriving = { SendspinSession(configuration: $0) })
    public func start(_ configuration: SendspinConnectionConfiguration)   // stops any running session first
    public func stop(reason: SendspinGoodbyeReason = .shutdown) async
    /// The single PCM format to advertise: 16-bit stereo at the output's rate.
    public func advertisedFormat() -> SendspinAudioFormat
}
```

Behaviour:

1. **Construction does nothing** (no session, no audio device, no network), so `LocalPlaybackStack.standard()` stays side-effect free.
2. `advertisedFormat()`: `SendspinAudioFormat(codec: "pcm", channels: 2, sampleRate: Int(player.streamOutputSampleRate.rounded()), bitDepth: 16)`. The app passes it into the configuration (#0109) so the server resamples to the output rate.
3. `start`: `status = .connecting`, build the session, `await session.start()`, consume `events()` in a task:
   - `.connected(hello)` → `status = .connected(serverName: hello.name)`; send the initial `report(volume:muted:)` from the player (`Int((player.volume * 100).rounded())`, `muted`).
   - `.streamStarted(format)`: only `codec == "pcm"` and `bitDepth` 16 or 24 are accepted (anything else: log and ignore the stream's audio; with one advertised PCM format it cannot happen). First start → `try player.beginStream(StreamFormat(sampleRate:, channels:, bitDepth:))`, `isStreaming = true`, `onStreamStarted?()`. A start while streaming → `player.changeStreamFormat`.
   - `.audio(chunk, localMicros)` → `player.appendStream(StreamChunk(presentationMicros: localMicros, pcm: chunk.payload))` while `isStreaming`; otherwise dropped.
   - `.streamCleared` → `player.clearStream()`. `.streamEnded` → `player.endStream()`, `isStreaming = false`.
   - `.setVolume(v)` → `player.volume = Float(v) / 100` (Winamp's linear slider; see notes section 5), un-mute bookkeeping, then `report`. `.setMute(m)`: mute by remembering `preMuteVolume` and setting `player.volume = 0`; un-mute restores it; report `muted`. (AudioCore has no mute flag; adding one is out of scope.)
   - `.disconnected(error)` → if streaming, `player.endStream()`; `status = error.map { .failed($0.localizedDescription) } ?? .connecting` (the session reconnects by itself; `.unauthorized` stays `.failed` because the session stops).
4. **Local volume → Music Assistant:** observe `player.volume` with `withObservationTracking` (re-armed after each change), debounce 150 ms, and `report` the new value unless it came from a server command (skip the echo by comparing with the last reported value).
5. **Preemption:** subscribe with `player.addEventObserver`: `.streamPreempted` → `isStreaming = false`, `onStreamPreempted?()`. `.streamEnded` initiated by `Player.stop()` (e.g. the user pressed stop on This Mac while the local feed was active) behaves the same.
6. `stop`: `await session.stop(reason:)`, end the stream, cancel the tasks, `status = .off`.
