# 0054 — Visualizer runs ahead of the audio on AirPlay 2

| | |
|---|---|
| **Status** | open |
| **Module** | AudioCore / App |
| **Platform** | macOS |
| **First seen** | 2026-10-13 |

## Description

The analyzer tap runs when audio is rendered. Under AirPlay 2 enhanced buffering that is up to minutes before the audio is heard, so the spectrum and oscilloscope would show the future.

## Acceptance criteria

- Analysis frames (spectrum bins, 576-sample oscilloscope) are stored in a ring buffer keyed by presentation time on the synchronizer's timeline.
- The visualizer's render loop reads the synchronizer's (or player's) current time and draws the frame nearest it, subtracting output latency if #0050 found the clock doesn't include it.
- Locally the visualizer still tracks the audio as it does now.
