## Description

Reported by the user on the 0.1.0-eb403d8 build. Nothing in the menu bar opens the Library window, so there is no discoverable way to browse Music Assistant and pick music. The scene's ⌘L shortcut works, but SwiftUI's automatic Window-menu entry for the `Window("Library")` scene does not appear in this app, so the shortcut isn't shown anywhere.

## Expected behavior

- Window › Library, with ⌘L shown, opens (or brings forward) the Library window.
- Playback › Library (⌘L) at the top of the Playback menu opens it too (the user asked for it there as well); the Window menu entry shows no shortcut, so ⌘L belongs to one item.
