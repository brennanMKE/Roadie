# 0010 — Server address input is not normalized or tested

| | |
|---|---|
| **Status** | open |
| **Module** | PlexKit |
| **Platform** | macOS |
| **First seen** | 2026-10-12 |

## Description

Implement `PlexAddress.normalize(_:)` and a three-step connection test whose failures map to the user-facing messages in `docs/plex-music-library.md`.

## Acceptance criteria

- `joe`, `joe:32400`, `http://joe:32400`, `192.168.1.10` normalize as documented; `https://` is kept.
- Identity → sections-with-token → music-section-exists, each with its own message.
- The `machineIdentifier` is saved; a change clears the selected library.
- Unit tests cover normalization and every failure path.
